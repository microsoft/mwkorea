# Microsoft 365 Copilot에 Anthropic Claude Opus 5 도착: Word·Excel·PowerPoint까지 모델을 골라 쓴다

Microsoft가 Microsoft 365 Copilot의 **모델 선택(model choice)** 폭을 다시 한 번 넓혔습니다. 이번에 추가된 모델은 Anthropic의 최신 모델인 **Claude Opus 5**입니다.

Claude Opus 5는 Anthropic Opus 제품군의 최신 모델로, **복잡하고 여러 단계를 거치는 업무를 매일 처리하도록** 설계됐습니다. Anthropic에 따르면 이전 세대인 Opus 4.8 대비 **에이전트 코딩(agentic coding), 전문 지식 업무(professional knowledge work), 장기 추론(long-horizon reasoning)** 전반에서 개선됐습니다.

여기서 눈여겨볼 점은 단순히 "더 좋은 모델이 하나 추가됐다"가 아닙니다. Copilot이 **아이디어에서 완성된 결과물까지 그 사이의 단계를 더 많이 대신 처리**하되, 최종 결과에 대한 통제권은 사용자가 유지하는 방향으로 나아가고 있다는 점입니다.

---

## 앱별로 무엇이 좋아지나

Opus 5는 매일 쓰는 앱 전반에서 다음과 같은 강점을 발휘합니다.

- **Word**: 거친 아이디어에서 **완성도 있는 초안**으로. 긴 문서에서도 구조와 흐름이 흐트러지지 않도록 유지합니다.
- **Excel**: 복잡한 분석을 단계적으로 처리하며, **더 높은 품질의 모델링**과 정돈된 워크북을 만들어 냅니다.
- **PowerPoint**: 첫 개요에서 완성된 덱까지 초안을 만들고 다듬습니다. **시각적 완성도, 창의적인 레이아웃, 슬라이드 공간 활용**이 개선됐습니다.
- **Copilot Chat**: 정답이 정해지지 않은 열린 문제 — 선택지 비교, 계획 구조화, 모호함 정리 — 를 **더 강한 추론**으로 다룹니다.
- **Copilot Cowork**: 오래 걸리는 작업에 집중력을 유지하며, **Work IQ**가 조직에서 가져오는 컨텍스트를 바탕으로 여러 도구와 파일을 오케스트레이션해 프로젝트를 처음부터 끝까지 끌고 갑니다.
- **Copilot Studio**: **미리 보기(preview) 오케스트레이터**에서 Claude Opus 5 기반 에이전트를 만들 수 있습니다. 고급 추론, 워크플로 자동화, 다단계 도구 사용에 활용됩니다.

## 왜 '모델 선택'이 중요한가

한국의 Copilot 도입 담당자·메이커 관점에서 이번 발표는 두 가지 의미가 있습니다.

**첫째, 업무 성격에 따라 모델을 고를 수 있게 됐습니다.** 모든 업무가 같은 성격이 아닙니다. 짧고 정형화된 요약과, 여러 단계를 거치며 판단이 필요한 분석은 요구되는 능력이 다릅니다. 모델 선택지가 늘어난다는 것은 조직이 **업무 유형에 맞는 엔진을 고를 수 있다**는 뜻입니다.

**둘째, 엔터프라이즈 요건 위에서 제공됩니다.** Microsoft는 최신 AI 혁신과 모델 선택지를 **Microsoft의 엔터프라이즈급 보안·개인정보 보호·규정 준수** 위에서 제공한다는 점을 강조했습니다. 외부 모델을 쓰더라도 조직의 거버넌스 체계 안에서 운영된다는 점이 도입 검토 시 핵심 고려사항입니다.

특히 **Copilot Studio의 preview 오케스트레이터**에서 Opus 5를 쓸 수 있다는 점은 에이전트를 만드는 메이커에게 실질적인 변화입니다. 다단계 도구 호출과 장기 추론이 필요한 에이전트라면 모델 후보로 검토해 볼 만합니다.

## 활용 시나리오

- **기획·전략 문서**: Word에서 긴 제안서·기획서를 쓸 때, 문서 전체의 논리 구조와 톤을 유지하며 초안을 완성합니다.
- **재무·데이터 분석**: Excel에서 다단계 모델링이 필요한 분석을 맡기고, 결과 워크북의 완성도를 높입니다.
- **임원 보고 덱**: PowerPoint에서 개요만 주고 레이아웃·여백 활용까지 다듬어진 덱 초안을 얻습니다.
- **장기 프로젝트 운영**: Copilot Cowork에서 여러 날에 걸친 작업을, Work IQ의 조직 컨텍스트와 함께 끝까지 진행합니다.
- **업무 자동화 에이전트**: Copilot Studio에서 여러 시스템을 오가며 판단이 필요한 에이전트를 Opus 5 기반으로 구성합니다.

## 시작하기와 확인할 점

Claude Opus 5는 **Word, Excel, PowerPoint, Chat, Copilot Cowork, Copilot Studio의 모델 선택기(model selector)** 에 순차적으로 롤아웃되고 있습니다.

도입 전 확인할 사항은 다음과 같습니다.

- **가용성 차이**: 제공 여부는 **지역(region)과 테넌트 구성에 따라 달라질 수 있습니다.** 최신 롤아웃 상태는 Microsoft 365 Roadmap과 Microsoft 365 Copilot 릴리스 노트에서 확인하세요.
- **Copilot Studio는 미리 보기 단계**: Opus 5 기반 에이전트 구성은 preview 오케스트레이터 대상이므로, 프로덕션 적용 전 충분한 검증이 필요합니다.
- **모델별 특성 비교**: 조직 내 대표 업무 몇 가지를 정해 기존 모델과 Opus 5의 결과를 나란히 비교해 보고, 어떤 업무에 어떤 모델을 권장할지 **사내 가이드**를 마련하는 것을 권합니다.
- **모델 세부 정보**: 모델 자체에 대한 상세 내용은 Anthropic의 Opus 5 발표를 참고하세요.

## 마무리

모델 선택지가 늘어난다는 것은 단순한 스펙 경쟁이 아니라, **"업무에 맞는 엔진을 조직이 직접 고른다"** 는 방향으로 Copilot이 성숙하고 있다는 신호입니다. Word에서의 긴 문서 작성부터 Copilot Studio의 다단계 에이전트까지, Claude Opus 5는 특히 **여러 단계를 거치고 오래 이어지는 업무**에서 존재감을 보일 것으로 보입니다.

이미 Microsoft 365 Copilot을 쓰고 있다면, 모델 선택기에 Opus 5가 나타나는지 확인하고 조직의 대표 업무로 짧은 비교 테스트부터 시작해 보시기 바랍니다.
