# Microsoft Edge의 Copilot 새 탭 페이지가 업무 허브로 확장됩니다

Microsoft Edge가 새 탭을 단순한 검색 시작 화면에서 Microsoft 365 Copilot과 업무 콘텐츠를 함께 사용하는 공간으로 확장합니다. 업그레이드된 Copilot 새 탭 페이지에서는 웹 검색과 사이트 이동, Copilot 질문, 관련 파일 및 일정 확인을 하나의 경험 안에서 처리할 수 있습니다.

이 기능은 모든 사용자에게 자동으로 켜지지 않습니다. Microsoft 365 Copilot 라이선스가 필요하며 관리자가 Edge 관리 서비스의 정책으로 활성화한 사용자 또는 Microsoft Entra 그룹에만 적용됩니다.

---

## 하나의 검색 상자에서 시작하는 세 가지 흐름

새 검색 상자는 웹사이트 주소 입력, 웹 검색, Microsoft 365 Copilot 질의를 함께 처리합니다. 사용자는 작업 목적에 따라 시작점을 따로 찾지 않고 같은 화면에서 이동할 수 있습니다. Copilot 채팅과 작성 기능도 강화되며, 제안 작업과 업무 콘텐츠를 사용해 다음 행동을 빠르게 시작하도록 돕습니다.

화면에는 새 디자인과 앱 시작 관리자, 고정된 빠른 링크, 테마 설정이 포함됩니다. 지원되는 환경에서는 선별된 뉴스와 콘텐츠를 제공하는 Discover 피드도 표시됩니다. 다만 2026년 9월부터 Discover 피드 및 피드 전환 기능은 제한되며 Microsoft는 이후 기능을 계속 개선할 계획입니다.

## 업무 카드가 가져오는 변화

Work cards는 조직의 파일과 일정 이벤트 같은 업무 콘텐츠를 새 탭에 표시할 수 있습니다. 브라우저를 열자마자 관련 자료를 확인하고 Copilot에 질문할 수 있다는 장점이 있지만, 공유 화면이나 공동 사용 환경에서는 노출되는 정보의 성격을 고려해야 합니다.

관리자는 사용자에게 단순한 디자인 변경이 아니라 조직 콘텐츠가 브라우저 시작 화면에 나타날 수 있는 변화임을 안내해야 합니다. 기존 권한 체계를 벗어나 콘텐츠를 공개한다는 의미는 아니지만, 조직의 AI 거버넌스와 화면 정보 노출 기준에 따라 사전 평가가 필요합니다.

## 기본 비활성 및 정책 구성

Copilot 새 탭 페이지는 **기본적으로 꺼져 있습니다**. 관리자는 Microsoft Edge management service에서 **CopilotNewTabPageEnabled** 정책을 사용해 전체 사용자 또는 선택한 Microsoft Entra 그룹에 구성을 할당할 수 있습니다.

이미 정책을 활성화한 조직에서는 업그레이드가 도달하면 사용자가 새 경험을 자동으로 보게 됩니다. 정책이 구성되지 않았거나 비활성화돼 있으면 기존 Edge 새 탭 페이지가 유지됩니다. 조직 정책에 따라 사용자가 새 경험을 직접 끄거나 Work cards와 Chat chips 사이를 전환할 수 있는 경우도 있습니다.

대상 사용자에게는 Microsoft 365 Copilot 라이선스가 필요합니다. 정책 대상 그룹과 라이선스 할당 그룹이 일치하는지 함께 확인해야 지원 문의를 줄일 수 있습니다.

## 출시 일정

업데이트된 일정은 다음과 같습니다.

- 공개 미리 보기: 2026년 9월 말 시작, 10월 중순 완료 예정
- 전 세계 일반 공급: 2026년 10월 중순 시작, 11월 초 완료 예정

이는 이전에 안내된 9월 초 미리 보기 및 9월 중순 일반 공급 계획보다 늦춰진 일정입니다. 조직의 파일럿과 교육 일정도 수정된 배포 기간을 기준으로 조정해야 합니다.

## 관리자 준비 체크리스트

현재 기능을 쓰지 않는 조직에는 출시 전 필수 조치가 없습니다. 활성화를 계획하거나 이미 정책을 사용 중이라면 다음을 확인합니다.

1. 현재 Edge와 Copilot 새 탭 페이지 정책 구성을 검토합니다.
2. 적용할 사용자 또는 Entra 그룹과 Microsoft 365 Copilot 라이선스를 대조합니다.
3. 파일과 일정 이벤트가 Work cards로 표시될 때의 거버넌스 영향을 평가합니다.
4. 관련 AI 및 규정 준수 요구 사항을 검토합니다.
5. 사용자 안내, 교육 자료, 헬프 데스크 문서를 업데이트합니다.

처음부터 전사 배포하기보다 대표 사용자 그룹에 정책을 할당해 검색·채팅 전환과 업무 카드 노출을 검증하는 방식이 안전합니다. 특히 사용자 자체 비활성화 허용 여부는 조직의 Edge 정책과 함께 확인해야 합니다.
