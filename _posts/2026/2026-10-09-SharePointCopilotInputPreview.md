# SharePoint Copilot, 채팅 옆 콘텐츠 미리보기와 입력 위젯을 예고하다

AI와 채팅하며 콘텐츠를 만들 때는 답변과 실제 결과물을 번갈아 확인해야 합니다. SharePoint Copilot의 새로운 로드맵은 이 확인 과정을 같은 화면에 가깝게 가져오는 변화입니다.

Roadmap **574106**은 채팅 옆 콘텐츠 미리보기와 AI 입력 위젯을 안내합니다. 핵심은 저장된 콘텐츠뿐 아니라 **아직 저장하지 않은 콘텐츠도 미리 볼 수 있는 경험**입니다.

---

## 채팅과 결과물을 함께 확인

사용자는 저장된 콘텐츠 및 미저장 콘텐츠의 미리보기를 채팅과 나란히 확인할 수 있게 됩니다. 작업 중인 결과를 살펴보며 추가 요청을 하는 데 도움이 될 수 있습니다.

원문은 저장된 버전과 미저장 버전의 차이를 자동 비교한다고 설명하지는 않습니다. 따라서 이를 버전 비교나 변경 이력 관리 기능으로 확대 해석하지 않아야 합니다.

## HTML 폼을 통한 입력

또 다른 변화는 생성된 HTML 폼과 상호작용하고, **응답을 확인한 뒤 채팅으로 전송**하는 방식입니다. 자연어 채팅만으로 입력하는 것과 다른 사용자 접점이 추가되는 셈입니다.

다만 원문에는 폼 데이터의 별도 저장소나 외부 시스템 제출, 승인 워크플로가 설명되어 있지 않습니다. 이 공지를 Power Apps나 업무용 폼 시스템을 대체한다는 의미로 받아들이면 안 됩니다.

## 제공 일정과 준비 사항

아카이브 기준 상태는 **In development**, **GA 목표는 2026년 11월**입니다. 플랫폼은 Web이며 Worldwide(Standard Multi-Tenant)를 대상으로 합니다.

콘텐츠 운영 담당자는 기능 제공 후 저장 전후의 동작과 입력 확인 흐름을 테스트하는 것이 좋습니다. 입력값을 채팅으로 보내기 전에 검토한다는 사용 습관을 안내하면 생성형 AI 사용 범위를 더 명확히 이해하는 데 도움이 됩니다.

## 마무리

이번 업데이트는 SharePoint Copilot의 콘텐츠 제작 경험을 더 시각적이고 상호작용 가능한 방향으로 확장합니다. 실제 제공 범위가 확인되면 콘텐츠 편집 업무의 검토 단계를 중심으로 활용을 평가해 보세요.
