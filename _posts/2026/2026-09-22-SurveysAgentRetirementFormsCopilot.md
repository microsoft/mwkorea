# Surveys 에이전트 종료, 기존 설문은 Forms에서 계속 사용합니다

Microsoft가 Surveys 에이전트의 종료 일정을 갱신했습니다. 2026년 9월 21일 수정된 Message Center 공지 MC1421920에 따르면, Microsoft 365 Copilot에서 사용하던 별도 Surveys 에이전트 대신 Microsoft Forms 안에서 Copilot을 이용하는 방식으로 전환합니다. 이 글의 날짜는 공지 피드의 발행 시각을 한국 시간으로 환산한 9월 22일입니다.

이번 변경은 기존 설문을 삭제하는 조치가 아닙니다. 에이전트에서 만든 양식은 Forms에서 계속 열 수 있고, 과거 에이전트 대화 기록도 Microsoft 365 Copilot에 남습니다. 사내 안내에서는 **에이전트 접근 종료와 설문 데이터 보존을 구분**해 설명하는 것이 중요합니다.

---

## 신규 사용자와 기존 사용자의 일정이 다릅니다

| 구분 | 공지에 명시된 일정 | 의미 |
|---|---|---|
| 신규 사용자 | 2026년 8월 31일부터 | Agent Store에서 Surveys 에이전트를 새로 사용할 수 없음 |
| 이미 에이전트를 추가한 사용자 | 2026년 12월 말까지 접근 종료 예정 | 기존 Surveys 에이전트 대신 Forms로 전환 |

8월 31일은 모든 기존 사용자의 접근이 동시에 끝난 날짜가 아니라, 신규 사용자를 위한 제공이 중단된 날짜입니다. 기존 사용자의 접근 종료 시점은 9월 21일 수정 공지에서 안내한 12월 말까지의 일정으로 구분해야 합니다.

원문은 서비스 종료와 전환을 다루는 공지입니다. 새로운 프리뷰나 GA 출시 발표로 해석해서는 안 됩니다.

## 설문 작성·수집·분석은 Forms로 통합됩니다

Microsoft는 설문 작성, 응답 수집, 분석을 Microsoft Forms의 Copilot 환경에 모으겠다고 설명합니다. 기존 Surveys 에이전트에 접근하면 Forms로 안내되며, 설문 관련 Copilot 기능은 Forms의 **dynamic action button**을 통해 계속 제공됩니다.

![기존 Surveys 에이전트 사용자를 위한 홈 화면과 Forms 전환 안내](/mwkorea/assets/images/2026-09-22-SurveysAgentRetirementFormsCopilot/image1.png)

사내 설문을 만드는 직원에게는 별도 에이전트를 다시 설치하도록 안내하기보다 Forms를 시작점으로 안내하는 편이 맞습니다. 다만 이 공지에는 모든 기능의 일대일 대응표나 구체적인 화면별 사용 절차가 제시되어 있지는 않습니다.

## 기존 양식과 대화 기록은 어디서 확인하나요?

두 가지 자료의 확인 위치가 다릅니다.

| 기존 자료 | 전환 후 확인 위치 |
|---|---|
| Surveys 에이전트로 만든 양식 | Microsoft Forms |
| Surveys 에이전트와 나눈 과거 대화 | Microsoft 365 Copilot의 대화 기록 |

![기존 Surveys 에이전트 사용자의 채팅 화면](/mwkorea/assets/images/2026-09-22-SurveysAgentRetirementFormsCopilot/image2.png)

예를 들어 사내 교육 만족도 설문을 에이전트로 만들었다면, 양식을 다시 만들기 전에 Forms에서 기존 양식을 찾으면 됩니다. 설문을 만들 때 어떤 요청을 했는지 살펴보려면 Copilot의 과거 대화 기록을 확인합니다. 대화 기록을 볼 수 있다는 설명이 종료된 에이전트에서 새 작업을 계속 실행할 수 있다는 뜻은 아닙니다.

## 관리자 설정이나 라이선스 변경은 필요하지 않습니다

이번 전환 공지는 라이선스나 권한을 변경할 필요가 없으며, 새로운 환경이 기본으로 활성화되어 별도 관리자 구성이 필요하지 않다고 안내합니다. 적용 대상은 현재 Microsoft 365 Copilot에서 Surveys 에이전트를 사용하는 사용자이고, 관련 서비스는 Microsoft 365 Copilot과 웹용 Microsoft Forms입니다.

이는 **이번 전환 때문에 추가 라이선스를 마련할 필요가 없다는 설명**입니다. 모든 Forms 사용자에게 모든 Copilot 기능이 무료로 제공된다는 포괄적인 과금 정책 발표는 아닙니다.

## 사내 안내에서 바꿀 내용

기술적인 필수 조치는 없지만, 사용자가 갑자기 다른 서비스로 이동한다고 느끼지 않도록 안내를 정리할 필요는 있습니다. 원문도 사용자 공지, 내부 문서 수정, 헬프데스크 준비를 권고합니다.

1. Agent Store에서 Surveys 에이전트를 추가하도록 설명한 가이드를 Forms 중심으로 수정합니다.
2. 기존 사용자의 접근은 2026년 12월 말까지 종료될 예정임을 안내합니다.
3. 양식은 Forms에, 과거 대화는 Copilot에 남는다는 내용을 FAQ에 반영합니다.
4. 헬프데스크가 Forms 리디렉션과 자료 확인 위치에 관한 질문에 답할 수 있도록 준비합니다.

원문은 별도의 컴플라이언스 고려사항을 식별하지 않았다고 적고 있습니다. 조직별 검토가 불필요하다고 단정한 것은 아니므로, 기존 설문에 적용하던 내부 데이터 관리 기준은 그대로 참고해야 합니다.
