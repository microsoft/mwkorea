# Copilot 에이전트, 얼마나 쓰고 있나요? Agent Dashboard 데이터 내보내기로 살펴보기

에이전트를 배포한 뒤에는 “몇 개를 만들었는가”만큼 “지속적으로 사용하고 있는가”가 중요합니다. 조직별 활용 추세와 크레딧 사용량을 함께 살펴봐야 추가 교육이나 라이선스 운영의 방향을 잡을 수 있기 때문입니다.

Microsoft는 Viva Insights 웹 앱의 **Agent Dashboard에서 비식별화된 Copilot 에이전트 사용 데이터를 내보내는 기능**을 예고했습니다. 대시보드에서 확인한 내용을 내려받아 조직의 도입·활용 분석에 사용할 수 있도록 하는 변화입니다.

이번 글은 **2026년 9월 29일 일정이 수정된 MC1288531 공지**를 기준으로 정리합니다. 공지의 한국 시간 발행일은 9월 30일이며, 정식 출시가 이미 끝났다는 의미는 아닙니다.

---

## 무엇을 내보낼 수 있나요?

내보내기 대상은 **사용자·주 단위로 집계한 에이전트 지표와 에이전트 속성**입니다. 조회 범위는 **최대 지난 6개월**이며, 결과에서 사용자 식별자는 제거됩니다.

| 데이터 구분 | 공지에 제시된 내용 |
|---|---|
| 에이전트 메타데이터 | 에이전트 이름, 작성자 유형, 게시 출처 |
| 에이전트 사용 지표 | 생성된 응답 수 등 |
| 크레딧·지속 사용 지표 | 에이전트 크레딧 사용량, 사용자 유지 지표 |
| 사람 관련 메타데이터 | 조직, 직무 유형 등 |

데이터는 여러 테이블로 제공됩니다. 사용자 단위 집계가 있다는 설명을 실명별 사용 내역 제공으로 해석하면 안 됩니다. **사용자 식별자를 제거한 데이터**라는 점이 전제입니다.

![Viva Insights Agent Dashboard 화면](/mwkorea/assets/images/2026-09-30-CopilotAgentDashboardDataExport/image1.png)

## 최소 50개 라이선스와 전사 접근 권한이 필요합니다

이 기능은 **Microsoft 365 Copilot 라이선스가 최소 50개인 조직**을 대상으로 하며, Viva Insights 웹 앱에 적용됩니다. 라이선스 조건을 충족하더라도 모든 사용자가 내보낼 수 있는 것은 아닙니다.

공지에서 지정한 대상은 Agent Dashboard의 **전사 데이터 접근 권한을 가진 사용자**입니다. Microsoft Entra ID 데이터로 식별되는 고위 리더, 관리자가 전사 접근 권한을 부여한 사용자, 전사 접근 권한을 가진 대리인, 전역 분석가와 관리자 등이 포함됩니다.

반면 **자신의 팀 데이터만 볼 수 있는 그룹 관리자에게는 제공되지 않습니다.** 도입 담당자는 라이선스 수뿐 아니라 실제 대시보드 접근 범위도 함께 확인해야 합니다.

## 출시 일정: 프리뷰와 정식 출시를 구분하세요

| 단계 | 공지에 기재된 일정 |
|---|---|
| Public Preview | 2026년 5월 말 시작, 6월 초 완료 예상 |
| Worldwide 정식 출시(GA) | 2026년 10월 말 시작, 11월 초 완료 예상 |

9월 29일 업데이트에서는 GA 일정이 **기존 9월 말~10월 초에서 10월 말~11월 초로 변경**됐습니다. 위 프리뷰 일정 역시 공지에 적힌 배포 계획이며, 이 글에서 개별 테넌트의 배포 완료 여부를 확인한 것은 아닙니다.

## 기본 활성화 기능, 관리자는 어떻게 통제하나요?

기능은 **자격을 갖춘 사용자에게 기본적으로 켜집니다.** 별도의 활성화 작업은 필요하지 않으며, 실제로 내보내기를 사용하는 경우 외에는 사용자 업무 흐름에 영향이 없다고 안내합니다.

관리자는 **Viva Feature Access Management(VFAM)**에서 테넌트 또는 그룹 단위로 기능을 관리하거나 끌 수 있습니다. 지정할 모듈은 **Viva Insights**, 기능은 **Agent Metrics Export**입니다.

국내 도입 담당자는 배포 전에 전사 접근 권한 보유자를 점검하고, 내보낸 데이터를 누가 어디에 보관할지 정해 두는 편이 좋습니다. 이는 별도 제품 요구사항이 아니라 운영 관점의 권고입니다. 비식별화된 결과라도 조직·직무 메타데이터가 포함되므로 내부 데이터 취급 기준에 맞춰 검토해야 합니다.

## 도입 후에는 어떤 질문에 활용할 수 있을까요?

이 데이터는 에이전트 도입 추세를 분석하고 라이선스 운영과 AI 전환 전략을 검토하는 데 사용할 수 있습니다. 예를 들어 조직별 사용 추세와 지속 사용 지표를 살펴보면 추가 안내가 필요한 영역을 찾는 데 도움이 됩니다.

다만 **응답 수나 크레딧 사용량 자체가 업무 성과를 증명하지는 않습니다.** 업무별 시간 절감, 결과 품질, 사용자 피드백과 함께 해석하는 것이 좋습니다. 공지는 새로운 내보내기 기능을 설명하는 것이지, 그러한 성과 측정을 자동으로 보장하는 것은 아닙니다.

## 마무리

Agent Dashboard 내보내기는 에이전트 운영을 화면 조회에서 데이터 기반 분석으로 확장하는 변화입니다. 최소 라이선스 조건, 전사 접근 권한, 기본 활성화 정책을 먼저 확인하고 실제 테넌트 제공 여부에 맞춰 적용을 준비하세요.
