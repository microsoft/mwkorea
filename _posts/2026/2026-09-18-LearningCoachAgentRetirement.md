# M365 Copilot 'Learning Coach Agent' 단종 공지 — 'Learning Agent'로 전환

Microsoft 365 Copilot의 **Learning Coach Agent**가 단종 수순에 들어갑니다. 후속 에이전트인 **Learning Agent**로의 전환이 2026년 10월부터 시작됩니다.

---

## 일정

- **2026년 10월**: Learning Coach Agent에서 Learning Agent로의 전환 시작
- **2026년 12월 말**: Learning Coach Agent **완전 단종**
- **2027년 초**: 사용자 접근 및 관리자 관리 화면에서도 완전히 제거

## 사용자가 해야 할 일

**사용자는 단종 전까지 반드시 Learning Agent로 전환해야 합니다.** 전환하지 않으면 2026년 12월 말 이후 더 이상 Learning Coach Agent를 사용할 수 없습니다.

## 관리자 조치

사용자에게 전환 일정과 필요성을 안내하는 커뮤니케이션을 준비하는 것이 권장됩니다.

## 한국 조직을 위한 체크포인트

사내에서 Learning Coach Agent를 학습·역량 개발 용도로 활용해온 부서(HR, 교육팀 등)가 있다면, 10월 전환 시작 전에 미리 사용자 공지를 준비해두는 것이 좋습니다. 특히 12월 말이라는 명확한 단종 시한이 있는 만큼, 자동 전환을 기다리기보다 사용자가 먼저 Learning Agent에 익숙해지도록 유도하는 것이 혼란을 줄이는 방법입니다.
