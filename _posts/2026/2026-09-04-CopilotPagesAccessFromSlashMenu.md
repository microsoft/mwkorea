# Copilot 채팅의 슬래시 메뉴에서 기존 Pages를 바로 참조합니다

Copilot Pages를 다시 대화에 활용할 때 기존 문서를 어디에서 찾고, 새 문서는 어디에서 만들어야 하는지가 더 분명해집니다. 기존 Page는 채팅 입력창의 `/` 메뉴에서 찾아 참조하고, 새 Page는 Edit in Pages 메뉴에서 만들게 됩니다.

이번 변경은 Pages의 저장 방식이나 권한 모델을 바꾸는 기능이 아닙니다. 기존 콘텐츠를 채팅에 연결하는 경로와 대화에서 새 Page를 만드는 경로를 나눠 자주 쓰는 흐름을 단순하게 정리한 사용자 경험 업데이트입니다.

---

## 기존 Page는 Library와 슬래시 메뉴에서

사용자는 Library 탭에서 기존 Pages에 접근할 수 있습니다. Copilot 채팅 중에는 프롬프트 입력 상자에서 `/` 메뉴를 열어 기존 Page를 선택하고 현재 대화의 참조 자료로 추가할 수 있습니다.

질문을 작성하다가 같은 입력 흐름 안에서 Page를 불러올 수 있기 때문에 별도 메뉴를 오가며 링크를 찾는 단계를 줄일 수 있습니다. 어떤 Page가 목록에 보이는지는 기존 접근 및 공유 권한의 범위를 따릅니다.

## Edit in Pages는 새 Page 생성에 집중

**Edit in Pages** 메뉴는 Copilot 대화 옆에서 새 Page를 만드는 역할에 집중합니다. 이미 존재하는 Page를 참조하는 일과 새 Page를 만드는 일을 서로 다른 진입점으로 구분한 것입니다.

따라서 메뉴 역할이 바뀌더라도 기존 Page가 이동하거나 삭제되는 것은 아닙니다. 사용자는 기존 Page를 `/` 메뉴로 대화에 넣고, 현재 대화 결과를 새 작업 공간으로 발전시키고 싶을 때 Edit in Pages를 사용할 수 있습니다.

## 콘텐츠와 권한은 그대로 유지됩니다

이번 업데이트로 기존 Pages의 내용이나 공유 권한은 바뀌지 않습니다. Page를 채팅에 추가하는 새 방법이 생긴 것이지, 사용자가 원래 열 수 없던 Page까지 검색하거나 참조할 수 있게 되는 것은 아닙니다.

조직에서는 짧은 사용자 안내만으로도 메뉴 변경에 따른 혼선을 줄일 수 있습니다. 특히 이전 Edit in Pages 위치에서 기존 Page를 찾던 사용자에게 Library와 `/` 메뉴라는 새 경로를 알려 주는 것이 유용합니다.

## 일정과 적용 방식

원문 설명은 2026년 9월부터 사용자가 Library와 `/` 메뉴로 기존 Pages에 접근한다고 안내합니다. 배포 표에는 전 세계 일반 공급을 **2026년 8월 말 시작, 9월 초 완료 예정**으로 적고 있습니다.

| 구분 | 내용 |
|---|---|
| 일반 공급 | 2026년 8월 말 시작, 9월 초 완료 예정 |
| 적용 방식 | 배포 도달 시 자동 제공 |
| 관리자 작업 | 없음 |
| 기존 Page와 권한 | 영향 없음 |

조직별 실제 화면 반영 시점에는 차이가 있을 수 있습니다. 별도 구성은 필요하지 않으며 사용자가 새 메뉴 역할을 이해할 수 있도록 내부 도움말이나 교육 자료의 화면 경로를 갱신하면 됩니다.
