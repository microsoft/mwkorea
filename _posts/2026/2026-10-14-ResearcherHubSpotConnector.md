# Researcher 에이전트, HubSpot 커넥터로 외부 CRM 정보까지 활용한다

Microsoft 365 로드맵에 **Microsoft Copilot (Microsoft 365): User can use Hubspot Connector in Researcher** 항목이 등록되었습니다. Researcher 에이전트를 쓰는 사용자가 HubSpot의 서드파티 정보를 활용해, 생성되는 응답을 관련 정보로 더 풍부하게 만들 수 있습니다.

영업·마케팅 데이터를 HubSpot에서 관리하는 조직이라면, Microsoft 365 안의 문서·메일과 CRM 정보를 함께 엮은 리서치 결과를 기대할 수 있습니다.

---

## 핵심 내용

- 대상: Microsoft 365 Copilot의 **Researcher** 에이전트
- 방식: **HubSpot 커넥터**로 외부 정보를 가져와 응답을 보강
- GA: 2025년 11월 (로드맵 표기)

## 도입 체크포인트

- 커넥터 사용 가능 여부와 관리자 허용 설정은 테넌트 정책에 따라 다를 수 있으므로 관리 센터에서 확인하세요.
- 외부 서비스 데이터를 응답에 반영하므로, 데이터 접근 범위와 인증 방식을 사전에 점검하는 것이 좋습니다.
- 로드맵에는 세부 설정 절차가 없으므로 공식 문서를 함께 확인하세요.
