# Microsoft Edge Copilot, 새 아이콘과 Voice·Vision으로 간결해진다

Microsoft Edge의 Copilot 경험이 2026년 10월 중순 새 모습으로 바뀝니다. Edge 안의 모든 Copilot 진입점에 업데이트된 아이콘이 적용되고, 사이드 패널은 더 단순한 UX를 사용합니다.

기능 측면에서는 **Copilot Voice**와 **Copilot Vision**이 강화됩니다. Microsoft는 이번 UI·기능 변경에도 기존 보안, 개인정보 보호, 규정 준수, 엔터프라이즈 관리 통제가 유지된다고 설명합니다.

![Microsoft Edge의 업데이트된 Copilot 진입점](/mwkorea/assets/images/2026-10-01-EdgeCopilotUpdatedExperience/image1.png)

---

## 달라지는 경험

- Edge의 모든 Copilot 진입점에 새 아이콘 적용
- Copilot 사이드 패널 UX 단순화
- Copilot Voice 기능 강화
- Copilot Vision 기능 강화

Copilot이 Edge에서 활성화된 모든 사용자는 변경된 경험을 자동으로 보게 됩니다. 관리자가 배포 전에 별도 작업을 수행할 필요는 없습니다.

![Microsoft Edge Copilot의 단순화된 사이드 패널](/mwkorea/assets/images/2026-10-01-EdgeCopilotUpdatedExperience/image2.png)

## 관리자가 확인할 내용

기존 정책은 계속 사용할 수 있고 보안·규정 준수·개인정보 보호 통제도 변경되지 않습니다. 다만 사용자가 아이콘과 화면 변화로 혼란을 겪지 않도록 사내 가이드와 스크린샷을 업데이트하는 것이 좋습니다.

Copilot URL 리디렉션과 관련해서는 `copilot.cloud.microsoft` 연결 허용을 안내한 Message Center 항목 **MC1462915**도 함께 확인해야 합니다. 네트워크 제한 환경에서는 새 UI보다 먼저 연결 정책이 실제 접근을 막지 않는지 점검하는 것이 중요합니다.

이번 기능은 Microsoft 365 콘텐츠, 프롬프트 또는 서비스 데이터를 사용하는 AI/Copilot 경험에 영향을 줍니다. 기존 관리 정책이 유지되더라도 조직의 Edge Copilot 활성화 상태와 사용자 범위를 다시 확인하는 것이 좋습니다.

## 일정
