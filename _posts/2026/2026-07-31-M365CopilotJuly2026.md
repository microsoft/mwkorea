# Microsoft 365 Copilot 2026년 7월 업데이트 총정리

![Microsoft 365 Copilot July 2026](/mwkorea/assets/images/2026-07-31-M365CopilotJuly2026/image1.png)

매달 발행되는 *What's New in Microsoft 365 Copilot*의 2026년 7월호가 공개되었습니다. 이번 달은 **모델 라인업 확대**와 **Cowork의 실행 능력 강화**, 그리고 **관리자 통제·리포팅 기능 정비**가 세 축입니다.

특히 눈에 띄는 것은 Copilot이 "답변하는 도구"에서 "일을 대신 실행하는 도구"로 이동하는 흐름이 이번 달 업데이트 전반에 걸쳐 뚜렷하다는 점입니다. Edge 브라우저를 직접 조작하고, 메일과 Teams를 감시하다가 조건이 맞으면 알아서 움직이고, 사용자가 만든 스킬을 조직에 공유하는 기능들이 한꺼번에 등장했습니다.

관리자 쪽도 마찬가지입니다. 에이전트가 늘어나는 만큼 **누가 무엇을 얼마나 쓰는지 보는 대시보드**와 **AI 비용을 통제하는 장치**가 함께 강화되었습니다. 아래에서 사용자 기능과 IT 관리자 기능으로 나눠 정리합니다.

---

## 사용자 기능

### Copilot Chat에서 에이전트 직접 호출

이제 **Word, Excel, PowerPoint 에이전트를 Copilot Chat 프롬프트에 직접 추가**할 수 있습니다. Copilot을 연 뒤 에이전트를 `@`로 멘션하면 대화에 합류합니다.

![Copilot Chat에서 @word로 Word 에이전트 호출](/mwkorea/assets/images/2026-07-31-M365CopilotJuly2026/image2.png)

Copilot 앱을 떠나지 않고 문서·스프레드시트·프레젠테이션을 만들 수 있다는 뜻입니다. **7월 롤아웃 완료.**

### 모델 업데이트: GPT-5.6과 Claude Sonnet 5

**OpenAI의 GPT-5.6 제품군**이 Microsoft 365 Copilot에서 사용 가능해졌습니다. Microsoft 365의 지식 근로(knowledge work)에 최적화된 모델로, 복잡한 다단계 작업에서 더 강한 추론 능력을 제공합니다.

![Microsoft 365 Copilot의 GPT-5.6](/mwkorea/assets/images/2026-07-31-M365CopilotJuly2026/image3.png)

원문이 든 예시는 다음과 같습니다.

- Word에서 초기 아이디어를 다듬어진 초안으로
- Excel에서 더 깊은 분석 추론
- PowerPoint에서 더 풍부한 프레젠테이션 생성
- Chat에서 더 명확한 응답
- Cowork에서 엔드투엔드 산출물 완수

**Anthropic의 Claude Sonnet 5**도 함께 제공됩니다. 에이전틱한 다단계 작업을 위해 설계된 모델로, **Copilot in PowerPoint, Word, Cowork**에서 사용할 수 있습니다. Work IQ와 결합해 파일·회의·채팅·업무 데이터에 근거한 결과를 제공합니다. 둘 다 **7월 롤아웃 완료.**

> 모델 선택지가 늘어난다는 것은 "어떤 작업에 어떤 모델을 쓸 것인가"를 조직이 판단해야 한다는 뜻이기도 합니다. 사내 가이드에 작업 유형별 권장 모델을 한 줄씩 정리해 두면 사용자 혼란을 줄일 수 있습니다.

### Copilot Search 응답 개선과 모바일 푸시 알림

**Copilot Search 모듈의 Copilot 답변**이 더 간결해졌고, 사이드바의 Copilot Chat에서 대화를 이어 갈 수 있다는 안내가 더 눈에 띄게 표시됩니다.

![Copilot Search의 개선된 Copilot 답변](/mwkorea/assets/images/2026-07-31-M365CopilotJuly2026/image4.png)

**Microsoft 365 Copilot 모바일 앱의 푸시 알림**도 새로 추가되었습니다. iOS·Android에서 'Your Day at a Glance', 'Items waiting for you' 같은 프롬프트를 푸시로 받고, 알림을 열면 **해당 프롬프트의 응답이 이미 화면에 표시된 상태**로 Copilot 모바일 앱이 열립니다. Outlook·Teams 등을 일일이 확인할 필요가 줄어듭니다.

![Copilot 모바일 앱 푸시 알림](/mwkorea/assets/images/2026-07-31-M365CopilotJuly2026/image5.png)

**Microsoft 365 Copilot 라이선스 보유자 전용** 기능입니다. **7월 롤아웃 완료.**

## Cowork: 실행 능력이 크게 확장되다

이번 달 업데이트에서 가장 변화 폭이 큰 영역입니다.

### Claude Fable 5 추가

**Anthropic의 Claude Fable 5**가 Copilot Cowork에 추가되었습니다. Anthropic은 이 모델을 "야심 차고 장기적으로 실행되는 프로젝트를 위해 만들어졌다"고 설명하며, 지속적인 추론, 더 깊은 컨텍스트 처리, 다단계 작업에 걸친 **계획·실행·검증** 능력을 강조합니다.

Cowork에서는 더 큰 끈기와 깊이가 필요한 에이전틱 작업에 대한 또 하나의 선택지가 됩니다. **기본값은 꺼짐(off by default)**이며 7월에 롤아웃되었습니다.

### Microsoft Edge 로컬 브라우저 자동화

**Cowork가 Edge 브라우저를 직접 조작**할 수 있게 되었습니다. Edge에 로그인한 사용자는 Cowork를 통해 SaaS 도구, 사내 포털 등 하루 종일 사용하는 웹 기반 시스템을 넘나들며 작업할 수 있습니다.

![Cowork의 Edge 로컬 브라우저 자동화](/mwkorea/assets/images/2026-07-31-M365CopilotJuly2026/image6.png)

Cowork가 사용자를 대신해 웹사이트를 오가며 동작하므로, 탭을 수동으로 전환하는 시간이 줄어듭니다. **7월 롤아웃 완료.**

### 이벤트 트리거 작업

받은 편지함을 계속 새로고침하거나 놓친 멘션을 걱정할 필요가 없어집니다. **Cowork에게 메일과 Teams를 감시하도록 요청**하면 중요한 순간이 발생하는 즉시 포착하고, 사용자가 요청하기 전에 응답을 준비해 둡니다.

![Cowork 이벤트 트리거 작업](/mwkorea/assets/images/2026-07-31-M365CopilotJuly2026/image7.png)

트리거로 지정할 수 있는 조건은 다음과 같습니다.

| 트리거 유형 | 예시 |
|-------------|------|
| 발신자 | 특정 인물이 보낸 메일 |
| @멘션 | 나를 언급한 메시지 |
| 키워드·주제 | 특정 단어나 주제가 등장할 때 |
| 이벤트 이름 | 지정한 회의·일정 |

트리거를 **평이한 자연어로 설명하기만 하면** Teams 채팅·채널, Outlook 메일, 회의 전반에서 실행됩니다. **7월에 Frontier 대상으로 롤아웃**되었습니다.

### 스킬과 플러그인으로 커스터마이징

**Customize 탭**에서 Cowork를 직접 확장할 수 있게 되었습니다.

![Cowork 스킬·플러그인 커스터마이징](/mwkorea/assets/images/2026-07-31-M365CopilotJuly2026/image8.png)

- **스킬 추가**: 가이드형 'Create new' 플로우를 쓰거나, 기존 `.md` / `.zip` / `.skill` 파일을 드래그 앤 드롭해 'Upload skill'
- **플러그인**: 동일한 방식이며, **Claude 또는 Open-Plugin zip이 게시 가능한 패키지로 자동 변환**됩니다. 번들 스킬과 MCP 커넥터가 포함됩니다.
- **공유**: 조직 내 특정 인원에게 스킬·플러그인을 공유하되 **소유권은 본인이 유지**하므로, 수정 사항이 자동으로 전파됩니다.

수동 설정 부담이 줄고 공유가 쉬워진다는 점에서, 사내에 잘 만든 스킬을 확산시키기 좋은 구조입니다. **7월 롤아웃 완료.**

## Copilot Notebooks: 참조 파일 형식 확대

Copilot Notebooks가 **Markdown(.md), TXT(.txt), RTF(.rtf) 파일을 노트북 참조로 지원**합니다.

![Copilot Notebooks의 확장된 참조 지원](/mwkorea/assets/images/2026-07-31-M365CopilotJuly2026/image9.jpg)

소프트웨어 문서, 영상 전사본, 서식 있는 메모 같은 콘텐츠를 노트북에 직접 추가하고 Copilot으로 프로젝트 산출물로 전환할 수 있습니다.

- **TXT·RTF**: 7월 롤아웃 완료
- **Markdown**: **8월 롤아웃 예정**

## Word: 검토 워크플로와 작성 워크플로

### 검토 워크플로 (Review workflows)

**변경 내용 추적(Track Changes)을 켠 상태로** Copilot이 문서를 편집합니다. 제안된 수정 사항이 투명하게 보이고 검토하기 쉬워집니다. 기본적으로 변경 사항이 표시되므로 모든 편집을 확인하고 승인할 수 있습니다.

또한 Copilot에게 **댓글 추가·읽기·답글·관리**를 요청할 수 있어, 피드백을 해당 내용에 연결된 상태로 정리할 수 있습니다. **6월 롤아웃 완료.**

Copilot이 **목차를 삽입하고 업데이트**할 수 있게 되었습니다. 문서가 변화해도 구성이 유지됩니다. 머리글, 바닥글, 페이지 번호, 날짜, 각주 관리도 지원해 수작업 없이 정돈된 문서를 유지할 수 있습니다.

## Excel: 새 스킬과 Power BI 컨텍스트

### 브랜드 키트 스킬

**brand kit 스킬**로 Copilot in Excel이 **Microsoft 365 브랜드 센터의 조직 Brand Kit**을 적용해 통합 문서 서식을 지정합니다. 승인된 색상·글꼴·로고가 표와 차트에 자동 적용되어 회사 브랜딩 가이드라인을 따릅니다.

![Excel 브랜드 키트 스킬](/mwkorea/assets/images/2026-07-31-M365CopilotJuly2026/image11.png)

**7월 롤아웃 완료.**

### 테마 디자인 스킬

**theme design 스킬**은 조화로운 색상 팔레트 선택, 차트 스타일링, 레이아웃 구조화를 통해 데이터에 일관된 디자인 테마를 적용합니다. `@theme-design` 스킬을 호출해 시트를 디자인하거나 다듬어 달라고 요청하면, 명확한 시각적 위계를 갖춘 서식이 적용됩니다.

![Excel 테마 디자인 스킬](/mwkorea/assets/images/2026-07-31-M365CopilotJuly2026/image12.png)

**8월 롤아웃 예정.**

### Power BI 데이터 기반 분석

Copilot in Excel이 **거버넌스가 적용된 Power BI 데이터에 근거해 분석**할 수 있습니다. 업무 콘텐츠 선택기에서 Power BI 보고서를 첨부한 뒤, 성과 분석·추세 파악·요약이나 보조 계산 생성을 요청할 수 있습니다.

핵심은 **행 수준 보안(row-level security)을 그대로 준수**한다는 점입니다. 데이터를 내보내거나 수치를 수동으로 복사·대조하거나 Power BI와 Excel을 오갈 필요가 없어집니다. **8월 롤아웃 예정.**

### AutoSave 꺼진 통합 문서에서도 사용 가능

Copilot in Excel이 **AutoSave가 꺼진 Windows·Mac 파일을 포함해 더 많은 클라우드 저장 통합 문서**에서 동작합니다. 기존에는 AutoSave가 켜져 있어야 했습니다.

AutoSave가 꺼져 있고 저장하지 않은 변경 사항이 있으면, Excel이 Copilot이 변경을 시작하기 전에 AutoSave를 켜라고 알려 줍니다. 다만 사용자는 AutoSave를 켜지 않고 계속 진행하는 것도 선택할 수 있습니다. **8월 롤아웃 중.**

## PowerPoint: 브랜드 자산, 사용자 정의 스킬, 그리고 댓글

### 회사 브랜드 자산 활용

Microsoft 365 Brand kit의 **로고·아이콘·테마·글꼴을 Copilot in PowerPoint에서 직접 사용**할 수 있습니다. 브랜드 관리자가 선호하는 브랜드 키트를 안전하게 업데이트·배포해 회사 자산 전반의 디자인 일관성을 유지합니다. **7월 롤아웃 완료.**

### 사용자 정의 스킬

**Custom user skills**가 Copilot in PowerPoint에 도입됩니다. 사용자가 **OneDrive에서 자신만의 스킬을 만들고 업로드하고 업데이트**할 수 있습니다. 반복되는 지시를 재사용 가능한 가이드로 바꿔, 프레젠테이션 작업 흐름 안에서 Copilot이 적용하도록 하는 개념입니다.

### 댓글 작성·답글·해결, 그리고 작업 할당

Copilot in PowerPoint가 프레젠테이션 안에서 **댓글을 작성하고, 답글을 달고, 해결**할 수 있습니다. 컨텍스트를 전환하지 않고 새 댓글 초안 작성, 기존 피드백 응답, 완료된 댓글 스레드 해결이 가능합니다. **7월 롤아웃 완료.**

여기에 더해, 곧 **댓글 안에서 작업을 할당하고 관련 이해관계자에게 알림**을 보낼 수 있게 됩니다. 피드백을 후속 작업으로 전환하고 적절한 사람을 댓글 스레드로 불러오는 것이 가능합니다. **8월 롤아웃 예정.**

### iOS 모바일·iPad 기능 강화

세 가지가 추가되었습니다.

1. **다단계 작업 계획** — 생성, 편집, 분석 같은 작업을 계획해 수행
2. **그라운딩 확장** — 현재 슬라이드 기반의 암묵적 그라운딩, 첨부 파일 기반의 명시적 그라운딩
3. **백그라운드 실행** — Copilot이 작업하는 동안 계속 일하거나 앱을 전환 가능

![PowerPoint iOS 모바일 기능](/mwkorea/assets/images/2026-07-31-M365CopilotJuly2026/image14.png)

**7월 롤아웃 완료.**

### 참조 프레젠테이션으로 새 덱 만들기·리스타일

**다른 프레젠테이션을 참조 삼아** 새 덱을 만들거나 기존 덱의 스타일을 바꿀 수 있습니다. PowerPoint 파일을 첨부하거나 덱을 연 뒤, 참조 덱의 시각적 스타일로 만들어 달라고 요청하면 됩니다.

![참조 덱으로 프레젠테이션 생성](/mwkorea/assets/images/2026-07-31-M365CopilotJuly2026/image15.png)

Copilot이 참조 덱의 **레이아웃·테마·시각 시스템**을 적용합니다. 검증된 디자인 재사용, 브랜드 가이드라인 정렬, 기존 프레젠테이션 톤앤매너 맞추기를 수동 재서식 없이 할 수 있습니다. **6월 롤아웃 완료.**

## IT 관리자 기능

### 웹 그라운딩 도메인 제외

조직이 **최대 1,000개 도메인을 Copilot 웹 그라운딩 결과에서 제외**할 수 있습니다. 지정한 웹사이트의 콘텐츠가 Copilot 웹 검색에 사용되는 것을 제한해, 원치 않거나 규정에 맞지 않는 소스의 영향을 줄입니다. **7월 롤아웃 완료.**

> 이 기능의 상세한 설정 절차와 PowerShell 스크립트 사용법은 [별도 글](/mwkorea/copilot/CopilotDomainExclusion/)에서 자세히 다뤘습니다.

### 외부 메일 참조를 막는 DLP

**Microsoft Purview DLP**가 Microsoft 365 Copilot과 Copilot Chat으로 확장되어, **외부 발신자의 메시지가 요약·참조되거나 그라운딩 데이터로 사용되는 것을 차단**할 수 있습니다.

![외부 메일 참조 제한 DLP](/mwkorea/assets/images/2026-07-31-M365CopilotJuly2026/image20.png)

**6월 퍼블릭 프리뷰 롤아웃 완료.**

### Agent 365 대시보드

Insights의 **Agent 365 대시보드**가 비즈니스 리더에게 팀의 에이전트 사용·도입 현황을 보여 줍니다. 분석가는 조직 필터링을 통해 전사 리포팅에도 활용할 수 있습니다.

![Agent 365 대시보드](/mwkorea/assets/images/2026-07-31-M365CopilotJuly2026/image21.png)

제공하는 정보는 다음과 같습니다.

- **그룹별 도입 현황**과 **유지율(retention)** 추적
- **상위 에이전트** 식별
- **사용 추세 비교**를 통한 배포 전략·최적화 판단
- 개별 에이전트로 **드릴다운**
- **Copilot Studio 에이전트의 과거 리포팅**도 같은 대시보드의 토글로 제공

Agent 365의 데이터를 통합해 서로 다른 소스와 에이전트 유형에 걸친 가시성을 제공합니다. **7월 롤아웃 완료.**

### Copilot 커넥터 사용 리포트

Microsoft 365 관리 센터에 **Copilot Connectors usage report**가 퍼블릭 프리뷰로 추가되었습니다. Copilot Chat, Copilot Search, 에이전트 전반의 응답이 조직에 배포된 커넥터 콘텐츠에 얼마나 자주 근거하는지 보여 줍니다.

![Copilot 커넥터 사용 리포트](/mwkorea/assets/images/2026-07-31-M365CopilotJuly2026/image22.png)

커넥터 도입률, 참여도, 사용 패턴, 커넥터별 영향을 파악해 **어떤 데이터 소스가 실제로 가치를 만드는지** 판단할 수 있습니다. **6월 롤아웃 완료.**

### GCC·GCC High·DoD용 Copilot Chat 사용 리포트

정부 클라우드 고객도 Microsoft 365 관리 센터에서 **Copilot Chat 사용 리포트**를 볼 수 있게 되었습니다.

![GCC용 Copilot Chat 사용 리포트](/mwkorea/assets/images/2026-07-31-M365CopilotJuly2026/image23.png)

포함되는 항목은 총 활성 사용자 수, **Microsoft 365 앱별로 구분된 Copilot Chat 사용량**, 사용자 수준 활동 인사이트(**기본 익명 처리**)입니다. **7월 롤아웃 완료.**

### 비용 관리 개선

사용량 기반 과금 서비스의 지출 통제가 개선되었습니다. Cowork와 Work IQ API 같은 서비스의 **AI 소비 비용**을 관리하는 데 직접적으로 영향을 주는 변경입니다.

![Microsoft 365 관리 센터 비용 관리](/mwkorea/assets/images/2026-07-31-M365CopilotJuly2026/image24.png)

주요 내용은 다음 세 가지입니다.

- **지출 알림 개선** — 소비가 정책 임계값에 근접할 때 더 안정적으로 알립니다. ⚠️ **기존 지출 정책에서 알림이 필요한 경우, 관리자가 알림을 다시 생성해야 합니다.**
- **명확해진 지출 정책 로직** — 여러 지출 정책의 적용을 받는 사용자는 **사용자당 한도가 가장 높은 정책에 남습니다.** 한도에 도달해도 다른 정책으로 이동하지 않습니다.
- **초과분 처리** — 작업 도중 지출 정책 한도에 도달한 사용자는 **해당 작업을 끝까지 완료**할 수 있으며, 이때 발생한 초과분은 **과금되지 않고 비용 관리 리포트의 크레딧 소비에도 나타나지 않습니다.**

**7월 롤아웃 완료.**

## 마무리

7월 업데이트를 관통하는 흐름은 명확합니다. **Copilot이 "물어보면 답하는" 단계를 넘어 "조건이 맞으면 스스로 움직이는" 단계로 이동**하고 있습니다. Cowork의 브라우저 자동화와 이벤트 트리거가 그 상징이고, Agent 365 대시보드와 Access 히트맵은 그런 실행이 늘어날 때 필요한 관측 장치입니다.

모델 선택지도, 확장 방법(스킬·플러그인·커넥터)도, 통제 수단(DLP·도메인 제외·지출 정책)도 함께 늘었습니다. 도입 담당자 입장에서는 **"무엇을 켤 것인가"만큼이나 "무엇을 어떻게 관측하고 통제할 것인가"**를 설계할 시점입니다.

8월 롤아웃 예정 항목(Excel 테마 디자인·Power BI 그라운딩, PowerPoint 사용자 정의 스킬·댓글 작업 할당, Notebooks Markdown 지원)도 미리 확인해 두시면 좋겠습니다.
