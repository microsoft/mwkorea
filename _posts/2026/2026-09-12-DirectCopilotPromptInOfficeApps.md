# Word·Excel·PowerPoint의 Copilot 버튼에서 바로 요청을 입력합니다

Microsoft 365 앱에서 Copilot을 사용하려면 별도의 창을 연 뒤 현재 작업을 다시 설명해야 하는 경우가 있습니다. Microsoft는 Word, Excel, PowerPoint의 Copilot 버튼에 프롬프트 입력란을 직접 추가해, 사용자가 문서 흐름을 유지한 채 필요한 작업을 바로 요청할 수 있도록 합니다.

콘텐츠를 선택했을 때는 선택 영역을 바탕으로 문맥에 맞는 프롬프트 경험도 제공됩니다. 새 기능을 별도로 찾아 이동하기보다 작업 중인 위치에서 생성, 편집, 후속 작업을 시작하게 만드는 변화입니다.

---

## Copilot 진입점이 작업 표면으로 이동

새 입력란은 Copilot 버튼을 단순한 패널 열기 기능에서 즉시 요청을 시작하는 진입점으로 바꿉니다. 사용자는 Word 문서, Excel 통합 문서, PowerPoint 프레젠테이션 안에서 무엇이 필요한지 곧바로 입력할 수 있습니다.

선택한 콘텐츠가 있을 때는 해당 선택 영역과 연결된 문맥형 프롬프트 경험을 사용할 수 있습니다. 이 방식은 요청에 필요한 배경을 다시 입력하는 부담을 줄이고, 현재 보고 있는 내용에 대한 생성과 편집을 더 빠르게 시작하도록 돕습니다.

![Microsoft 365 앱의 Copilot 버튼 프롬프트 입력 경험](/mwkorea/assets/images/2026-09-12-DirectCopilotPromptInOfficeApps/image1.png)

## 지원 앱과 플랫폼

대상은 Microsoft 365 Copilot을 사용할 자격이 있는 Microsoft 365 사용자입니다. 지원 범위는 다음과 같습니다.

- 앱: Word, Excel, PowerPoint
- 데스크톱: Windows, macOS
- 브라우저: 웹

플랫폼별 배포 시점은 서로 다를 수 있습니다. 같은 조직 안에서도 앱과 운영체제에 따라 새 입력란이 보이는 시점이 달라질 수 있으므로, 헬프 데스크에서는 단일 날짜를 기준으로 장애로 판단하지 않는 것이 좋습니다.

![선택한 콘텐츠에서 사용하는 문맥형 Copilot 경험](/mwkorea/assets/images/2026-09-12-DirectCopilotPromptInOfficeApps/image2.png)

## 출시 일정

전 세계 일반 공급은 2026년 9월 시작해 12월 말 완료될 예정입니다. 약 4개월에 걸친 단계적 배포이며 Word, Excel, PowerPoint의 Windows, macOS, 웹 버전에 순차적으로 적용될 수 있습니다.

따라서 사용자 교육 자료를 한 번에 교체하기보다 플랫폼별 화면을 확인하면서 갱신하는 접근이 현실적입니다. 일부 사용자가 먼저 기능을 보고 다른 사용자는 기존 버튼을 계속 보더라도 배포 기간 중에는 정상적인 차이일 수 있습니다.

## 관리자 제어와 규정 준수

필수 관리자 조치는 없습니다. 이번 업데이트는 새로운 생성형 AI 상호 작용 진입점을 추가하지만, 기존 Copilot 기능을 호출하는 방식을 확장하는 변화입니다.

공지에 따르면 기존 관리자 제어는 **Pin Microsoft 365 Copilot Chat** 설정을 통해 계속 사용할 수 있습니다. 새로운 입력란이 등장한다고 해서 조직의 라이선스나 접근 정책을 우회하는 것은 아닙니다. 다만 사용자가 생성형 AI를 시작할 수 있는 지점이 문서 표면 가까이 늘어나므로, 조직의 사용 지침과 데이터 취급 교육에는 이를 반영해야 합니다.

## 조직이 준비할 내용

관리자는 기능 활성화보다 채택과 지원에 집중하면 됩니다.

1. Word, Excel, PowerPoint에서 Copilot을 시작하는 위치가 바뀐다는 점을 안내합니다.
2. 선택 콘텐츠가 요청 문맥으로 사용될 수 있음을 교육합니다.
3. 플랫폼별로 배포 시점이 다를 수 있다는 내용을 헬프 데스크에 공유합니다.
4. 기존 Pin Microsoft 365 Copilot Chat 설정과 라이선스 구성을 확인합니다.
5. 사내 프롬프트 가이드와 스크린샷을 새 진입점에 맞게 갱신합니다.

사용자에게는 긴 프롬프트 예시만 제공하기보다 “대상을 선택하고 목적과 결과 형식을 짧게 요청하는” 작업형 예제를 제공하는 편이 새 UI의 장점을 살리는 데 도움이 됩니다. 결과 검토와 민감 정보 취급 같은 기존 책임 있는 AI 원칙은 진입점이 간편해져도 그대로 적용됩니다.
