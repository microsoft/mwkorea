# Copilot 라이선스 없이도 달라지는 검색: Microsoft 365 앱의 새 검색 경험

Microsoft 365 Copilot 앱을 사용하는 모든 사람이 Microsoft 365 Copilot 라이선스를 가진 것은 아닙니다. 일반 Microsoft 365 사용자는 앱에서 필요한 파일을 찾고 검색 결과를 탐색하는 업무도 수행합니다.

MC1562275는 **Microsoft 365 라이선스가 있지만 Microsoft 365 Copilot 라이선스는 없는 사용자**를 위한 검색 인터페이스 업데이트를 안내합니다. 공지의 발행 시각은 한국 시간으로 2026년 11월 21일이며, 새 검색은 11월 말부터 순차 배포될 예정입니다. 이는 유료 Copilot의 모든 AI 기능을 무료로 제공한다는 발표가 아니라, 해당 사용자군의 검색 경험을 개선하는 변경입니다.

---

## 무엇이 달라지나요?

새 인터페이스는 검색 결과를 찾고, 조건을 조정하고, 결과 사이를 이동하기 위한 현대적인 검색 컨트롤을 제공합니다. 기존처럼 키워드로 파일을 찾는 기능을 유지하면서 결과 탐색 경험을 개선하는 방향입니다.

조직이 연결된 콘텐츠 소스를 구성했다면 **지원되는 타사 콘텐츠**도 검색할 수 있습니다. 다만 이 공지를 모든 외부 서비스가 자동으로 연결된다는 뜻으로 해석해서는 안 됩니다. 조직의 연결 소스 구성과 지원 범위가 전제입니다.

검색 결과에는 계속해서 **사용자에게 접근 권한이 있는 콘텐츠만** 표시됩니다. 검색 화면의 변화가 새로운 파일 접근 권한을 부여하는 것은 아닙니다.

## 기본 활성화, 기존 검색으로 전환 가능

Standard release 테넌트에서는 업데이트된 검색 경험이 기본으로 활성화됩니다. 사용자는 검색 결과 페이지의 토글을 이용해 기존의 classic search 경험으로 돌아갈 수 있습니다.

![새 검색 경험에서 기존 검색으로 전환하는 옵션](/mwkorea/assets/images/2026-11-21-CopilotAppSearchWithoutLicense/image1.png)

조직의 안내 문서에는 새 화면 설명뿐 아니라 **기존 검색으로 돌아가는 방법**도 함께 담는 것이 좋습니다. 익숙한 인터페이스가 바뀌었을 때 헬프데스크가 빠르게 안내할 수 있기 때문입니다.

## 배포 일정

| 배포 구분 | 전 세계 배포 계획 |
|---|---|
| General Availability | 2026년 11월 말 시작, 12월 중순 완료 예상 |
| Deferred Release | 2026년 12월 말 시작, 2027년 1월 중순 완료 예상 |

날짜는 공지 시점의 예상 배포 기간입니다. 조직의 배포 구분에 따라 사용자에게 새 화면이 나타나는 시기가 다를 수 있습니다.

## 한국 조직의 준비 포인트

먼저 사용자 안내에서 **Microsoft 365 라이선스와 Microsoft 365 Copilot 라이선스의 차이**를 명확히 하세요. 이번 변경의 대상과 제공 기능을 구분해야 “Copilot 앱이 바뀌었으니 유료 AI 기능도 사용할 수 있다”는 오해를 줄일 수 있습니다.

헬프데스크에는 새 검색 컨트롤과 classic search 전환 방법을 공유하는 것이 원문의 권장 사항입니다. 연결된 타사 콘텐츠를 사용한다면, 검색 대상이 되는 소스와 권한 구성도 함께 확인하는 것이 실무적으로 도움이 됩니다.

원문은 별도의 규정 준수 고려 사항을 식별하지 않았다고 설명하면서도 조직에 맞는 검토를 권장합니다. 이를 조직의 자체 보안 검토가 불필요하다는 의미로 받아들이지는 않아야 합니다.

## 마무리

이번 업데이트의 가치는 Copilot 라이선스가 없는 직원도 일상적인 정보 검색을 더 편하게 수행할 수 있다는 데 있습니다. **사용자 권한을 유지하면서 검색 인터페이스를 개선하고, 기존 경험으로 돌아갈 선택지도 제공한다**는 점을 중심으로 안내하면 좋겠습니다.
