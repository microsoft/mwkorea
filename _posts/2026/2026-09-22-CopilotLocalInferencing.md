# Copilot의 AI 추론은 어디서 실행될까? Local inferencing 로드맵 읽기

기업에서 Copilot을 도입할 때는 답변 품질만큼이나 **업무 데이터가 어느 지역에서 처리되는지**가 중요한 검토 항목입니다. 특히 여러 국가에 사업장을 운영하는 조직이라면 데이터 저장 위치와 함께 AI가 요청을 처리하는 위치도 구분해 살펴야 합니다.

Microsoft 365 Roadmap의 **571886, Microsoft Copilot (Microsoft 365): Local inferencing**은 이 질문과 관련된 기능을 예고합니다. 지원되는 Copilot 상호작용의 AI 추론을 해당 지역 안에서 수행하도록 해, 조직의 주권 관련 통제 범위를 넓히겠다는 내용입니다.

다만 이번 소식은 **로드맵에 등록된 계획**입니다. 아래 내용은 수집한 원문 기준이며, 이미 모든 테넌트에서 사용할 수 있는 기능으로 이해하면 안 됩니다.

---

## 새로운 점: 저장 위치가 아니라 추론 실행 위치

원문에서 설명하는 *inferencing*은 AI 모델이 프롬프트를 실행해 결과나 응답을 만드는 처리 단계입니다. Local inferencing은 **지원 대상 상호작용에서 이 처리가 수행되는 지리적 범위**를 다룹니다.

따라서 기능 이름의 “Local”을 사용자 PC에서 모델을 실행한다거나, 인터넷 연결 없이 Copilot을 사용한다는 뜻으로 읽어서는 안 됩니다. 이번 공지의 설명은 **해당 지역 내 AI 추론**에 관한 것이며, 온디바이스 실행이나 오프라인 지원을 발표한 내용이 아닙니다.

또한 “지원되는 Copilot 상호작용”이라는 범위 제한이 있습니다. 모든 Copilot 기능, 모든 모델, 모든 에이전트의 외부 도구 호출까지 동일한 지역에 한정된다고 확대 해석할 근거는 없습니다.

## 최초 대상 국가와 일정

| 항목 | 원문에서 확인되는 내용 |
|---|---|
| 로드맵 ID | 571886 |
| 기능 | Microsoft Copilot (Microsoft 365): Local inferencing |
| 최초 출시 대상 | 호주, 인도, 아랍에미리트, 영국, 미국 |
| GA 목표 | 2026년 12월 |
| 기대 효과 | AI 추론 위치에 대한 통제를 강화해 주권 및 지역별 요구사항 대응 지원 |

**한국은 이번 공지의 최초 출시 대상 국가에 포함되어 있지 않습니다.** 한국 소재 조직에서의 제공 여부나 국내 추론 지원 일정을 이 공지만으로 판단할 수는 없습니다.

해외 법인이 위 국가에 있다는 사실만으로 적용을 확정해서도 안 됩니다. 어떤 테넌트와 워크로드가 대상인지, 별도 설정이나 라이선스 조건이 있는지는 후속 안내를 확인해야 합니다.

## 도입 담당자가 확인할 체크포인트

다음은 원문이 확정한 추가 기능이 아니라, 이번 로드맵을 검토할 때 조직에서 확인해 볼 질문입니다.

1. **지원 범위**: 어떤 Copilot 상호작용과 모델이 Local inferencing 대상인지 확인합니다. 현재 사용하는 기능 전체가 포함된다고 가정하지 않습니다.
2. **지역 적용 조건**: 테넌트 위치, 사용자 위치, 계약 조건 중 무엇을 기준으로 적용 지역이 정해지는지 확인합니다. 이번 공지는 세부 판정 기준을 설명하지 않습니다.
3. **다른 데이터 처리와의 경계**: 추론 위치에 관한 통제가 데이터 저장, 로그 보관, 외부 커넥터 및 에이전트 도구 호출에 어떤 관계를 갖는지 별도로 검토합니다.
4. **운영과 규정 준수**: 관리자가 설정하거나 확인할 방법, 적용 상태를 입증할 자료, 조직의 규정 준수 요구사항을 충족하는지 검토합니다. 지역 내 추론만으로 모든 규제 준수가 자동 보장되는 것은 아닙니다.

원문에는 가격, 상세 라이선스, 관리자 설정 절차, 개별 앱별 지원 목록이 제시되어 있지 않습니다. 아직 공개되지 않은 내용을 전제로 배포 일정을 확정하기보다는 GA 안내에서 실제 적용 조건을 확인하는 편이 안전합니다.

## 마무리

이번 로드맵의 핵심은 **“AI가 무엇을 답하는가”뿐 아니라 “AI가 어디서 처리하는가”에 대한 통제를 확대한다**는 점입니다. 데이터 주권을 중요하게 다루는 조직이라면 후속 발표를 추적할 만한 변화입니다.

한국 기업은 국내 제공 여부를 단정하지 말고, 우선 최초 대상 국가의 해외 사업장과 현재 Copilot 사용 범위를 연결해 검토 질문을 정리해 두면 좋겠습니다.
