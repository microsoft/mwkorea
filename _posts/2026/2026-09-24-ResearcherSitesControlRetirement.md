# Microsoft 365 Copilot Researcher, 'Sites' 컨트롤 단종 — 프롬프트 내 지정으로 대체

Microsoft 365 Copilot **Researcher**(Frontier 사용자 대상)에서 특정 웹사이트를 지정해 검색하던 **Sites 컨트롤**이 단종됩니다.

---

## 무엇이 바뀌나

- **Sites 컨트롤**이 **2026년 9월 말까지** 단종됩니다.
- 사용자는 여전히 **프롬프트에 직접 선호 웹사이트를 명시**해 검색 범위를 지정할 수 있습니다.
- 기존 웹 검색 제어(web search controls)는 변경 없이 그대로 유지됩니다.

## 조치 사항

관리자의 별도 조치나 새 설정은 필요하지 않습니다. 다만 Microsoft는 사용자에게 변경 사항을 안내하고 관련 문서를 업데이트할 것을 권장합니다.

## 한국 사용자를 위한 체크포인트

Researcher에서 특정 사이트(예: 사내 지식베이스, 특정 뉴스 매체)만 검색하도록 Sites 컨트롤을 활용해온 사용자라면, 앞으로는 프롬프트 문장 안에 직접 "example.com 사이트에서 찾아줘"와 같이 명시하는 방식으로 전환해야 합니다. UI 컨트롤이 사라지는 것이지 기능 자체가 없어지는 것은 아니므로, 사용 방법 안내만 미리 공지하면 큰 혼란 없이 전환할 수 있습니다.
