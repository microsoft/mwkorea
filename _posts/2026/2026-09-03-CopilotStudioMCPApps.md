# 대화 안에 표와 드릴다운이 뜹니다: Copilot Studio의 MCP Apps

에이전트의 답변이 텍스트로만 끝나면 사용자는 데이터를 확인하거나 조작하기 위해 결국 다른 앱으로 이동해야 합니다. 표를 정렬하고 상세 항목을 내려가며 살펴보는 작업은 채팅만으로 처리하기 어렵기 때문입니다.

메시지 센터 공지 **RM570433**에 따르면 Copilot Studio 에이전트가 **MCP Apps**를 사용해 풍부한 인터랙티브 UI를 대화 안에 직접 렌더링할 수 있게 됩니다.

---

## MCP Apps란

MCP Apps는 **Model Context Protocol(MCP)의 확장**입니다. 에이전트가 호환되는 MCP 서버의 UI 지원 도구를 호출하면, 단순 텍스트 대신 인터랙티브 경험이 대화 안에 나타납니다.

공지에 나온 예시는 다음과 같습니다.

- **정렬 가능한 표(sortable tables)**
- **드릴다운(drilldowns)**

사용자는 채팅이나 도구를 벗어나지 않고 데이터를 탐색하고 작업할 수 있습니다.

---

## 작동 조건

필요한 것은 **호환되는 MCP 서버**입니다.

1. 메이커가 규격을 준수하는 MCP 서버를 연결합니다.
2. 에이전트가 그 서버의 **UI 지원 도구**를 호출합니다.
3. 호환되는 채널에서는 인터랙티브 UI가 대화 안에 렌더링됩니다.

별도의 화면을 새로 설계하는 것이 아니라, MCP 서버 연결을 통해 UI 경험을 제공한다는 것이 핵심입니다.

---

## UI를 지원하지 않는 곳에서는

모든 채널이 같은 UI 기능을 지원하는 것은 아닙니다. 이를 위해 **일반 텍스트 대체(plain-text fallback)** 가 제공됩니다.

| 채널 능력 | 결과 |
|---|---|
| MCP Apps UI 렌더링 지원 | 인터랙티브 UI 표시 |
| UI 렌더링 미지원 | 일반 텍스트로 대체 |

따라서 UI 기능이 없는 표면에서도 에이전트 자체는 계속 동작합니다. 한 채널을 위해 만든 에이전트가 다른 채널에서 완전히 실패하는 상황을 줄입니다.

---

## 왜 의미가 있나요

### 답변에서 행동으로

표를 보여 주는 데 그치지 않고 정렬하거나 상세 항목을 탐색할 수 있어, 사용자가 **정보 확인과 후속 작업을 같은 대화에서** 이어 갈 수 있습니다.

### 앱 전환 감소

채팅에서 결과를 받고 원본 업무 앱으로 이동해 다시 찾는 단계를 줄입니다.

### 채널 호환성

일반 텍스트 대체가 있어 여러 배포 표면을 고려한 에이전트를 만들기 쉽습니다.

### 표준 기반 확장

Model Context Protocol 확장 위에서 동작하므로, 특정한 독자 UI 체계보다 MCP 생태계를 통해 경험을 확장하는 방향입니다.

---

## 활용 시나리오

- 영업 데이터를 정렬 가능한 표로 보여 주고 고객별 상세 내역 탐색
- 지원 티켓 목록을 표시하고 우선순위·상태별 드릴다운
- 재고 현황에서 제품군별 합계를 보고 개별 품목으로 이동
- 규정 준수 결과를 요약한 뒤 위반 항목의 근거 확인

## 메이커·도입 담당자를 위한 체크포인트

- **MCP 서버의 규격 준수 여부**를 먼저 확인하세요. UI 지원 도구를 제공하는 호환 서버가 전제입니다.
- **텍스트 대체 결과도 시험**하세요. 주요 채널에서 UI가 보이더라도 미지원 표면의 텍스트 응답이 충분히 이해 가능한지 확인해야 합니다.
- **UI와 권한을 함께 설계**하세요. 인터랙티브 화면에서 사용자가 실행할 수 있는 행동도 원본 시스템 권한을 넘어서는 안 됩니다.
- **접근성을 검증**하세요. 정렬·드릴다운 기능이 키보드와 보조 기술에서도 사용 가능한지 확인하세요.
- **과도한 UI를 피하세요**. 간단한 답변까지 모두 앱처럼 만들기보다 탐색과 행동이 실제로 필요한 시나리오에 적용하는 것이 좋습니다.
- **내부 MCP 서버 운영 책임**을 정하세요. 서버의 가용성, 버전, 보안, 장애 대응이 에이전트 경험에 직접 영향을 줍니다.

---

## 마무리

MCP Apps는 에이전트의 대화를 **답변 창에서 업무 화면으로** 확장합니다. 정렬 가능한 표와 드릴다운을 채팅 안에서 사용하고, 지원하지 않는 채널에서는 텍스트로 안전하게 돌아갑니다.

미리 보기는 2026년 10월, 정식 출시는 11월 예정입니다.
