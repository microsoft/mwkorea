# 에이전트 5천만 개 시대의 다음 과제: Agent 365 9월 업데이트

![Agent 365 9월 업데이트](/mwkorea/assets/images/2026-09-30-Agent365SeptemberUpdate/image1.png)

2026년 5월 출시 이후 수만 개 조직에서 **5천만 개에 가까운 에이전트**가 등록됐습니다. 에이전트 도입 속도가 빨라지면서 IT·보안 팀의 고민도 바뀌고 있습니다. 단순한 가시성·거버넌스를 넘어, **어떤 에이전트가 실제 가치를 내는지, 자원이 어디에 쓰이는지, 커지는 에이전트 자산을 어떻게 규모 있게 최적화할지**가 새로운 과제로 떠올랐습니다.

TechCommunity Agent 365 Blog가 공개한 이번 달 업데이트는 **AI 워크로드와 비즈니스 성과 연결, 에이전트 자산 전반의 가시성·통제 강화, 에이전트·도구·런타임에 걸친 거버넌스 중앙화**라는 세 축으로 이 과제를 다룹니다.

이번 글은 해당 원문을 기준으로 정리하며, 자세한 내용은 원문을 참조하시기 바랍니다.

---

## AI 워크로드를 비즈니스 가치와 연결하기

에이전트·애플리케이션·서비스 전반에서 AI 사용량이 늘어나면서, 조직은 **사용량을 한곳에서 관리하고 접근 권한을 비즈니스 필요에 맞추는** 체계가 필요해졌습니다. Agent 365의 **Cost management**는 사용량 기반 AI 지출을 관리하는 FinOps 기능으로, Microsoft 클라우드 구독에 포함되어 제공됩니다.

### 더 많은 사용량 기반 과금 워크로드를 한곳에서 관리

Cost management는 Copilot Cowork와 Work IQ를 넘어 **Code**와 **Copilot Managed Runtime**까지 지원 범위를 넓혔습니다. **Microsoft Copilot Studio**로 만든 에이전트 지원은 10월로 예정돼 있으며, 더 많은 AI 워크로드가 뒤따를 예정입니다. 이로써 Agent 365는 사용량 기반 과금을 관리하는 중심 창구가 됩니다.

![사용량 기반 과금 워크로드 관리](/mwkorea/assets/images/2026-09-30-Agent365SeptemberUpdate/image2.png)

### 모델 선택을 업무 필요에 맞추기

Cost management에서 지출 정책을 설정할 때, 관리자는 그룹별로 업무에 맞는 **모델과 성능(effort) 수준**에 대한 접근 권한을 다르게 부여할 수 있습니다. 이 정책은 Cowork에서 **Auto**가 선택할 수 있는 모델에도 영향을 미쳐, 영향도가 높은 프로젝트와 파워 유저에게는 고급 모델을, 나머지에는 더 효율적인 옵션을 제공할 수 있습니다. 현재 Cowork 대상으로 출시 중이며 추가 워크로드도 계획돼 있습니다.

![모델 선택을 업무 필요에 맞추는 지출 정책](/mwkorea/assets/images/2026-09-30-Agent365SeptemberUpdate/image3.png)

### 사용량을 Cowork 가치와 연결하기

Insights의 **Consumption Dashboard**는 Copilot Cowork 사용량을 성과와 연결합니다. 활성 사용자, 크레딧, 작업 건수의 추세를 보여주고, 업무를 작업 카테고리별로 정리하며, Cowork가 지원한 가치를 **시간과 금액**으로 추정합니다.

리더는 가치를 창출하는 작업과 그에 소비된 크레딧을 비교해, 도입을 확대할지, 사용성을 개선할지, 투자를 재배치할지 판단할 수 있습니다.

![Cowork 사용량과 가치를 연결하는 Consumption Dashboard](/mwkorea/assets/images/2026-09-30-Agent365SeptemberUpdate/image4.png)

## 에이전트 자산 전반의 가시성과 통제 강화

플랫폼마다 에이전트 자산이 커지면서, IT는 **완전한 인벤토리**와 조치가 필요한 지점을 더 빠르게 찾는 방법이 필요합니다. Agent 365는 Microsoft 네이티브 에이전트와 서드파티 에이전트를 하나의 레지스트리로 모은 뒤, 지능형 검색과 자동화된 거버넌스로 그 가시성을 실행으로 연결합니다.

### AI 모드로 주의가 필요한 에이전트 찾기

레지스트리가 커질수록 올바른 에이전트를 찾는 데 복잡한 필터를 만들 필요는 없어야 합니다. **공개 프리뷰로 제공되는 AI 모드**는 Agent 365 레지스트리를 정적인 탐색 환경에서 지능형 검색 환경으로 바꿉니다. 관리자는 자연어 프롬프트로 소유자가 없는 에이전트를 찾거나, 비활성 에이전트를 위치시키거나, 면밀한 검토가 필요한 에이전트를 드러내는 등 맥락적 속성을 활용해 에이전트를 찾고 필터링하고 탐색할 수 있습니다. 이는 인사이트 도출 시간을 줄이고, 레지스트리 데이터를 실질적인 거버넌스 워크플로로 바꾸는 데 도움이 됩니다.

![AI 모드를 사용한 지능형 에이전트 검색](/mwkorea/assets/images/2026-09-30-Agent365SeptemberUpdate/image5.gif)

### 자동화 규칙으로 일관성·효율성·확장성 확보

**공개 프리뷰로 제공되는 Agent Management Rules**는 관리자가 대규모로 에이전트 거버넌스를 자동화할 수 있는 강력한 방법을 제공합니다. Microsoft 365 관리 센터에서 관리자는 지정한 조건이 충족되면 에이전트를 차단하거나, 게시 요청을 거부하거나, 정책 템플릿을 적용하는 등의 동작을 자동으로 실행하는 커스텀 규칙을 만들 수 있습니다. 규칙은 소유권 상태, 에이전트 태그, Microsoft Entra Agent ID, 게시자, 위험 신호, 사용 활동 등 점점 늘어나는 기준을 바탕으로 할 수 있습니다. 이를 통해 조직은 수동 관리를 줄이고, 거버넌스를 일관되게 적용하며, 에이전트 도입이 늘어나는 와중에도 인벤토리를 안전하고 규정에 맞게 잘 관리된 상태로 유지할 수 있습니다.

![자동화된 Agent Management Rules](/mwkorea/assets/images/2026-09-30-Agent365SeptemberUpdate/image6.gif)

## 에이전트·도구·런타임에 걸친 거버넌스 중앙화

에이전트가 더 많은 도구·데이터·서비스에 접근하게 되면서, 조직은 전체 에이전트 생태계에 걸쳐 일관된 통제가 필요합니다. Agent 365는 에이전트·도구·런타임 환경에 걸친 거버넌스를 중앙화해, IT가 파편화된 관리 감독을 줄이고, 정책을 일관되게 적용하며, 도입이 늘어나는 와중에도 기업 자원을 보호하도록 돕습니다.

### 한곳에서 MCP 서버·플러그인·스킬·커넥터 제어

**정식 출시(GA)된 Tools management**는 중앙화된 거버넌스 경험을 MCP 서버를 넘어 **플러그인, 스킬, 커넥터**까지 확장합니다. 플러그인은 재사용 가능한 작업과 통합을, 스킬은 특화된 AI 기능과 워크플로를, 커넥터는 기업·서드파티 데이터와 서비스에 대한 안전한 접근을 제공합니다.

관리자는 하나의 관리 화면에서 연결된 도구를 찾고, 핵심 메타데이터와 사용량을 검토하며, MCP 서버·플러그인·스킬·커넥터 전반에 테넌트 전체 허용·차단 제어를 적용할 수 있습니다. 이 일관된 프레임워크는 여러 시스템에 걸쳐 도구를 따로 관리해야 하는 부담을 줄이고, 에이전트 접근을 승인된 조직 경계 안에 유지하도록 돕습니다. **Power Platform 커넥터 거버넌스는 진행 중**입니다.

![한곳에서 관리하는 MCP 서버·플러그인·스킬·커넥터](/mwkorea/assets/images/2026-09-30-Agent365SeptemberUpdate/image7.gif)

### 커스텀 MCP 서버를 승인 경로에 올리기

조직은 자체 MCP 서버도 IT의 명시적 관리 감독 아래 둘 수 있습니다. **2026년 9월 공개 프리뷰**로, 개발자는 Agent 365 CLI를 통해 커스텀 MCP 서버를 등록하고, 에이전트가 호출하기 전에 관리자 검토를 위해 제출할 수 있습니다. Microsoft 365 관리 센터에서 관리자는 서버 설명, 게시자, 요청자, 엔드포인트, 기능을 확인한 뒤 요청을 승인하거나 거부할 수 있습니다.

이를 통해 확장에서 승인까지 명확한 경로가 만들어집니다. 고객과 파트너는 업무에 필요한 커스텀·서드파티 MCP 서버를 추가할 수 있고, IT는 Microsoft 365 테넌트에서 동작하는 에이전트 전반에 걸친 가시성과 통제를 유지할 수 있습니다.

### 기업 AI 거버넌스와 런타임 정책 집행 연결

**9월 30일부터** Microsoft Agent 365와 **Azure API Management**의 통합이 순차적으로 롤아웃을 시작하며, 중앙화된 AI 거버넌스와 런타임 정책 집행을 연결합니다. 에이전트, 도구, 모델, MCP 서버를 포함해 Azure API Management에 온보딩된 AI 자산은 Agent 365에서 자동으로 검색되어, 가시성을 높이고 수동 온보딩 부담을 줄입니다. 관리자는 Agent 365를 통해 중앙에서 접근을 관리하고, Azure API Management는 에이전트가 동작할 때 인증·라우팅·런타임 제어를 적용해 AI 트래픽과 기업 자산을 보호합니다.

## 에이전트 성장을 비즈니스 임팩트로 전환하기

조직은 AI 도입의 새로운 국면에 들어서고 있습니다. 성공의 척도는 더 이상 배포된 에이전트 수가 아니라, **그 에이전트들이 얼마나 효과적으로 추적·관리되고 비즈니스 성과에 연결되는가**입니다.

이번 Agent 365 업데이트는 조직이 AI 가치를 이해하고, 커지는 에이전트 자산에 대한 가시성을 더 깊이 확보하며, 거버넌스를 대규모로 적용할 수 있도록 돕습니다. 이를 통해 IT·보안 팀은 에이전트 성장을 측정 가능한 비즈니스 임팩트로 자신 있게 전환할 수 있습니다.
