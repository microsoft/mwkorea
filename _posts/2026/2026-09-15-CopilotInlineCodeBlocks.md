# Copilot 코드·차트·다이어그램, 별도 캔버스 없이 대화 안에서 확인

Copilot이 만든 코드를 확인하거나 차트를 보려면 대화와 별도 캔버스를 오가야 했습니다. Microsoft는 **Code blocks의 인라인 미리보기**를 통해 지원되는 콘텐츠를 대화 흐름 안에 표시하는 경험을 도입합니다.

2026년 9월 14일자 MC1472029의 초점은 새로운 개발 실행 환경이 아니라, 생성한 결과를 확인하고 수정하는 인터페이스 개선입니다. 한국의 메이커와 업무 사용자에게는 “요청과 결과를 한곳에서 비교한다”는 변화로 이해하면 쉽습니다.

---

## 무엇이 바뀌나요?

기존에는 코드 콘텐츠를 별도의 나란히 배치된 코드 캔버스에서 미리 보았습니다. 업데이트 후에는 지원되는 코드 블록이 **Copilot 대화 안에서 직접 렌더링**됩니다.

공지의 예시에는 코드, 차트, 다이어그램 및 유사한 시각적 출력이 포함됩니다. 지원되는 콘텐츠를 보고 상호작용하는 흐름을 유지하면서, 별도 캔버스를 여는 전환을 줄입니다.

## 지원 범위를 과장하지 않기

원문은 “지원되는 콘텐츠”라고 명시합니다. 따라서 모든 프로그래밍 언어를 실행한다거나, 임의 코드를 안전하게 배포하거나, 모든 시각화 형식을 동일하게 처리한다고 단정해서는 안 됩니다.

기존 Copilot 작업 흐름과 프롬프트는 계속 동작하도록 안내되어 있습니다. 이번 변경은 기존 기능을 전면 교체하기보다는, 생성한 콘텐츠와 미리보기를 대화 맥락에 가깝게 배치하는 개선입니다.

## 업무 활용과 교육 자료 업데이트

예를 들어 프로세스 다이어그램을 만들고 수정 요청을 이어가거나, 데이터 설명과 차트를 함께 검토하는 업무에서 화면 이동을 줄일 수 있습니다. 구체적인 결과물의 정확성과 지원 여부는 실제 사용하는 환경에서 확인해야 합니다.

내부 교육 자료에 “옆의 코드 캔버스를 여세요”라는 설명이 있다면 새 화면에 맞춰 수정하는 것이 좋습니다. 개발 결과물은 화면에 잘 표시되는지와 별개로 로직·데이터·보안을 검토해야 합니다.

## 일정과 관리자 조치

| 항목 | 원문 안내 |
|---|---|
| 대상 | Microsoft 365 Copilot 접근 권한이 있는 사용자 |
| 제공 단계 | Worldwide 일반 공급(GA) |
| 배포 계획 | 2026년 9월 중순 시작, 9월 말 완료 예상 |
| 관리자 필수 조치 | 없음 |

위 일정은 공지 시점의 계획입니다. 사용자가 느끼는 변화가 주로 화면과 작업 흐름에 있으므로, 기능 차단 설정을 새로 찾기보다 사용자 안내와 기존 가이드의 화면 설명을 점검하는 것이 우선입니다.
