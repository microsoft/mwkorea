# Teams의 Copilot 경험이 대화 중심 디자인으로 개편됩니다

Teams에서 사용하는 Copilot이 Microsoft 365 Copilot 앱과 일관된 대화 중심 경험으로 개편됩니다. 전체 화면에서는 Copilot 작업을 넓게 탐색하고 관리할 수 있고, 측면 창에서는 회의나 채팅 등 현재 Teams 작업의 맥락을 유지한 채 도움을 받을 수 있습니다.

2026년 9월 일반 공급되는 이번 업데이트는 탐색과 채팅 화면을 단순화하고 에이전트 상호 작용, Work IQ 제어, 장기 실행 작업의 가시성을 개선합니다. 서비스 업데이트로 자동 적용되므로 관리자는 배포 설정보다 안내 자료와 지원 체계를 점검해야 합니다.

---

## 새 대화 중심 경험

Teams의 전체 화면 Copilot은 최근 Copilot 앱에 적용된 디자인과 유사해집니다. 탐색 구조를 간결하게 만들고 채팅 레이아웃을 개선해, 사용자가 질문과 결과에 더 집중하도록 구성합니다. 에이전트를 찾고 실행하는 흐름도 정돈되며 Work IQ 제어를 통해 업무 및 웹 기반 정보가 대화에 제시되는 방식을 이해하고 다룰 수 있습니다.

새로운 **Tasks 보기**는 장시간 실행되는 Copilot 활동을 한곳에 보여 줍니다. 에이전트 활동과 예약된 채팅처럼 사용자가 다른 업무를 하는 동안 계속되는 작업을 추적할 수 있어, 결과가 준비됐는지 확인하려고 개별 대화를 반복해서 열 필요가 줄어듭니다.

![Teams의 새 전체 화면 Copilot 경험](/mwkorea/assets/images/2026-09-16-SimplifiedCopilotExperienceInTeams/image1.png)

## 측면 창에서 유지되는 Teams 맥락

Teams 전반에서 열 수 있는 Copilot 측면 창도 새 디자인과 채팅 레이아웃을 사용합니다. 현재 보고 있는 채팅, 채널 또는 회의 흐름을 벗어나지 않고 Copilot과 상호 작용하는 용도에 맞춰져 있습니다.

다만 측면 창에는 Tasks 보기가 없습니다. 장기 실행 에이전트 활동이나 예약 채팅을 확인하려면 전체 화면 경험을 사용해야 합니다. 교육 시에는 “측면 창은 현재 작업의 문맥 지원, 전체 화면은 폭넓은 Copilot 작업과 실행 상태 관리”라는 차이를 중심으로 설명하면 이해하기 쉽습니다.

![Teams의 새 Copilot 측면 창 경험](/mwkorea/assets/images/2026-09-16-SimplifiedCopilotExperienceInTeams/image2.png)

## 라이선스·권한·규정 준수 영향

이번 변경은 2026년 9월 일반 공급되며 기본 활성화됩니다. 사용자가 별도로 기능을 켜거나 관리자가 구성 정책을 배포할 필요가 없습니다. 공지에서는 라이선스, 권한, 기존 규정 준수 제어가 바뀌지 않는다고 명시했습니다.

따라서 새 UI와 에이전트 탐색 기능은 기존에 허용된 접근 범위를 확장하는 것이 아닙니다. 조직이 이미 적용 중인 Copilot 라이선스와 데이터 접근 권한, 규정 준수 정책은 그대로 유지됩니다.

## 도입 전 점검 사항

관리자가 수행할 필수 설정은 없지만 다음 준비가 권장됩니다.

- Teams 사용자에게 시각적 변화와 새 탐색 구조를 미리 알립니다.
- 기존 Copilot 화면을 사용한 사내 교육, 채택 가이드, 헬프 데스크 문서를 업데이트합니다.
- Work IQ가 업무와 웹 기반 정보를 표시하는 방식을 사용자에게 설명합니다.
- 전체 화면에만 Tasks 보기가 있다는 점을 지원 담당자와 공유합니다.

부서별 매뉴얼이나 녹화 교육이 기존 화면에 크게 의존한다면 실제 배포가 도달하는 시점에 맞춰 다시 캡처해야 합니다. 자동 업데이트인 만큼 기능 배포 자체보다 변화 관리와 사용자 커뮤니케이션이 성공적인 도입의 중심입니다.
