# OneNote Android, Copilot 채팅 창에서 페이지 요약과 노트 질의응답 지원

Android 휴대폰에서 긴 OneNote 페이지를 확인하는 사용자는 이제 앱 안에서 Copilot에게 핵심을 정리해 달라고 요청할 수 있습니다. 새 Copilot 채팅 창은 긴 노트를 요약하고 페이지 내용에 관한 질문에 답해, 이동 중 검토 시간을 줄이는 데 초점을 둡니다.

Copilot은 사용자가 원래 열람할 수 있는 OneNote 콘텐츠를 분석합니다. 기존 Microsoft 365 Copilot의 데이터 처리와 권한, 보안 정책은 그대로 적용되며 새 채팅 창이 다른 사용자의 노트나 권한 밖의 콘텐츠를 보여 주는 것은 아닙니다.

---

## Android OneNote에 들어오는 기능

적격 사용자는 Android용 OneNote 모바일 앱에서 **Copilot chat pane**을 사용할 수 있습니다.

![Android용 OneNote의 Copilot 채팅 창](/mwkorea/assets/images/2026-09-03-OneNoteMobileCopilotChatSummaryAndroid/image1.png)

새 화면에서 사용자는 긴 페이지를 간단히 정리하는 **Summary** 기능을 실행하고, 현재 노트의 내용에 관해 자연어로 질문할 수 있습니다.

![Copilot 채팅의 Summary와 노트 질의응답](/mwkorea/assets/images/2026-09-03-OneNoteMobileCopilotChatSummaryAndroid/image2.png)

요약은 페이지의 원문을 대체하는 고정된 문서가 아니라 생성형 AI가 만든 결과입니다. 결정 사항, 날짜, 수치처럼 정확성이 중요한 내용은 원본 OneNote 페이지에서 다시 확인해야 합니다.

## 누가 사용할 수 있나

대상은 **Android용 OneNote**를 사용하는 모든 Microsoft 365 테넌트의 사용자 중 **Microsoft 365 Copilot (Premium) 라이선스**를 보유한 사람입니다. Premium 라이선스가 없는 사용자는 이번 변경의 영향을 받지 않습니다.

메시지에는 최소 Android OS 버전, OneNote 앱 빌드 번호, 태블릿 지원 범위가 명시되어 있지 않습니다. iPhone용 기능도 별도 공지로 배포되므로, Android 일정과 지원 범위를 iOS에 그대로 적용해서는 안 됩니다. 조직은 실제 관리 대상 Android 기기에서 앱 업데이트와 기능 노출 여부를 확인해야 합니다.

## 2026년 9월 2일 변경된 일정

전 세계 일반 공급 일정은 당초 계획보다 늦춰졌습니다.

- **배포 시작:** 2026년 9월 말
- **완료 예상:** 2026년 10월 중순
- 이전 일정: 8월 말 시작, 9월 중순 완료

단계적 배포이므로 9월 말이 되어도 모든 사용자에게 즉시 나타나는 것은 아닙니다. 헬프 데스크는 라이선스가 있어도 10월 중순까지는 기능 도달 차이가 있을 수 있음을 안내해야 합니다.

## 기존 제어가 그대로 적용됩니다

새 채팅 창에는 기존 Microsoft 365 Copilot의 제어, 권한과 정책이 계속 적용됩니다. Copilot은 사용자가 접근할 수 있는 OneNote 데이터로 요약과 답변을 생성합니다. Microsoft는 이번 공지에서 별도의 새 관리자 정책이나 설정을 발표하지 않았습니다.

규정 준수 관점에서는 두 가지 변화가 있습니다. 생성형 AI가 기존 고객 데이터인 OneNote 콘텐츠를 분석하며, 사용자가 모바일 앱 안에서 AI와 대화하는 새 방식이 생깁니다. 조직은 현재의 Copilot 거버넌스와 모바일 기기 사용 정책이 이 시나리오를 충분히 다루는지 검토해야 합니다.

## 배포 전 준비 사항

필수 관리자 조치는 없지만 다음 준비가 권장됩니다.

1. 사용 대상자에게 Premium 라이선스가 정확히 할당되어 있는지 확인합니다.
2. Android 사용자와 헬프 데스크에 채팅 창, Summary와 질의응답 기능을 안내합니다.
3. 기존 Microsoft 365 Copilot의 보안·규정 준수·사용 정책을 모바일 시나리오에 대입해 검토합니다.
4. Android와 iPhone의 Roadmap ID 및 배포 문의를 분리합니다.
5. 요약 결과를 원문과 대조하고 민감한 노트의 기존 공유 권한을 점검하도록 교육합니다.

관리자는 별도 기능을 켤 필요가 없지만, 라이선스가 없는 사용자에게 제공되는 기능으로 오해하지 않도록 해야 합니다. 또한 기능이 아직 보이지 않는 문의에는 앱 버전을 임의로 단정하기보다 순차 배포 기간과 계정 라이선스를 먼저 확인하는 것이 정확합니다.
