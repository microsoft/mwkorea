# Copilot 확장 개발의 다음 단계를 만나다: 첫 Dev Camp Summit 가을 행사

Copilot과 에이전트 개발은 대화 응답을 만드는 것만으로 끝나지 않습니다. 사용자가 결과와 상호작용하는 화면, 에이전트의 구성 방식, 이를 뒷받침하는 인텔리전스 플랫폼까지 함께 이해해야 합니다.

Microsoft 365 Developer Blog는 이 주제를 다룰 첫 **Copilot Dev Camp Summit — Fall Edition**을 안내했습니다. 개발자·메이커·제품 전문가가 만나는 새로운 **분기별 무료 온라인 행사**이며, 첫 회는 2026년 9월 30일 오전 8시 미국 태평양 시각에 열립니다.

원문이 소개하는 커뮤니티의 범위는 Microsoft 365 Copilot, Cowork, GitHub Copilot, Microsoft IQ와 각 확장 생태계입니다. 다만 이번에 공개된 세부 의제는 특히 Copilot UX components, 선언형 에이전트, Microsoft IQ에 초점을 맞춥니다.

---

## 한국에서는 언제 참여하나요?

| 항목 | 안내 |
|---|---|
| 원문 행사 시각 | 2026년 9월 30일 오전 8시 PT |
| 한국 시각 | **2026년 10월 1일 목요일 오전 0시 KST** |
| 방식 | 100% 온라인 |
| 참가비 | 무료 |
| 등록 | [Copilot Dev Camp Summit Fall Edition](https://aka.ms/CopilotDevCamp/Summit) |

9월 30일 미국 태평양 지역에는 일광절약시간인 PDT가 적용되므로, 한국과의 시차는 16시간입니다. 한국 참가자는 **9월 30일 밤에서 10월 1일로 넘어가는 자정**으로 기억하면 됩니다.

원문 본문은 종료 시각이나 녹화본 제공 여부를 명시하지 않습니다. 참여 계획을 세울 때는 등록 페이지에서 추가 안내를 확인하는 것이 좋습니다.

## 어떤 내용을 다루나요?

![Copilot Dev Camp Summit Fall Edition 2026 행사 의제](/mwkorea/assets/images/2026-09-24-CopilotDevCampSummitFall/image1.webp)

### 텍스트를 넘어서는 Copilot UX

**Beyond Text: The New Copilot UX components Experience**에서는 Paolo Pialorsi가 SharePoint Framework와 TypeScript를 활용해 더 풍부하고 상호작용 가능한 Copilot 경험을 만드는 방향을 소개합니다.

이어지는 제품팀 대화에는 **Vesa Juvonen, Bert Jansen, Paolo Pialorsi**가 참여합니다. 개발자 입장에서는 단순 텍스트 응답을 넘어 어떤 사용자 경험을 구성할 수 있는지, 제품팀이 어떤 방향으로 발전시키고 있는지 살펴볼 기회입니다.

### 선언형 에이전트의 현재와 다음 단계

**Declarative Agents Unleashed: What's New and What's Next**는 **Rabia Williams**가 진행합니다. 선언형 에이전트의 새로운 기능과 개발자·메이커에게 앞으로 제공될 방향을 다룹니다.

제품팀 대화에는 **Rachit Malik과 Rabia Williams**가 참여합니다. 새로운 기능 소개와 향후 계획이 함께 다뤄지는 세션이므로, 행사에서 들은 내용을 사내 도입 계획으로 옮길 때는 **현재 제공 기능과 향후 계획을 구분**해 정리하는 것이 좋습니다. 행사 소개 자체가 특정 기능의 GA 발표는 아닙니다.

### 에이전트를 뒷받침하는 Microsoft IQ

**Inside Microsoft IQ: The Intelligence Platform Behind Agents**에서는 **Ayça Baş와 Pamela Fox**가 Microsoft IQ와 차세대 에이전트를 지원하는 인텔리전스 플랫폼을 소개합니다.

이후 **Matt Gotteiner, Pamela Fox, Ayça Baş**가 제품팀 대화를 이어갑니다. 에이전트 구현을 개별 프롬프트나 UI에만 한정하지 않고, 그 기반 플랫폼의 기능과 방향까지 이해하려는 개발자에게 유용한 주제입니다.

행사의 오프닝은 **Barnam Bora와 Paolo Pialorsi**가 맡습니다.

## 참가 전에 질문을 준비해 보세요

이번 행사는 발표를 듣는 것뿐 아니라 제품 전문가에게 질문하고 커뮤니티와 연결되는 기회를 강조합니다. 한국의 에이전트 개발팀이라면 다음처럼 자신의 과제에 맞춰 질문을 준비할 수 있습니다.

- UI 개발 담당자: 현재 텍스트 응답으로 처리하는 업무 중 어떤 부분에 상호작용형 UX가 필요한가?
- 에이전트 메이커: 선언형 에이전트로 구현 중인 시나리오에서 어떤 기능과 제약을 확인해야 하는가?
- 아키텍처 담당자: Microsoft IQ의 역할을 기존 에이전트 설계와 어떻게 연결해 이해해야 하는가?

이 질문들은 참가 준비를 위한 제안이며, 원문이 특정 통합 기능이나 지원 범위를 보장한 것은 아닙니다. 실제로 확인한 기능, 프리뷰 내용, 향후 계획을 따로 기록하면 행사 이후 팀에 공유하기도 쉬워집니다.

## 마무리

첫 Copilot Dev Camp Summit은 **UX·선언형 에이전트·인텔리전스 플랫폼을 함께 살펴보고 제품팀과 직접 대화**할 수 있는 자리입니다. 참석하려면 [등록 페이지](https://aka.ms/CopilotDevCamp/Summit)를 확인하고, 한국 시각으로 **10월 1일 0시**를 일정에 반영하세요.
