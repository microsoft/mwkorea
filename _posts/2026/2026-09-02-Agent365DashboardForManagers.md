# 팀의 에이전트 활용을 한눈에: 관리자용 Agent 365 대시보드

에이전트가 늘어날수록 팀 관리자는 누가 어떤 에이전트를 쓰는지, 일회성 체험에 그치는지 반복 활용으로 이어지는지 알고 싶어집니다. Microsoft는 리더와 대리인에게 제공하는 핵심 Agent 365 가시성을 팀 수준 Copilot Analytics 접근 권한이 있는 관리자에게 확대합니다.

메시지 센터 **MC1431365**에 따르면 관리자는 자신의 기존 조회 범위 안에서 Agent 365와 다른 에이전트의 도입 현황을 볼 수 있습니다. 조직 전체 데이터를 새로 열어 주는 권한이 아니라, Viva Insights에서 이미 허용된 팀 범위를 따릅니다.

---

## 대시보드에 표시되는 지표

관리자용 Agent Dashboard는 에이전트 활동을 한곳에 모아 다음 채택·참여 지표를 제공합니다.

- 활성 에이전트
- 활성 사용자
- 세션
- 재방문 사용자
- 그룹별 사용량

Microsoft 365 Copilot에서 만든 에이전트뿐 아니라 조직에서 사용하는 전체 에이전트 범위의 인사이트도 볼 수 있습니다. 에이전트를 누가 만들었고 어떤 목적으로 만들었는지에 관한 세부 맥락을 함께 제공해, 단순 사용량과 운영 배경을 연결하도록 돕습니다.

## 모든 관리자에게 자동으로 보이는 것은 아닙니다

대상은 **Viva Insights의 Microsoft Copilot Analytics에서 팀 수준 접근 권한이 활성화된 관리자**이며 플랫폼은 웹입니다. Agent 365 데이터가 표시되려면 기존 적격 조건도 충족해야 합니다.

- Agent 365 라이선스 요건 충족
- Microsoft 365 Copilot 라이선스 최소 50개 할당
- 충분한 에이전트 활동 존재
- 최소 그룹 크기 임계값 충족

따라서 대시보드 접근 권한이 있어도 활동량이나 그룹 크기 요건 때문에 일부 인사이트가 표시되지 않을 수 있습니다. 이 제한은 개인 단위 감시가 아니라 집계 인사이트 제공 범위를 지키는 데도 중요합니다.

## 수정된 출시 일정

| 환경 | 최신 정식 출시 일정 |
|---|---|
| 전 세계 | 2026년 9월 중순 시작, 9월 말 완료 예정 |
| GCC | 2026년 9월 중순 시작, 9월 말 완료 예정 |

이전 일정은 전 세계가 8월 말, GCC가 8월 말 시작~9월 중순 완료였습니다. 2026년 9월 1일 공지는 두 환경 모두 9월 중순부터 말까지로 변경했습니다. 현재 날짜가 9월 초라면 아직 배포 전이거나 테넌트별로 제공 시점이 다를 수 있습니다.

## VFAM으로 관리자 접근 관리

조직은 Viva Insights 웹 앱 설정의 **View Feature Access Management(VFAM)**를 사용해 관리자용 Agent 365 대시보드 접근을 제어할 수 있습니다. 사용자, 그룹, 테넌트 수준으로 원하는 구성을 검토하세요.

이번 변경에 맞춰 다음을 준비할 수 있습니다.

1. 현재 VFAM 설정과 관리자 대상 그룹 확인
2. 에이전트 채택 데이터를 볼 필요가 있는 역할 정의
3. 적용 가능한 경우 근로자 대표 기구와 데이터 활용 방식 검토
4. 관리자 교육에서 집계 지표의 범위와 최소 그룹 임계값 설명
5. 내부 분석·교육 자료의 기존 출시 일정 수정

대시보드는 도입 추세를 보여 주지만 에이전트의 품질, 안전성, 업무 성과를 자동으로 판정하지 않습니다. 세션 수만 목표로 삼기보다 업무 목적, 사용자 피드백, 라이선스 비용과 함께 해석하는 것이 좋습니다.
