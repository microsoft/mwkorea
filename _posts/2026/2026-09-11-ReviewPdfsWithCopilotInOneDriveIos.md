# OneDrive iOS에서 선택한 PDF 내용을 Copilot으로 바로 검토합니다

모바일에서 PDF의 어려운 문장을 이해하거나 번역하려면 텍스트를 복사해 다른 앱으로 옮겨야 하는 경우가 많습니다. Microsoft 365 Copilot은 OneDrive iOS의 PDF 문맥 메뉴에 **Ask Copilot**을 추가해, 선택한 내용을 그대로 질문의 배경으로 사용할 수 있도록 합니다.

데스크톱에서 이미 일반 공급된 문맥형 PDF Copilot 경험이 iOS로 확장되는 것입니다. 2026년 9월 말부터 10월 말까지 전 세계 상용 환경뿐 아니라 GCC, GCC High, DoD에도 배포될 예정입니다.

---

## 선택한 텍스트로 할 수 있는 작업

OneDrive iOS에서 PDF 텍스트를 선택하면 문맥 메뉴에 Ask Copilot이 나타납니다. 이를 누르면 선택 영역이 Copilot의 문맥으로 전달돼 다음 작업을 수행할 수 있습니다.

- 전문적이거나 밀도가 높은 구절을 쉬운 말로 설명
- 긴 섹션의 핵심 내용 요약
- 선택한 텍스트를 다른 언어로 번역
- 사용자가 직접 프롬프트를 추가해 원하는 형식으로 답변 요청

현재 문서를 벗어나거나 별도 앱에 텍스트를 붙여 넣지 않아도 된다는 점이 핵심입니다. 질문 범위가 선택 영역으로 명확해져 모바일에서 긴 PDF를 검토할 때 필요한 부분에 집중할 수 있습니다.

## 실제 사용 순서

1. iOS용 OneDrive 앱을 열고 회사 계정으로 로그인합니다.
2. 검토할 PDF 파일을 엽니다.
3. PDF에서 원하는 텍스트를 선택합니다.
4. 문맥 메뉴의 **Ask Copilot**을 누릅니다.
5. 기본 설명을 받거나 직접 프롬프트를 입력해 결과를 조정합니다.

사용자 안내에서는 PDF 전체와 선택 영역을 구분해야 합니다. 이번 공지가 설명하는 진입점은 사용자가 선택한 텍스트를 문맥으로 삼는 기능이며, 해당 영역에 설명·요약·번역·맞춤 질문을 적용합니다.

## 라이선스와 기본 활성화

이 기능을 사용하려면 **Microsoft 365 Copilot 라이선스**가 필요합니다. Copilot이 활성화된 환경에서는 기본으로 켜집니다. 관리자가 별도의 모바일 전용 설정을 적용할 필요는 없습니다.

따라서 모바일 사용자가 기능을 보지 못할 때는 회사 계정 로그인 여부, Microsoft 365 Copilot 라이선스 할당, 조직에서 Copilot을 사용할 수 있는지, 단계적 배포가 테넌트에 도달했는지를 확인해야 합니다.

## 출시 일정과 지원 환경

일반 공급 대상은 Worldwide, GCC, GCC High, DoD입니다. 2026년 9월 말 배포를 시작해 10월 말 완료할 예정입니다. 단계적으로 제공되므로 같은 조직의 사용자에게도 표시 시점이 다를 수 있습니다.

공지는 OneDrive **iOS** 앱을 대상으로 합니다. Android나 다른 모바일 앱의 동일 기능 여부는 이번 메시지에 포함되지 않으므로 확대 해석하지 않는 것이 좋습니다.

## 데이터 보호와 조직의 준비

Microsoft는 이 기능이 기존 Copilot 데이터 처리 및 엔터프라이즈 데이터 보호 약속을 따른다고 설명합니다. 새 문맥 메뉴는 Copilot을 호출하는 위치를 모바일 PDF로 확장하지만, 조직은 기존 Copilot 거버넌스 기준에 따라 사용을 검토해야 합니다.

필수 관리자 조치는 없으며 다음 준비가 권장됩니다.

- 모바일 업무 사용자에게 Microsoft 365 Copilot 라이선스가 적절히 할당됐는지 검토합니다.
- OneDrive iOS의 PDF 문맥 메뉴와 사용 순서를 교육 자료에 추가합니다.
- 헬프 데스크에 기본 활성화 상태와 단계적 배포 기간을 알립니다.
- 사용자가 선택 영역과 결과를 확인하고 중요한 번역·요약을 원문과 대조하도록 안내합니다.

특히 법률, 재무, 기술 문서에서는 Copilot의 설명이나 번역을 최종 판단으로 사용하지 말고 원문과 조직의 검토 절차를 함께 적용해야 합니다. 모바일에서 접근이 간편해진 만큼 기존의 민감 정보와 책임 있는 AI 사용 지침도 반복해 안내하는 것이 좋습니다.
