# OneDrive 파일 우클릭 메뉴가 바뀝니다: Copilot 개별 작업 대신 Ask Copilot으로

OneDrive에 저장된 파일을 우클릭해 곧바로 요약하거나 비교하던 분이라면, 앞으로는 메뉴에서 익숙한 작업 이름이 보이지 않을 수 있습니다. Microsoft는 MC1515940에서 파일 탐색기의 OneDrive Copilot 개별 작업 메뉴를 종료한다고 안내했습니다.

핵심은 **Copilot 기능 전체의 종료가 아니라 진입 경로의 단순화**입니다. 파일을 선택해 Copilot 대화를 여는 방식은 유지되며, OneDrive 활동 센터에서도 기존 Copilot 작업을 계속 이용할 수 있습니다.

이번 글은 한국 시간 2026년 10월 20일에 게시된 Message Center 공지를 기준으로, 달라지는 메뉴와 사용자 안내에 필요한 내용을 정리합니다.

---

## 어떤 메뉴가 사라지나요?

종료 대상은 파일 탐색기의 OneDrive 파일 컨텍스트 메뉴에 표시되는 다음 개별 작업입니다.

| 작업 | 의미 |
|------|------|
| Summarize | 파일 요약 |
| Create FAQ | FAQ 생성 |
| Compare Files | 파일 비교 |
| Ask a question | 파일에 관해 질문 |
| Explain image / Explain images | 단일·여러 이미지 설명 |
| Compare images | 이미지 비교 |
| Extract text | 텍스트 추출 |

**Ask a question이라는 개별 작업과 앞으로 이용할 Ask Copilot 진입점을 혼동하지 않는 것이 중요합니다.** 공지는 전자는 제거되지만 후자는 계속 이용할 수 있다고 설명합니다.

## 앞으로는 어디에서 이용하나요?

파일 탐색기에서 OneDrive 파일을 우클릭한 뒤 **Ask Copilot**을 선택하거나, 파일 탐색기 **Home**에서 파일 위에 마우스를 올려 **Copilot 아이콘**을 선택하면 됩니다. 그러면 해당 파일이 첨부된 새 Copilot 대화가 열립니다.

![공지에 포함된 OneDrive Copilot 메뉴 변경 화면 1](/mwkorea/assets/images/2026-10-20-OneDriveCopilotContextMenuRetirement/image1.png)

![공지에 포함된 OneDrive Copilot 메뉴 변경 화면 2](/mwkorea/assets/images/2026-10-20-OneDriveCopilotContextMenuRetirement/image2.png)

파일은 **참조 방식으로 첨부**됩니다. 공지는 이 때문에 파일에 이미 적용된 권한과 보호가 계속 적용된다고 명시합니다. 메뉴 변경을 파일 접근 권한 확대나 보호 해제로 해석해서는 안 됩니다.

OneDrive 활동 센터의 Copilot 작업도 유지됩니다. 기존 업무 안내에서는 파일 탐색기 메뉴만이 유일한 실행 경로인 것처럼 설명하지 않는 편이 좋겠습니다.

## 일정과 도입 담당자 체크포인트

원문에 안내된 전 세계 일반 공급 환경의 종료 일정은 **2026년 11월 중순 시작, 12월 초 완료 예상**입니다. 이는 종료 변경의 배포 범위를 설명하는 것으로, 새로운 Copilot 기능이 GA로 출시된다는 의미는 아닙니다.

필수 관리자 작업은 없습니다. 다만 사내 매뉴얼과 헬프데스크 문서에 “우클릭 → Summarize”처럼 특정 메뉴를 직접 가리키는 설명이 있다면 수정하는 것이 좋습니다.

사용자에게는 “요약 기능이 없어졌다”가 아니라 **“Ask Copilot으로 파일 대화를 열어 작업한다”**고 안내하면 혼란을 줄일 수 있습니다. 교육 자료의 스크린샷과 OneDrive 활동 센터 대체 경로도 함께 확인하세요.

## 마무리

이번 변경은 파일마다 흩어져 있던 Copilot 작업 진입점을 대화 중심으로 정리하는 조정입니다. 기능 종료와 메뉴 종료를 구분해 안내하고, 실제 사용하는 환경에서 대체 경로를 확인하는 것이 가장 중요한 준비입니다.
