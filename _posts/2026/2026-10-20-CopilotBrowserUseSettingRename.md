# Cowork 설정을 찾고 계신가요? 이제 Browser use in Microsoft Copilot입니다

Copilot 관리자 화면에서 예전의 **Cowork** 패널을 찾기 어려워졌다면, 설정이 삭제된 것이 아니라 이름이 바뀐 것일 수 있습니다. Microsoft는 MC1515930에서 해당 패널을 **Browser use in Microsoft Copilot**으로 변경한다고 안내했습니다.

이 패널은 Copilot 앱이 사용자를 대신해 작업을 수행할 때 **Microsoft Edge 브라우저를 사용할 수 있는지** 관리하는 설정을 담고 있습니다. 이름만으로 관리 대상 기능을 더 쉽게 알아볼 수 있게 하려는 변경입니다.

중요한 점은 **명칭 변경으로 기능이나 기존 설정값이 바뀌지 않는다**는 것입니다. 새로운 브라우저 자동화 권한을 켜거나 기존 정책을 다시 구성하라는 공지가 아닙니다.

---

## 무엇이 바뀌고, 무엇이 유지되나요?

| 구분 | 공지 내용 |
|------|-----------|
| 이전 패널 이름 | Cowork |
| 새로운 패널 이름 | Browser use in Microsoft Copilot |
| 위치 | Copilot Settings |
| 관리 대상 | Copilot 앱의 Microsoft Edge 브라우저 사용 허용 여부 |
| 설정 기능 | 변경 없음 |
| 기존 구성 | 변경 없이 유지 |
| 필수 관리자 조치 | 없음 |

Microsoft는 Cowork 관련 제어를 기능별로 더 쉽게 찾을 수 있는 설정으로 정리하는 과정이라고 설명합니다. 따라서 이번 패널 이름 변경을 Cowork 서비스 전체의 이름 변경으로 확대 해석할 필요는 없습니다.

## 언제 적용되나요?

원문은 **전 세계 일반 공급 환경에서 2026년 10월 중순에 배포를 시작하고 같은 시기 완료할 예정**이라고 안내합니다.

이 글의 기준인 한국 시간 10월 20일 공지 게시 시점보다 앞선 표현이 포함되어 있지만, 이를 근거로 모든 조직에 이미 적용됐다고 단정하지는 않습니다. 실제 관리자 화면에 표시되는 이름으로 적용 여부를 확인하면 됩니다.

## 한국 조직의 운영 체크포인트

관리자가 설정을 다시 저장하거나 기본값을 변경할 필요는 없습니다. 오히려 이름이 달라졌다는 이유만으로 정책을 재설정하지 않도록 운영 담당자에게 안내하는 것이 좋습니다.

사내 운영 문서에서 **“Copilot Settings → Cowork”를 새 패널 이름으로 수정**하고, 헬프데스크에는 같은 브라우저 사용 제어라는 점을 공유하세요. 변경 이력에는 “표시 명칭 변경, 기존 구성 유지”로 기록하면 기능 변경과 구분하기 쉽습니다.

브라우저 사용을 허용할지 여부는 별도의 조직 정책 판단입니다. 이번 공지는 그 판단을 바꾸도록 요구하지 않으며, 브라우저 작업의 범위나 새로운 권한·라이선스 조건도 추가로 발표하지 않았습니다.

## 마무리

이번 업데이트는 작은 명칭 변경이지만, 관리 대상이 무엇인지 더 명확히 드러냅니다. **기존 제어는 그대로, 찾는 이름만 Browser use in Microsoft Copilot으로 변경**된다는 점을 기억하면 됩니다.
