# 검색의 Quick Access에서 Copilot Notebooks 참조 자료 빠르게 추가하기

업무 주제별로 자료를 모을 때는 파일을 찾는 것과 노트북에 참조로 추가하는 일이 이어집니다. 검색에서 확인한 자료를 다시 찾아 연결해야 한다면 작은 반복 작업이 생깁니다.

로드맵 **510099**, 수집 ID **RM510099**는 Microsoft 365 Copilot 앱의 검색에 있는 **Quick Access 영역에서 Copilot Notebook에 참조 자료를 빠르게 추가**하는 기능을 설명합니다.

---

## 어디에서 사용하는 기능인가요

| 구분 | 원문 설명 |
|---|---|
| 앱 | Microsoft 365 Copilot 앱 |
| 위치 | Search 안의 Quick Access |
| 동작 | Copilot Notebook에 참조 자료 추가 |

원문은 추가 경로를 간단히 소개하며 버튼 이름이나 화면별 절차, 지원 파일 종류를 자세히 제시하지 않습니다. 노트북의 자료 개수 제한이나 다른 기능의 변경까지 이 항목에서 발표한 것은 아닙니다.

## 자료를 찾는 흐름에서 연결하기

프로젝트 자료를 검색한 뒤 같은 주제를 다루는 Notebook에 연결하는 용도로 생각해 볼 수 있습니다. 이는 원문의 기능을 바탕으로 한 활용 예시입니다.

추가하기 전에는 선택한 자료가 원하는 주제와 맞는지, 어떤 Notebook에 연결하려는지 확인하는 것이 좋습니다. Quick Access에서 찾은 항목이라고 해서 항상 최신 자료이거나 모든 사용자와 공유되는 자료라고 가정할 필요는 없습니다.

## 일정과 제공 상태

이 항목의 **GA 표기는 2025년 11월**입니다. 이번 글의 날짜는 수집한 피드 항목의 한국 시간 기준 날짜이며, 새로운 출시 시점을 뜻하지 않습니다.

현재 앱에서 제공되는 화면과 동작은 실제 환경에서 확인하세요. 라이선스 세부 조건이나 관리자 설정은 원문에 명시되지 않았습니다.

이번 항목은 검색과 노트북을 연결하는 작은 작업 흐름의 개선입니다. 자료를 모으는 데 걸리는 단계를 줄일 수 있는지 실제 업무에서 살펴볼 만합니다.
