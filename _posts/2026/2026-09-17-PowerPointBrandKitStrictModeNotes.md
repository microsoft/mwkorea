# Copilot 발표 자료의 브랜드를 지키는 두 설정: Strict Mode와 Notes Steering

발표 자료 초안을 빠르게 만들어도 회사가 승인한 레이아웃과 메시지에서 벗어나면 다시 고치는 데 시간이 듭니다. 매번 프롬프트에 같은 브랜드 지침을 반복해서 적는 것도 번거롭습니다.

메시지 센터 **MC1470415**는 Microsoft 365의 Brand Kit 템플릿에 **Strict brand adherence**와 **Allow note instructions** 설정을 소개합니다. 원문은 현재 사용할 수 있다고 안내하며, 두 설정을 독립적으로 또는 함께 적용할 수 있다고 설명합니다.

---

## 레이아웃을 제한하는 Strict Mode

Strict brand adherence를 켜면 Copilot은 승인된 템플릿과 슬라이드 마스터 레이아웃만 사용합니다. 자리 표시자를 추가하거나 제거하지 않으며 새 레이아웃도 만들지 않습니다.

레이아웃의 자유로운 변경보다 브랜드 일관성이 중요한 고객 제안서, 경영진 보고, 규제 관련 발표 자료에 검토할 만한 설정입니다. 이 설정이 문서 내용의 정확성이나 법적 적합성까지 보장하는 것은 아닙니다.

## 발표자 노트로 방향을 주는 Notes Steering

Allow note instructions는 템플릿 발표자 노트에 넣은 지침으로 발표 자료 생성 방향을 안내하는 설정입니다. 원문은 다음과 같은 용도를 제시합니다.

- 특정 슬라이드를 반드시 포함하기
- 브랜드 관련 내용을 보존하고 슬라이드 순서를 유지하기
- 텍스트 밀도를 조절하고 특정 청중에 맞춰 구성하기

템플릿에 재사용할 지침을 담아 두면 사용자가 매 요청마다 반복할 필요가 줄어듭니다. 이는 Brand Kit 템플릿에 제공된 설정에 관한 설명이며, 모든 문서의 노트가 자동으로 신뢰할 지침이 된다는 뜻은 아닙니다.

## 누가 설정할 수 있나요

| 항목 | 원문 안내 |
|---|---|
| 제공 시점 | 현재 사용 가능 |
| 설정 권한 | Brand Kit 소유자와 Brand Manager |
| 적용 방법 | 기존 Brand Kit 템플릿 수정 또는 새 템플릿 업로드 |
| 설정 조합 | 각각 사용하거나 함께 사용 가능 |

일반 사용자가 모두 템플릿 정책을 변경할 수 있는 것은 아닙니다. 조직이 이 기능을 활용하려면 Brand Manager를 지정하고 Brand Kit 관리 권한을 확인하는 것이 좋습니다.

배포를 받기 위한 별도 조치는 없지만, 조직의 기준을 반영하려면 담당자가 실제 템플릿 설정을 구성해야 합니다. 대표 자료로 결과를 확인하면서 노트에 담을 내용 지침과 레이아웃 제한을 나눠 설계하세요.
