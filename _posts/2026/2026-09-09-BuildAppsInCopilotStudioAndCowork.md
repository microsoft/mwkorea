# 대화로 업무 앱을 만드는 Copilot Cowork와 Copilot Studio 앱 빌더

업무 아이디어를 앱으로 옮길 때 화면 구성과 데이터 연결을 처음부터 직접 설정하지 않고, 만들고 싶은 동작을 자연어로 설명하는 방식이 Copilot Cowork에 추가됩니다. 사용자는 대화를 통해 작동하는 첫 초안을 만든 뒤 계속 다듬고 미리 보고 시험할 수 있습니다.

같은 방향의 앱 작성 경험은 Copilot Studio에도 이어집니다. Cowork에서 시작한 앱을 Copilot Studio로 열어 더 편집할 수 있으며, 관리자는 Microsoft 365 관리 센터에서 조직 안의 앱을 일관된 방식으로 확인하고 관리할 수 있습니다.

---

## 아이디어에서 게시까지 대화로 이어집니다

적격 제작자는 자연어 대화로 필요한 앱을 설명하고 생성된 초안을 반복해서 수정할 수 있습니다. 결과를 미리 보고 시험한 뒤, 조직 정책에서 허용하는 사용자나 그룹에 게시하고 공유하는 흐름까지 지원합니다.

조직 데이터가 필요하면 관리 정책이 허용한 커넥터를 사용할 수 있습니다. 앱은 Microsoft Entra 인증을 사용하며 기존 커넥터, 환경, 데이터, 보안, 규정 준수와 공유 정책을 따릅니다. 생성형 AI가 앱을 만들더라도 조직의 Power Platform 거버넌스 경계 밖에서 별도로 운영되는 구조는 아닙니다.

## Cowork와 Copilot Studio의 연결

Copilot Cowork에서 만든 앱은 Copilot Studio에서 열어 후속 편집할 수 있습니다. Cowork는 대화를 통한 빠른 시작점을 제공하고, Copilot Studio는 같은 앱을 더 세밀하게 다룰 수 있는 연결 경로가 됩니다.

Copilot Studio 경험이 공개되면 적격 제작자에게 기본으로 켜질 예정입니다. 미리 보기 기간에는 관리자가 Microsoft 365 관리 센터에서 기능을 켜거나 끄고 특정 보안 그룹으로 접근 범위를 제한할 수 있습니다.

## 개인 개발 환경과 안전한 기본값

조직의 거버넌스 정책에 따라 이 경험에서 앱을 만드는 제작자는 공유 환경 대신 격리된 개인 개발 환경으로 자동 라우팅됩니다. 개인 개발 환경은 처음부터 안전한 기본값으로 보호되며, 관리자는 조직 요구에 맞춰 설정을 조정할 수 있습니다.

환경 라우팅을 아직 켜지 않은 조직도 이 경험으로 만든 앱에는 라우팅이 자동 적용됩니다. 이 변화는 Power Platform이나 Copilot Studio에서 다른 방식으로 만든 리소스에는 영향을 주지 않습니다. 각 앱 생성 시점에 적용 가능한 정책이 시행돼 조직의 거버넌스 범위 안에 두는 것이 목적입니다.

## 관리 센터에서 앱을 확인

게시된 앱은 Microsoft 365 관리 센터의 **Apps > All apps**에 표시됩니다. 관리자는 새 **Apps** 경험에서 조직 전반의 앱을 파악할 수 있고, **Apps > Settings**에서 기본 구성을 검토하고 정책을 조정할 수 있습니다.

도입 전에 다음을 준비하는 것이 권장됩니다.

- Frontier Program 온보딩을 마치고 **Apps > Overview**에서 적격 앱 제작자를 활성화합니다.
- 조직의 앱 생성·데이터 연결·게시·공유 기준을 제작자에게 안내합니다.
- 앱 작성과 실행에 필요한 **Copilot Credits** 조건을 검토합니다.
- 필요하다면 사용량 기반 청구를 구성합니다.

## 미리 보기 대상과 일정

| 항목 | 내용 |
|---|---|
| Cowork 대상 | Microsoft 365 Copilot 라이선스와 Cowork 접근 권한을 가진 Frontier Program 사용자 |
| Cowork 배포 | 2026년 9월 8일 시작, 9월 14일 완료 예정 |
| Copilot Studio | 공지 시점 기준 향후 수주 안에 제공 예정 |

Copilot Studio의 정확한 제공일은 공지에 제시되지 않았습니다. 조직은 Cowork와 Studio의 실제 제공 상태를 각각 확인하고, 미리 보기 기능을 운영 환경의 필수 프로세스에 바로 의존하기보다 정책과 비용을 먼저 검증하는 편이 좋습니다.
