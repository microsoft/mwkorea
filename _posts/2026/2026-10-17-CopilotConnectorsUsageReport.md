# 연결한 데이터가 실제로 쓰일까? Copilot 커넥터 사용 보고서가 답합니다

사내 데이터를 Copilot에 연결한 뒤에도 활용도를 확인할 수 없다면, 어떤 커넥터를 개선해야 할지 판단하기 어렵습니다. Microsoft는 관리자가 연결 데이터의 실제 이용 현황을 볼 수 있도록 새 사용 보고서를 도입합니다.

이번 글은 **2026년 10월 16일 수정된 MC1404326**을 기준으로 합니다. 최초 공지 당시의 일정이 아니라, GA가 11월로 조정된 최신 상세 공지를 확인하는 것이 중요합니다.

---

## 어디서 무엇을 볼 수 있나요?

경로는 **Microsoft 365 admin center → Reporting → Usage → Microsoft 365 Copilot → Connectors**입니다.

- Copilot Chat, Copilot Search, 에이전트에서 커넥터를 사용한 활성 사용자
- 조직에서 생성된 전체 커넥터 응답 수
- 활성 사용과 응답 수의 일별 추세
- 사용자별·커넥터별 사용 내역

![Copilot 커넥터 사용 보고서 화면](/mwkorea/assets/images/2026-10-17-CopilotConnectorsUsageReport/image1.png)

단순히 연결 개수를 세는 것이 아니라, 어떤 연결이 실제 응답에 활용되는지 살펴볼 수 있다는 점이 핵심입니다. 다만 사용량 지표 자체를 응답의 정확도나 업무 성과와 동일시해서는 안 됩니다.

## 대상과 최신 일정

원문은 **Microsoft 365 Copilot (Premium) 라이선스**를 요구합니다. 보고서는 기본 활성화되며 기존 권한을 따르고, 사용자 업무 흐름에는 영향을 주지 않습니다.

공개 프리뷰는 Worldwide 기준 2026년 6월 말 시작·7월 초 완료 일정이었습니다. GA는 종전 9월 말에서 **2026년 11월 시작·11월 완료 예정**으로 변경됐습니다.

## 관리자가 준비할 일

출시 전 필수 조치는 없습니다. 분석 담당자에게 새 경로를 안내하고, 제공 후 커넥터별 활용 추이를 검토하세요. 연결이 적게 쓰인다면 데이터 품질·검색 가능성·사용자 안내를 함께 점검하는 방식이 유용합니다. 이는 운영 제안이며 보고서가 원인을 자동 진단한다는 의미는 아닙니다.
