# Copilot Dashboard에 지능형 요약 추가: 도입 추세를 AI가 먼저 짚어줍니다

Copilot Dashboard의 수치와 그래프를 읽는 데서 한 걸음 더 나아가, 무엇이 도입을 이끌고 있는지 AI가 요약해 주는 기능이 추가됩니다. 성공 영역과 주의가 필요한 지점을 짚고, 더 깊이 살펴볼 질문도 제안합니다.

이 기능은 일반 사용자의 Copilot 작업 흐름을 바꾸는 업데이트가 아니라 **대시보드를 사용하는 관리자용 분석 보조 기능**입니다. 요약은 판단을 대신하는 결론이 아니라 조사할 방향을 좁혀 주는 출발점으로 다루는 것이 적절합니다.

---

## 지능형 요약이 제공하는 것

지능형 요약(Intelligent summaries)은 조직의 Copilot 사용 데이터를 바탕으로 주요 도입 추세와 사용 패턴을 AI가 설명하는 영역입니다. 관리자는 대시보드 지표를 하나씩 비교하기 전에 변화의 방향과 주목할 항목을 빠르게 파악할 수 있습니다.

함께 제공되는 **제안 프롬프트**는 특정 동인이나 개선 기회를 더 탐색하도록 돕습니다. 예를 들어 눈에 띄는 사용 패턴을 발견한 뒤, 그 배경이나 집중할 영역을 후속 질문으로 살펴보는 흐름입니다. 공지는 구체적인 프롬프트 문구나 모든 분석 기준을 확정해 제시하지 않으므로 실제 테넌트에 표시되는 내용을 기준으로 활용해야 합니다.

![Copilot Dashboard의 지능형 요약 화면](/mwkorea/assets/images/2026-08-27-CopilotDashboardIntelligentSummaries/image1.png)

## 적용 대상과 기본 동작

- **대상:** Microsoft Viva와 Microsoft 365에서 Microsoft 365 Copilot Dashboard를 사용하는 관리자
- **동작:** 적격 테넌트에 자동 표시
- **기본값:** 켜짐
- **기존 권한:** 관리자 제어와 권한은 변경되지 않음
- **일반 사용자 영향:** 사용자 작업 흐름 변화 없음

사전 구성 변경은 필요하지 않습니다. 다만 자동으로 나타나는 AI 생성 인사이트가 조직의 내부 보고 절차에 들어갈 수 있으므로, 대시보드 접근 권한과 결과 해석 책임은 기존 운영 기준에 맞춰 유지해야 합니다.

기능을 사용하지 않으려는 조직은 제공되는 관리자 제어로 지능형 요약을 비활성화해 롤백할 수 있습니다. 공지는 기존 권한 체계가 그대로라고 명시하므로, 이 기능 때문에 새로운 사용자 권한이 자동으로 부여되는 것은 아닙니다.

## 운영에서 유용하게 쓰는 방법

### 요약과 원시 지표를 함께 확인하세요

AI 생성 문장은 빠른 이해에 유용하지만, 채택률 변화의 원인을 확정하는 근거로 단독 사용해서는 안 됩니다. 요약에서 제기한 추세를 실제 대시보드 수치, 대상 기간, 조직 변화와 함께 확인하세요.

### 제안 프롬프트를 조사 질문으로 활용하세요

제안 프롬프트는 미리 정해진 결론이 아니라 다음 분석으로 이동하는 장치입니다. 성공 영역을 확대할 질문과 사용이 낮은 영역의 원인을 찾는 질문을 구분하면 교육·커뮤니케이션 계획으로 연결하기 쉽습니다.

### 보고서 문구에는 AI 생성임을 남기세요

지능형 요약의 문장을 내부 보고에 옮길 때는 사람이 검토했는지, 어떤 대시보드 기간을 근거로 했는지 기록하는 편이 안전합니다. 숫자를 설명하는 문장과 조직이 내린 판단을 분리하면 과도한 해석을 줄일 수 있습니다.

## 준비 체크리스트

- 대시보드 운영자와 헬프데스크에 새 요약 영역을 안내합니다.
- 기존 Copilot Dashboard 교육 자료와 화면 캡처를 갱신합니다.
- AI 생성 인사이트를 검토·인용하는 내부 기준을 정합니다.
- 기능을 사용하지 않을 경우 관리 제어의 위치와 비활성화 절차를 확인합니다.
- 배포 완료 전에는 테넌트별 표시 여부가 다를 수 있음을 안내합니다.
- 별도 규정 준수 영향은 공지에서 식별되지 않았지만, 조직 정책에 맞춰 검토합니다.

## 정리

지능형 요약은 대시보드를 “수치를 보여 주는 곳”에서 “살펴볼 이유를 제안하는 곳”으로 확장합니다. 도입 담당자는 분석 시간을 줄이면서도 어느 영역에 후속 조사가 필요한지 빠르게 찾을 수 있습니다.

효과를 제대로 얻으려면 AI의 설명을 최종 결론으로 받아들이기보다 원시 지표로 되돌아가는 탐색 경로로 사용해야 합니다. 기본으로 켜지지만 필요하면 비활성화할 수 있다는 점도 운영 방침에 반영하세요.
