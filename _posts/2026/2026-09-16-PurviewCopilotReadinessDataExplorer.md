# Copilot 도입 전 데이터 노출 점검: Purview DSPM 준비도와 Data Explorer

Copilot을 도입하기 전에 사용자에게 어떤 데이터가 열려 있는지 살펴볼 필요가 있습니다. 민감한 파일이 과도하게 공유되어 있다면 AI 사용 여부와 관계없이 먼저 점검할 과제입니다.

로드맵 **571157**, 수집 ID **RM571157**은 Microsoft Purview Data Security Posture Management에 Copilot 준비도와 **Data Explorer** 경험을 추가한다고 안내합니다. 보안 팀이 위험을 파악하고 조사·개선의 우선순위를 정하도록 돕는 변화입니다.

---

## 준비도와 조사의 역할 구분

| 기능 | 원문이 설명하는 정보 |
|---|---|
| Microsoft Copilot 준비도 | 민감 데이터 노출, 과도한 공유, 보호 범위와 개선 진행 상황 |
| Data Explorer | 사이트별 민감 데이터 위치, 사이트 수준 접근 권한, 미리 정의된 보기 |

준비도 경험은 Copilot 도입에 앞서 데이터 상태를 평가하고 개선하는 데 초점을 둡니다. Data Explorer는 사이트, 데이터, 권한을 한곳에서 조사해 도구 사이를 오가는 부담을 줄이는 방향입니다.

원문은 가시성과 조사 지원을 설명합니다. 모든 권한을 자동으로 수정하거나 민감 데이터를 알아서 삭제한다는 발표는 아닙니다.

## 제공 일정

| 구분 | 로드맵 표기 |
|---|---|
| 프리뷰 | 2026년 9월 |
| 정식 출시(GA) | 2027년 1월 |

프리뷰와 정식 출시의 간격이 있으므로 조직 전체에 이미 완성된 기능이 제공된다고 안내하지 마세요. 세부 라이선스, 지원 데이터 위치의 전체 목록, 프리뷰 참여 방법은 이 항목에 명시되지 않았습니다.

## 보안 담당자의 준비

조사한 위험을 누가 검토하고 누가 권한을 수정할지 정해 두면 새로운 가시성 정보를 실제 개선으로 연결하기 쉽습니다. 예를 들어 사이트 소유자와 보안 팀이 과도한 공유를 확인한 뒤 적절한 공유 범위를 합의하는 절차를 준비할 수 있습니다.

이런 운영 절차는 활용 제안입니다. 제품이 위험을 보여 주는 것과 조직이 해결 조치를 승인·실행하는 것은 별개의 단계로 관리하는 것이 좋습니다.
