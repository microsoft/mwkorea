# 모바일 Outlook의 Copilot Chat, 화면은 새롭게 쓰던 기능은 그대로

메일을 확인하다 Copilot에 질문할 때, 앱마다 대화 화면과 메뉴 위치가 다르면 작은 불편이 쌓입니다. Microsoft는 Message Center 공지 **MC1551148**을 통해 iOS 및 Android용 Outlook의 Copilot Chat 사용자 경험을 새롭게 정비한다고 알렸습니다.

이번 변경의 중심은 새로운 에이전트 기능이나 권한 확대가 아니라 **Microsoft 365 앱 전반에서 일관되게 사용할 수 있는 채팅 화면**입니다. 기존 Copilot 기능과 접근 제어는 유지하면서, 질문을 시작하고 답변을 읽고 대화 화면 사이를 이동하는 흐름을 개선합니다.

---

## 무엇이 달라지나요?

| 항목 | 공지에서 안내한 변화 |
|---|---|
| 전체 디자인 | Microsoft 365 앱 전반의 One Copilot 디자인과 일관성 강화 |
| 질문 시작 | 추천 프롬프트와 입력 상자 업데이트 |
| 답변 확인 | 응답 표시 방식 개선 |
| 탐색 | 측면 탐색 등 채팅 화면 간 이동 경험 개선 |
| 임시 채팅 | 오른쪽 위에서 **더 보기(...) 메뉴**로 이동 |

특히 기존에 오른쪽 위에서 임시 채팅을 시작하던 사용자는 메뉴 위치가 달라졌다는 점을 알아두면 좋습니다. **임시 채팅이 삭제되는 것이 아니라 진입 위치가 바뀌는 것**입니다.

## 바뀌지 않는 부분도 중요합니다

원문은 기존 Copilot 기능과 접근 제어가 변경되지 않는다고 명시합니다. 사용자는 일반적인 대화를 이어가거나 지원되는 Outlook 업무 흐름 안에서 Copilot을 계속 사용할 수 있습니다.

따라서 이번 공지를 근거로 새로운 라이선스 혜택, 추가 데이터 접근 권한, 자동 메일 발송 기능이 생긴다고 해석해서는 안 됩니다. 화면 개선과 기능·권한 변경을 구분해 안내하는 것이 좋습니다.

## 언제 제공되나요?

2026년 11월 13일 공지 기준, **전 세계 일반 공급(GA) 배포는 2026년 12월 중순에 시작해 2027년 1월 말까지 완료**될 예정입니다. 대상은 iOS 및 Android용 Outlook입니다.

이는 예정된 순차 배포 일정입니다. 공지가 게시된 시점에 모든 사용자에게 새 화면이 적용되었다는 의미는 아닙니다.

## 도입 담당자가 준비할 일

Microsoft는 **관리자 작업이 필요하지 않다**고 안내합니다. 별도의 규정 준수 고려사항도 식별되지 않았다고 명시하지만, 조직별 검토 필요성까지 없어지는 것은 아닙니다.

한국 기업의 운영 담당자에게는 설정 변경보다 사용자 안내가 실용적인 준비입니다. 사내 가이드에 임시 채팅 진입 위치를 반영하고, 추천 프롬프트·입력 상자·탐색 화면이 바뀌어도 기존 접근 제어는 유지된다는 점을 함께 설명하면 혼선을 줄일 수 있습니다. 이는 원문이 요구하는 필수 조치가 아니라 운영상 권장하는 준비입니다.

## 마무리

이번 업데이트는 모바일 Outlook 안에서 Copilot과 대화하는 방식을 더 익숙하게 만드는 변화입니다. 기능이 새로 생겼는지보다 **어디서 질문하고, 어떻게 답변을 읽고, 임시 채팅을 어디서 시작하는지**를 중심으로 살펴보세요.
