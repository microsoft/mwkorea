# Copilot Notebooks에서 Workspaces로: 팀의 AI 작업 공간이 달라집니다

AI에 참고 자료를 모아 주는 일은 개인 생산성의 출발점입니다. 팀 단위 업무에서는 여기에 누가 참여하고 있는지, 어떤 활동이 있었는지, 누가 공간을 소유하는지도 중요해집니다.

MC1559638은 Copilot Notebooks가 **Copilot Workspaces로 발전하면서 협업 기능을 확대**한다고 안내합니다. 이름 변경만이 아니라 팀의 업무 맥락과 진행 상황을 함께 관리하는 방향의 변화입니다.

---

## 새롭게 추가되는 협업 요소

| 기능 | 업무에서 주목할 점 |
|---|---|
| 활동 피드 | 작업 공간의 활동과 진행 상황을 파악하는 접점 |
| 추천 작업 공간 | 관련 작업 공간을 발견하는 경험 |
| 팀 참여 상태(Team presence) | 팀원의 참여 상태를 확인하는 경험 |
| 그룹 소유권 | 개인뿐 아니라 그룹 중심으로 소유권을 다루는 방식 |
| Project를 참조 자료로 추가 | 프로젝트를 작업 맥락에 연결하는 기능 |

이는 공지에 열거된 기능을 정리한 것입니다. 추천 기준, 그룹 소유권의 상세 관리 절차, Project 연동의 세부 제약은 이번 공지만으로 확정할 수 없습니다.

## 제공 일정과 영향 범위

Frontier Public 제공은 **2026년 11월 시작**됐으며, 전 세계 일반 공급은 **2026년 12월 시작 예정**입니다. 공지는 Frontier에서 Workspaces에 접근할 수 있는 사용자에게 확장된 협업 기능과 변경된 동작이 표시된다고 설명합니다.

따라서 모든 테넌트에 동시에 제공됐다고 안내하기보다 실제 사용자의 제공 상태를 확인하는 것이 좋습니다.

## 조직에서는 무엇을 바꾸면 좋을까요?

즉시 필요한 관리자 작업은 없습니다. 다만 기존 사내 매뉴얼에 Copilot Notebooks라는 이름으로 기록한 화면과 사용 절차는 업데이트 대상입니다.

도입 시에는 팀 프로젝트 하나를 골라 활동 피드와 소유권 흐름을 확인하는 접근을 권합니다. 이는 운영상 제안이며, 기능 추가가 기존 자료의 접근 권한을 자동으로 확대한다는 의미로 해석해서는 안 됩니다.

## 마무리

Workspaces의 방향은 **개인의 참고 자료 묶음에서 팀의 공동 작업 맥락으로 확장**하는 데 있습니다. 기능 소개와 함께 소유권, 참여 방식, 내부 교육 문서를 정리하면 변화의 의미를 더 명확히 전달할 수 있습니다.
