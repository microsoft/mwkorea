# 대화 기록을 활용하는 Copilot 개인화와 새 Memory 설정

사용자가 매번 같은 선호와 업무 맥락을 다시 설명하지 않아도 된다면 Copilot과의 대화는 더 자연스러워질 수 있습니다. Microsoft는 **대화 기록**을 활용해 답변을 개인화하고, Copilot이 기억하는 항목을 사용자가 더 분명하게 관리하도록 Memory 설정을 개편합니다.

메시지 센터 **MC1158329**는 모든 Copilot Chat 사용자를 위한 개인화와 Saved Memory 제어 개선을 설명합니다. 이번 공지는 새로운 관리자 정책을 추가하는 내용이 아니라, 기존 관리자·사용자 설정을 존중하면서 사용자 경험을 바꾸는 업데이트입니다.

---

## 대화 기록 기반 개인화

Copilot은 이전 채팅 기록을 활용해 현재 질문에 더 관련성 있고 맥락에 맞는 응답을 제공할 수 있습니다. 이는 사용자의 과거 상호 작용을 응답 생성에 활용하는 데이터 처리 변화입니다.

![Copilot의 Memory 및 개인화 사용자 설정](/mwkorea/assets/images/2026-09-02-CopilotMemoryPersonalizationUpdate/image1.png)

개인화가 정확성을 보장하는 것은 아닙니다. 이전 대화의 조건이 바뀌었거나 잘못된 맥락이 남아 있다면 현재 요청에 최신 정보를 명시하고 결과를 검증해야 합니다.

## Saved Memory를 관리하는 새 화면

새 Memory 설정 페이지는 Copilot이 기억하는 내용을 더 쉽게 보고 관리하도록 가시성과 제어 방식을 개선합니다. 대화 기록을 이용한 개인화 제어도 설정 화면에서 제공합니다.

기존에 관리자 또는 사용자가 Memory를 꺼 두었다면 업데이트 후에도 꺼진 상태가 유지됩니다. 관리자 제어나 정책 적용 방식에는 변경이 없습니다. 따라서 기능이 모든 사용자에게 무조건 켜진다고 해석하기보다, **Memory가 활성화된 테넌트의 사용자**라는 적용 범위를 확인해야 합니다.

## 현재와 과거 일정을 구분하세요

| 단계 | 공지 일정 |
|---|---|
| Frontier 공개 미리 보기 | 2025년 11월 중순 시작 |
| 정식 출시 | 2026년 9월 중순 시작, 10월 말 완료 예정 |

2026년 9월 1일 업데이트 전 공지에는 정식 출시가 2026년 1월 초 시작~7월 말 완료로 적혀 있었습니다. 최신 안내는 **9월 중순부터 10월 말**입니다. 공개 미리 보기 시작일은 이미 지난 날짜지만, 정식 출시가 모든 테넌트에 완료된 것은 아닙니다.

## 개인정보 보호와 사용자 안내

별도 관리자 작업은 필요하지 않습니다. 다만 대화 기록이 개인화에 사용된다는 점은 조직의 Copilot 교육과 개인정보 안내에 반영할 필요가 있습니다.

- 현재 테넌트의 Memory 활성화 여부와 대상 사용자 확인
- 사용자가 Memory 설정에서 기억 내용을 확인·관리하는 방법 안내
- 기존에 꺼 둔 설정은 그대로 유지된다는 점 설명
- 민감한 내용을 Copilot에 입력할 때 조직의 데이터 취급 정책 준수
- 개인화된 답변도 원자료와 최신 업무 조건으로 검증

공지의 규정 준수 설명에 따르면 기존 문서·이메일·채팅 같은 고객 데이터의 처리 방식에 변화가 생기며, 대화 기록을 사용해 맥락 응답을 생성합니다. 사용자는 기능을 직접 관리할 수 있지만, 그 사실만으로 조직의 데이터 분류와 사용 정책이 대체되지는 않습니다.

이번 업데이트의 도입 포인트는 ‘더 많이 기억하게 한다’보다 **어떤 기억이 응답에 쓰이는지 사용자가 이해하고 제어할 수 있게 안내하는 것**입니다. 지원 문서에는 화면 경로뿐 아니라 잘못된 과거 맥락을 수정하고 중요한 답변을 검증하는 습관도 함께 담는 것이 좋습니다.
