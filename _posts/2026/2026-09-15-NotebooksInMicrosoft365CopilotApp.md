# Microsoft 365 Copilot 앱의 Notebooks가 OneNote와 연결됩니다

프로젝트를 진행하며 나눈 Copilot 대화와 생성한 문서, 참고 자료가 여러 위치에 흩어지면 작업 맥락을 다시 구성하는 데 시간이 듭니다. Microsoft는 Microsoft 365 Copilot 앱의 Notebooks 경험을 업데이트해 이러한 요소를 가볍고 지속적인 작업 공간에 모으고, OneNote와 오가며 계속 작업할 수 있도록 합니다.

이번 변경은 OneNote의 기존 Notebooks 기능을 교체하는 것이 아닙니다. Microsoft 365 Copilot 앱에 Notebooks가 표시되고 양쪽 앱이 동기화되지만, OneNote 안의 기존 경험과 기존 Notebook 데이터는 그대로 유지됩니다.

---

## 프로젝트 맥락을 유지하는 작업 공간

Notebooks는 대화, Copilot이 만든 콘텐츠, 참조 자료를 하나의 프로젝트 단위로 정리합니다. 사용자는 이전 대화와 자료를 다시 찾아 연결하는 대신 같은 Notebook에서 맥락을 이어가며 다음 작업을 수행할 수 있습니다.

Notebook에서 만든 Word 문서, PowerPoint 프레젠테이션, Excel 스프레드시트, Copilot Pages 및 기타 지원 개체는 해당 Notebook과의 연결을 유지합니다. 단순한 메모 모음이 아니라, 프로젝트에서 생성되는 여러 형식의 결과물을 맥락과 함께 관리하는 허브로 활용할 수 있습니다.

![채팅, 생성물, 참조를 모은 Copilot Notebook](/mwkorea/assets/images/2026-09-15-NotebooksInMicrosoft365CopilotApp/image1.png)

## Copilot 앱과 OneNote 사이의 동기화

사용자는 Microsoft 365 Copilot 앱 또는 OneNote에서 Notebook을 열고 이어서 작업할 수 있습니다. 두 앱 사이에서 Notebooks가 동기화되므로 작업 장소를 바꾸더라도 같은 프로젝트 자료를 이용할 수 있습니다.

기존 Copilot Notebooks 진입점과 이미 저장된 Notebook 데이터도 유지됩니다. 공지는 기존 데이터를 별도의 새 저장소로 이동하거나 사용자가 마이그레이션해야 한다고 안내하지 않습니다. OneNote의 기존 Notebooks 경험 역시 변경되지 않습니다.

이 점은 사용자 교육에서 중요합니다. “새 Notebook이 별도로 생긴다”기보다 “기존 Notebook 작업 공간을 Microsoft 365 Copilot 앱에서도 보고 이어서 사용할 수 있다”는 관점으로 설명해야 중복 생성과 혼선을 줄일 수 있습니다.

## 대상 사용자와 서비스

배포가 테넌트에 도달하면 **Microsoft 365 Copilot 라이선스가 있는 사용자**가 Microsoft 365 Copilot 앱에서 Notebooks를 볼 수 있습니다. 관련 서비스는 Microsoft 365 Copilot 앱, OneNote, Microsoft 365 Copilot Notebooks이며 Notebook에서 생성하는 지원 콘텐츠도 연결 범위에 포함됩니다.

관리자가 별도로 기능을 켤 필요는 없습니다. 다만 사용자가 기능을 보지 못하는 경우 배포 도달 여부와 Microsoft 365 Copilot 라이선스 할당을 먼저 확인해야 합니다.

## 변경된 출시 일정

2026년 9월 14일 업데이트에서 일정이 수정됐습니다.

- 전 세계 일반 공급 시작: 2026년 9월 말, 이전 계획은 8월 말
- 배포 완료 예상: 2026년 10월 초, 이전 계획은 9월 초

공지의 권장 사항 일부에는 여전히 “8월 말부터 보일 수 있다”는 이전 표현이 남아 있지만, 최신 일정은 9월 말 시작과 10월 초 완료입니다. 내부 안내에는 수정된 일정을 사용해야 합니다.

## 데이터와 규정 준수 관점

업데이트는 기존 Notebook 데이터를 Microsoft 365 Copilot 앱에서도 접근 가능하게 하고 OneNote와 동기화합니다. 또한 채팅, 생성 콘텐츠, 참조 자료를 지속적인 공간에서 다루는 생성형 AI 상호 작용 경로를 확장합니다.

따라서 새로운 데이터 이전 작업은 안내되지 않았더라도, 조직은 기존 Microsoft 365 Copilot 및 OneNote의 데이터 접근·보존 정책이 프로젝트형 Notebook 사용 방식에 적합한지 검토할 수 있습니다. Notebook에 어떤 참조를 추가할지에 대한 사용자 교육도 함께 제공하는 것이 좋습니다.

## 관리자가 준비할 일

필수 관리자 조치는 없습니다. 운영 준비로는 다음이 권장됩니다.

- 헬프 데스크와 지원 팀에 수정된 배포 일정을 공유합니다.
- Microsoft 365 Copilot 및 OneNote Notebooks 안내 문서를 업데이트합니다.
- 라이선스가 있는 사용자만 Copilot 앱에서 새 경험을 본다는 점을 명시합니다.
- 기존 데이터와 OneNote 경험이 유지된다는 점을 안내합니다.
- 프로젝트 자료와 생성 콘텐츠가 Notebook에 계속 연결되는 사용 방식을 교육합니다.

사용자는 앱 간 동기화를 파일 복제와 혼동할 수 있으므로, 실제 테넌트에서 작업 흐름을 검증한 뒤 짧은 예제 중심의 가이드를 제공하는 것이 효과적입니다.
