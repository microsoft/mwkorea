# Copilot Chat 안에서 바로 계산하고 비교한다: App Blocks의 대화형 앱 경험

Copilot의 답변을 읽는 데서 끝나지 않고, 조건을 바꾸며 결과를 직접 확인할 수 있다면 어떨까요? Microsoft는 MC1545695에서 **App Blocks**를 통해 Copilot Chat의 대화 안에 대화형 앱을 표시하는 경험을 안내했습니다.

핵심은 별도 앱 캔버스로 이동하지 않고 대화 흐름 안에서 앱을 미리 보고 조작할 수 있다는 점입니다. 정적인 설명을 받은 뒤 다른 화면에서 계산하는 대신, 질문과 결과 탐색을 같은 대화 안에서 이어 가는 방식입니다.

---

## 어떤 경험을 만들 수 있나요?

원문은 요청과 데이터를 다음과 같은 대화형 경험으로 바꿀 수 있다고 설명합니다.

| 앱 유형 | 대화 안에서 해 볼 수 있는 탐색 |
|---|---|
| 계산기·비교 도구 | 입력 조건을 바꿔 결과 비교 |
| 대시보드·시각화 | 데이터를 시각적으로 살펴보기 |
| 폼·플래너 | 정보를 입력하고 계획 검토 |
| 시뮬레이션 | 조건에 따른 결과와 업무 흐름 탐색 |

위 오른쪽 열은 각 유형을 이해하기 위한 활용 예시입니다. 모든 업무 시스템과 자동 연결되거나 특정 데이터 원본을 반드시 지원한다는 뜻은 아닙니다.

원문은 **최신 정보를 검색한 뒤 대화형 경험으로 렌더링하는 grounded 시나리오**도 지원한다고 설명합니다. 다만 이 공지에는 개별 커넥터, 데이터 접근 권한, 외부 시스템 쓰기 기능에 대한 세부사항은 없습니다.

## 별도 캔버스 대신 대화 안에서 미리 보기

App Blocks는 Copilot 대화에 직접 표시됩니다. 사용자는 별도의 앱 캔버스를 열지 않고도 미리 보기를 확인하고, 입력을 조정하거나 결과를 살펴볼 수 있습니다.

이는 Copilot의 기존 워크플로나 프롬프트를 없애는 변경이 아닙니다. Microsoft는 **기존 워크플로와 프롬프트가 계속 예상대로 동작한다**고 안내합니다. 사용자 교육에서는 “어떤 명령이 사라졌는가”보다 “생성 결과와 미리 보기가 어디에 표시되는가”를 설명하는 것이 적절합니다.

## 대상 사용자와 배포 단계

| 항목 | 공지 내용 |
|---|---|
| 대상 | Microsoft 365 Copilot **Premium**, Copilot Chat **Basic** |
| 서비스 | Microsoft 365 Copilot Chat |
| 배포 단계 | General Availability, Worldwide |
| 예정 일정 | 2026년 10월 말 시작, 11월 초 완료 예상 |

Basic 사용자도 영향 대상이라는 점을 놓치지 마세요. 유료 Microsoft 365 Copilot 사용자만을 대상으로 내부 공지를 보내면 실제 변경을 보게 되는 일부 사용자가 안내에서 빠질 수 있습니다.

배포 일정은 원문에 적힌 예상치입니다. 예정 완료 시점이 지났다고 해서 모든 계정의 실제 제공 상태를 확인한 것으로 간주해서는 안 됩니다.

## 조직에서는 무엇을 준비하면 좋을까요?

필수 관리자 조치는 없습니다. Microsoft는 별도 컴플라이언스 고려사항을 식별하지 않았다고 안내하면서도 조직 상황에 맞는 검토를 권고합니다.

우선 **side-by-side app canvas를 기준으로 작성된 기존 교육 자료**를 점검하는 것이 좋습니다. 새 경험에서는 대화 안에 결과가 나타나므로, 예전 화면만 보여 주는 가이드가 사용자를 혼란스럽게 만들 수 있습니다.

실무 적용 시에는 예산 비교나 일정 검토처럼 결과를 사람이 검토할 수 있는 시나리오부터 평가해 볼 수 있습니다. 입력값과 계산 결과의 타당성은 별도로 확인해야 하며, 원문에 없는 지속 저장·앱 배포·외부 시스템 업데이트 기능까지 제공된다고 가정하지 않아야 합니다.

## 마무리

App Blocks는 Copilot Chat을 답변을 읽는 공간에서 **조건을 바꾸고 결과를 탐색하는 공간**으로 확장합니다. 조직의 도입 담당자는 Premium과 Basic 사용자를 함께 고려하고, 대화 안에서 이뤄지는 새 미리 보기 경험에 맞춰 안내를 정비하면 좋겠습니다.
