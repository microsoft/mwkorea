# Outlook의 Copilot 경험, 대화 중심으로 더 단순해집니다

Microsoft가 Outlook 안의 Copilot 경험을 Microsoft 365 Copilot 앱과 비슷한 대화 중심 구조로 새롭게 정리합니다. 메일을 보면서 사용하는 측면 창과 Copilot에 집중하는 전체 화면이 함께 바뀌기 때문에, 사용자는 작업 맥락에 따라 진입점을 바꾸더라도 더 일관된 방식으로 대화를 이어갈 수 있습니다.

이번 변경은 새 기능 하나를 추가하는 수준보다 탐색, 채팅, 에이전트 접근 방식을 한 흐름으로 재구성하는 업데이트에 가깝습니다. 2026년 9월 일반 공급되며 서비스 업데이트로 자동 적용됩니다.

---

## 무엇이 달라지나

전체 화면 Copilot은 최근 개편된 Copilot 앱의 구조를 따릅니다. 탐색 메뉴가 단순해지고 채팅 레이아웃이 정돈되며, 에이전트를 찾고 상호 작용하는 과정도 개선됩니다. 업무 정보와 웹 정보가 어떤 방식으로 대화에 활용되는지 조정할 수 있도록 Work IQ 관련 제어도 제공됩니다.

전체 화면에는 **Tasks 보기**가 추가됩니다. 에이전트가 백그라운드에서 수행하는 활동이나 예약된 채팅처럼 즉시 끝나지 않는 작업의 진행 상태를 확인하는 공간입니다. 여러 Copilot 작업을 병행할 때 현재 무엇이 실행 중인지 찾기 쉬워집니다.

![Outlook의 새 전체 화면 Copilot 경험](/mwkorea/assets/images/2026-09-16-SimplifiedCopilotExperienceInOutlook/image1.png)

## 전체 화면과 측면 창의 차이

Outlook 곳곳에서 열 수 있는 Copilot 측면 창도 새 디자인과 채팅 경험을 적용받습니다. 메일 읽기와 작성 흐름을 유지하면서 문맥 기반 도움을 받도록 최적화된 형태입니다. 다만 측면 창에는 Tasks 보기가 포함되지 않습니다. 장기 실행 작업을 확인하려면 전체 화면 Copilot으로 이동해야 합니다.

두 화면 모두 대화 중심 사용 방식, 개선된 에이전트 탐색, Work IQ 표현을 공유합니다. 따라서 조직의 교육 자료에서는 단순히 버튼 위치만 안내하기보다, 빠른 문맥 작업은 측면 창에서 하고 장기 작업 관리와 넓은 탐색은 전체 화면에서 한다는 구분을 설명하는 편이 좋습니다.

![Outlook의 새 Copilot 측면 창 경험](/mwkorea/assets/images/2026-09-16-SimplifiedCopilotExperienceInOutlook/image2.png)

## 적용 범위와 기존 제어

업데이트는 Outlook의 전체 화면 Copilot과 측면 창 모두에 적용되며, 2026년 9월 일반 공급됩니다. 별도의 사용자 또는 관리자 설정 없이 기본으로 활성화됩니다. 이번 공지에 따르면 라이선스, 권한, 기존 규정 준수 제어에는 변경이 없습니다.

즉, 새 화면이 보인다고 해서 사용자가 이전에 접근할 수 없던 조직 데이터나 에이전트 권한을 새로 받는 것은 아닙니다. 기존 접근 권한과 Copilot 정책의 범위 안에서 사용자 경험만 새로워집니다.

## 관리자가 준비할 일

기술적인 배포 작업은 없지만 사용자 혼선을 줄이기 위한 준비는 필요합니다.

- Outlook Copilot의 화면과 탐색 방식이 바뀐다는 점을 사전에 알립니다.
- 기존 스크린샷이 포함된 도움말, 교육 자료, 헬프 데스크 문서를 갱신합니다.
- Work IQ에서 업무 및 웹 기반 정보가 어떻게 표시되는지 설명합니다.
- Tasks 보기는 전체 화면에만 있다는 차이를 지원 조직에 공유합니다.

특히 단계별 안내서가 기존 메뉴 구조에 의존한다면 9월 중 실제 테넌트 화면을 확인해 수정하는 것이 안전합니다. 기능 활성화를 위한 조치는 없지만, 사용자 채택 관점에서는 새 진입점과 화면별 역할을 명확히 안내하는 것이 핵심입니다.
