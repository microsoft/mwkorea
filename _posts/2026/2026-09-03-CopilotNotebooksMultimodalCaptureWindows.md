# OneNote Copilot Notebooks, Windows에서 오디오·이미지·노트를 함께 캡처

회의나 현장 업무의 맥락은 음성만으로 남지 않습니다. 대화 중 촬영한 이미지와 손으로 적은 메모까지 함께 모아야 결정 과정과 후속 작업을 온전히 복원할 수 있습니다.

Microsoft는 Windows용 OneNote의 **Copilot Notebooks 멀티모달 캡처**를 공개합니다. 오디오, 이미지, 노트를 하나의 경험에서 수집하고 Microsoft 365 Copilot이 이를 분석해 요약, 결정 사항과 실행 항목을 구조화된 Copilot Page로 만듭니다.

---

## 무엇을 캡처하고 어떻게 정리하나

사용자는 Copilot Notebook에 오디오와 이미지, 노트를 직접 캡처할 수 있습니다. 지원되는 브라우저 기반 회의가 감지되면 캡처 시작이 제안되거나 시작될 수 있으며, 대상 회의 서비스로 **Zoom, Webex, Google Meet**이 명시됐습니다.

회의가 아니어도 Windows 시스템 트레이의 OneNote 아이콘에서 캡처를 수동으로 시작할 수 있습니다. Copilot은 수집한 내용을 바탕으로 다음 정보가 담긴 구조화된 Copilot Page를 생성합니다.

- 대화와 작업의 요약
- 확인된 결정 사항
- 담당자가 처리할 실행 항목
- 함께 수집한 이미지와 메모의 맥락

캡처한 콘텐츠는 사용자가 선택한 Copilot Notebook에 저장되고 다른 엔드포인트에서도 접근할 수 있습니다. 현장에서 모은 비정형 기록을 후속 업무에 사용할 수 있는 결과로 바꾸는 것이 핵심입니다.

## 라이선스와 지원 환경

대상은 **OneNote에서 Copilot Notebooks에 접근할 수 있는 사용자**입니다. **Microsoft 365 Copilot 라이선스**가 필요하며, 상업용 Microsoft 365의 업무·학교 계정, 즉 Microsoft Entra ID 계정으로 사용해야 합니다.

클라이언트는 **Windows 데스크톱용 OneNote**이고 Microsoft 365 데스크톱 앱이 설치되어 있어야 합니다. 공지에는 최소 Windows 버전이나 OneNote 빌드 번호가 따로 제시되지 않았습니다. Mac, 웹, iOS, Android용 OneNote를 이번 Windows 캡처 기능의 지원 대상으로 간주해서는 안 됩니다.

## 변경된 배포 일정

2026년 9월 2일 업데이트에서 기존 일정보다 늦춰졌습니다.

- **전 세계 일반 공급 시작:** 2026년 9월 말
- **배포 완료 예상:** 2026년 10월 중순
- 이전 일정: 8월 말 시작, 9월 중순 완료

기능은 적격 사용자에게 **기본 활성화**됩니다. 사용자가 별도 미리 보기 프로그램에 들어가야 하는 일정은 아니지만, 순차 배포이므로 모든 계정에 같은 날 나타나지는 않을 수 있습니다.

## 저장·처리와 규정 준수

이 기능은 새 고객 데이터를 저장합니다. 캡처된 오디오, 이미지와 노트는 사용자가 선택한 Copilot Notebook의 **SharePoint 또는 OneDrive**에 보관됩니다. Microsoft 365 Copilot은 콘텐츠를 전사하고 처리해 요약, 결정 사항과 실행 항목을 생성합니다.

또한 Zoom, Webex, Google Meet의 브라우저 회의 캡처를 지원하므로 제3자 서비스와 관련된 업무 흐름이 생깁니다. 조직은 해당 서비스의 사용 정책과 함께 녹음·전사에 대한 법률, 내부 규정, 참여자 동의 요건을 확인해야 합니다.

## 관리자 제어와 준비 사항

별도의 필수 사전 작업은 없지만, 관리자는 **정책 설정으로 기능을 비활성화**할 수 있습니다. 캡처를 허용하지 않는 조직이나 부서는 배포 전에 사용 가능한 정책을 검토해야 합니다.

준비 과정에서는 다음을 확인하는 것이 좋습니다.

1. 대상 사용자에게 Microsoft 365 Copilot 라이선스와 Windows Microsoft 365 데스크톱 앱이 있는지 확인합니다.
2. SharePoint·OneDrive 저장 위치와 보존·접근 정책을 검토합니다.
3. 회의 녹음, 전사 및 참여자 동의 절차를 사용자에게 알립니다.
4. Zoom, Webex, Google Meet을 포함한 제3자 회의 서비스 정책과 충돌하지 않는지 살펴봅니다.
5. 기능을 허용하지 않을 범위가 있다면 관리자 정책으로 비활성화합니다.

멀티모달 캡처는 메모 작성의 편의 기능을 넘어 실제 음성과 이미지 데이터를 저장하고 AI로 처리합니다. 따라서 기본 활성화 여부만 확인할 것이 아니라, 캡처 시작 전에 동의를 받고 생성된 Copilot Page의 내용과 담당 항목을 사람이 검토하는 운영 절차가 필요합니다.
