# Copilot 답변 복사, 이제 출처를 함께 가져올지 직접 선택하세요

Copilot 답변을 메일이나 보고서 초안에 옮길 때, 원문 링크와 인용 표시를 남기고 싶은 경우도 있고 문장만 가져오고 싶은 경우도 있습니다. 용도에 따라 필요한 형태가 다른데, 복사한 뒤 출처 표시를 일일이 지우는 작업은 번거롭습니다.

Microsoft는 Message Center 공지 **MC1568700**에서 Microsoft 365 Copilot의 **Copy with sources** 옵션을 안내했습니다. 사용자가 Copilot 답변을 복사할 때 **출처를 함께 포함할지 직접 선택**할 수 있게 하는 기능입니다.

기본 설정은 출처 포함입니다. 필요하면 옵션을 끄고 인용 표시 없이 텍스트를 복사할 수 있습니다. 다만 이 공지는 출시 예고로, 원문 기준 배포 시작은 2026년 12월 중순입니다.

---

## 새로운 점: 출처를 지우는 대신 복사 설정 바꾸기

이번 기능은 Copilot 답변을 재사용하는 과정의 선택권을 넓힙니다.

| 설정 | 복사할 때의 동작 |
|---|---|
| **Copy with sources 켜짐** | 복사한 콘텐츠에 인용·출처를 포함 |
| **Copy with sources 꺼짐** | 인용 표시 없이 텍스트를 복사 |

**Copy with sources는 기본적으로 켜져 있습니다.** 출처를 보존하고 싶은 사용자는 기본 설정을 유지하면 되고, 문장만 필요한 사용자는 옵션을 끄면 됩니다.

원문은 이 변화가 답변을 복사한 뒤 인용 표시를 수동으로 제거할 필요를 줄여 준다고 설명합니다. 답변 생성 방식이 달라지는 기능이라기보다, 생성된 콘텐츠를 다른 업무 도구로 옮기는 방식을 조정하는 기능입니다.

## 원문 화면으로 살펴보는 사용 흐름

원문에 첨부된 예시 화면에서는 답변의 복사 버튼을 누른 뒤 **Copied without sources**라는 알림이 나타납니다. 알림에는 복사 기본 설정을 관리하는 **settings** 링크도 보입니다.

![Copilot 답변을 출처 없이 복사한 뒤 표시되는 Copied without sources 알림과 설정 링크](/mwkorea/assets/images/2026-11-26-CopilotCopyWithSources/image1.png)

두 번째 화면에서는 **Settings의 General 영역**에 **Copy with sources** 스위치가 있습니다. 설명은 Copilot 답변을 복사할 때 출처를 포함하는 설정임을 보여 줍니다.

![Settings의 General 영역에서 Copy with sources 스위치를 조정하는 원문 예시 화면](/mwkorea/assets/images/2026-11-26-CopilotCopyWithSources/image2.png)

기능이 제공되면 해당 옵션을 원하는 상태로 조정하고, 답변을 복사한 뒤 실제 붙여넣기 결과를 확인하면 됩니다. 위 이미지는 Microsoft가 공지에 첨부한 예시이며, 실제 배포 화면의 메뉴 이름이나 위치는 달라질 수 있습니다.

## 언제 사용할 수 있나요?

원문이 안내한 일정은 다음과 같습니다.

| 항목 | 안내 내용 |
|---|---|
| 배포 단계 | 전 세계 일반 공급(GA) |
| 배포 시작 | 2026년 12월 중순 |
| 배포 완료 예상 | 2026년 12월 말 |
| 영향 대상 | Microsoft 365 Copilot 사용자 |
| 관리자 조치 | 별도 조치 불필요 |

이는 **2026년 11월 25일 공지 시점의 예정 일정**입니다. 공지의 한국 표준시 발행일은 2026년 11월 26일이며, 모든 사용자가 그날 바로 기능을 사용할 수 있다는 뜻은 아닙니다.

원문에는 앱별 세부 배포 순서나 최소 버전이 제시되지 않았습니다. 옵션이 아직 보이지 않는 경우에도 이 공지만으로 배포 오류라고 판단할 수는 없습니다.

## 업무 용도에 맞춰 선택하기

다음은 기능을 업무에 적용할 때 생각해 볼 수 있는 활용 예시입니다. Microsoft가 특정 용도에 특정 설정을 의무화한 것은 아닙니다.

### 근거를 확인해야 하는 보고서 초안

팀에 공유할 조사 결과나 검토 자료를 만들 때는 출처 포함 설정이 유용합니다. 읽는 사람이 원래 자료를 찾아가 내용을 검증하기 쉬워지기 때문입니다.

다만 출처를 함께 복사해도 답변의 정확성이 자동으로 보장되지는 않습니다. 중요한 주장과 수치는 인용된 원문을 직접 확인해야 합니다.

### 문장만 필요한 메일·공지 초안

이미 검토한 내용을 메일 문장이나 사내 공지 초안으로 옮길 때는 출처 없이 복사하는 방식이 편리할 수 있습니다. 인용 표시를 지우는 반복 편집을 줄일 수 있습니다.

**인용 표시를 빼는 것과 필요한 출처 표기를 생략해도 되는 것은 다릅니다.** 조직의 문서 작성 기준이나 인용 요건이 있다면 별도로 지켜야 합니다.

## 도입 담당자가 안내할 핵심 두 가지

관리자가 기능을 활성화하기 위해 별도 조치를 할 필요는 없습니다. Microsoft는 사용자에게 새 복사 옵션을 안내할 것을 권고합니다.

사내 교육 자료에는 다음 두 가지를 분명하게 설명하면 좋습니다.

1. **기본값은 출처 포함**이며, 사용자가 설정을 바꿀 수 있습니다.
2. **출처 없이 복사하는 기능은 비식별화나 보안 기능이 아닙니다.** 복사한 본문 자체에 민감한 정보가 있다면 그대로 남을 수 있으므로, 외부 공유 전 내용과 공유 권한을 확인해야 합니다.

원문은 확인된 별도 컴플라이언스 고려사항이 없다고 안내하지만, 각 조직의 상황에 맞는 검토도 권고합니다. 편집 편의 기능을 문서 보안 정책의 대체 수단으로 사용하지 않는 것이 중요합니다.

## 마무리

Copy with sources는 작은 설정이지만, Copilot 답변을 실제 업무 산출물로 옮기는 과정의 불필요한 편집을 줄여 줍니다.

근거를 남겨야 하는 자료에는 출처를 보존하고, 문장 중심의 초안에는 필요한 형태로 복사하세요. 편리한 재사용과 사실 확인을 함께 유지하는 것이 이번 기능을 잘 활용하는 방법입니다.
