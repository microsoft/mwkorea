# Copilot Workspaces, 에이전트 선택 대신 말로 맡기는 업무 공간으로 바뀝니다

자료를 조사하고, 수치를 분석하고, 결과를 시각적으로 정리할 때마다 에이전트를 바꿔야 한다면 업무 흐름이 끊길 수 있습니다. Microsoft는 Copilot Workspaces에서 이러한 선택 과정을 줄이는 **agentic chat** 경험을 예고했습니다.

2026년 11월 12일 UTC에 게시된 메시지 센터 공지 MC1550540에 따르면, 기존 Copilot Notebooks라는 이름으로 알려진 **Copilot Workspaces**에서는 Researcher, Analyst, Designer가 독립적인 선택 항목으로 표시되지 않게 됩니다. 대신 요청 내용과 작업 공간의 콘텐츠에 맞춰 Copilot이 적절한 조사·분석·디자인 역량을 적용합니다.

이는 세 에이전트의 기능을 없애는 발표가 아닙니다. **작업 공간 안에서 기능을 호출하는 방식의 변화**이며, 개별 에이전트를 선호하는 사용자는 Microsoft 365 Copilot 앱에서 계속 이용할 수 있습니다.

---

## 무엇이 달라지나요?

| 구분 | 공지된 변화 |
|---|---|
| Workspaces의 에이전트 선택 | Researcher·Analyst·Designer의 개별 선택 항목 제거 |
| 작업 요청 | 채팅에 필요한 일을 자연어로 설명 |
| 역량 적용 | 요청과 작업 공간 콘텐츠에 따라 Copilot이 적절한 역량 적용 |
| 기존 기능 | 조사·분석·디자인 역량 유지 |
| 개별 에이전트 이용 | Microsoft 365 Copilot 앱에서 계속 가능 |

사용자가 먼저 “어떤 에이전트가 맞는지” 판단하기보다 **달성하려는 결과를 설명하는 방식**에 가까워집니다. 다만 원문은 내부의 모델 선택 방식이나 새로운 데이터 접근 권한을 상세히 설명하지 않으므로, 이 변경을 권한 확대나 완전한 무인 자동화로 해석해서는 안 됩니다.

## 현업에서는 결과 중심으로 요청하세요

예를 들어 다음과 같이 요청하는 방법을 사내 교육에 활용할 수 있습니다. 아래 문장은 원문에 제시된 데모가 아니라, 공지된 사용 방식에 맞춘 활용 예시입니다.

> 이 작업 공간의 자료를 바탕으로 고객 제안의 핵심 근거를 정리하고, 숫자로 비교할 수 있는 항목을 분석한 뒤, 발표에 쓸 요약 구성을 제안해 줘.

사용자는 작업 공간에 넣은 자료의 적합성과 최종 결과를 검토해야 합니다. “에이전트를 선택하지 않아도 된다”는 변화가 “출력물을 검증하지 않아도 된다”는 뜻은 아닙니다.

## 제공 일정: 12월 Frontier 프리뷰 예정, GA는 미정

원문 시점의 계획은 다음과 같습니다.

- **Frontier 프리뷰**: 2026년 12월 배포 시작 예정. 완료일은 아직 정해지지 않았습니다.
- **일반 공급(GA)**: 일정 조율 중으로, 확정된 시작일과 완료일은 공지되지 않았습니다.
- **대상**: Frontier 프리뷰에 접근할 수 있는 Copilot Workspaces 사용자.
- **플랫폼**: 메시지 센터의 플랫폼 표기는 Web입니다.

따라서 이 글을 읽는 시점에 모든 테넌트에서 이미 바뀌었다고 단정할 수 없습니다. 원문은 Workspaces와 Microsoft 365 Copilot 앱을 관련 서비스로 함께 언급하지만, 이를 모든 클라이언트의 동시 배포 발표로 확대해 해석하지 않는 것이 좋습니다.

## 관리자와 도입 담당자의 체크포인트

원문은 **필수 관리자 작업이 없으며 배포 시 자동 적용**된다고 안내합니다. 실무적으로는 설정 변경보다 사용자 안내를 준비하는 편이 중요합니다.

1. “Workspaces에서 Researcher를 선택하세요”처럼 에이전트 선택을 전제로 한 사내 매뉴얼을 수정합니다.
2. 조사·분석·디자인 기능은 유지되며, 필요한 일을 채팅으로 직접 설명하면 된다고 알립니다.
3. 개별 에이전트를 쓰고 싶은 사용자에게 Microsoft 365 Copilot 앱의 해당 에이전트를 안내합니다.
4. 조직의 컴플라이언스 요구사항에 맞춰 새로운 채팅 경험을 검토하고, 메시지 센터의 후속 일정 공지를 확인합니다.

## 마무리

이번 변화의 핵심은 **에이전트 이름을 고르는 경험에서 업무 목적을 설명하는 경험으로의 이동**입니다. 한국 기업의 Copilot 교육도 기능별 버튼 설명뿐 아니라, 자료·목적·원하는 결과 형태를 명확하게 전달하는 방법을 함께 다루면 좋겠습니다.
