# 복잡한 개념을 한 장의 인터랙티브 슬라이드로: PowerPoint Frontier 기능

복잡한 시스템이나 시간의 흐름을 한 장에 설명하려면 도형, 연결선, 텍스트를 직접 배치하는 작업이 길어집니다. PowerPoint의 **Create interactive slides**는 이런 내용을 전체 슬라이드 크기의 시각적 경험으로 만드는 과정을 줄이기 위한 기능입니다.

메시지 센터 **MC1461152**는 Windows와 Mac용 PowerPoint에서 이 기능을 Microsoft Copilot **Frontier** 경험으로 안내합니다. 시각 자료 생성의 진입 장벽을 낮추는 것이 목적이지만, 사전 출시 기능이므로 정식 출시 전 동작과 범위가 달라질 수 있습니다.

---

## 어떤 슬라이드를 만들 수 있나요

적격 사용자는 다음과 같은 시나리오를 전체 슬라이드 시각 자료로 표현할 수 있습니다.

- 복잡한 개념 설명
- 프로젝트나 사건의 타임라인 제시
- 옵션과 정보 비교
- 시스템과 요소 사이 관계 시각화
- 데이터의 시각적 전달

공지의 표현은 ‘인터랙티브한 전체 슬라이드 시각 자료’입니다. 어떤 상호 작용 유형을 지원하는지, 결과를 편집하거나 내보낼 때 어떤 제한이 있는지, 발표 모드에서 외부 데이터와 실시간 연결되는지는 명시하지 않았습니다. 따라서 일반적인 웹 앱이나 대시보드를 슬라이드에 자동 생성한다고 단정해서는 안 됩니다.

## 플랫폼과 현재 상태

대상은 이 기능에 접근할 수 있는 PowerPoint for Windows 및 Mac 사용자입니다.

| 플랫폼 | Frontier 상태 |
|---|---|
| Windows 데스크톱 | 현재 사용 가능 |
| Mac | 현재 배포 중, 2026년 9월 초 완료 예정 |

일정은 **Frontier 전 세계 배포** 기준입니다. Windows에서 현재 사용 가능하다는 설명도 모든 일반 고객의 정식 출시를 뜻하지 않습니다. 조직은 Frontier 프로그램 참여와 사용자 자격을 먼저 확인해야 합니다.

## 어디에 유용한가요

기능은 복잡한 내용을 빠르게 초안으로 시각화할 때 유용할 수 있습니다. 예를 들어 시스템 구성도를 토론하기 위한 첫 화면, 여러 선택지를 비교하는 워크숍 자료, 긴 일정을 한눈에 보는 설명 슬라이드를 만들고 사람이 검토하는 방식입니다.

자동 생성된 관계나 수치가 원자료와 일치하는지는 별도로 확인해야 합니다. 접근성, 색 대비, 글꼴 크기, 브랜드 템플릿 준수, 발표 장비에서의 동작도 조직의 실제 기준으로 시험할 필요가 있습니다.

## Frontier 평가를 준비하는 방법

배포 전에 필수 관리자 작업은 없습니다. Microsoft는 발표 지원, 도입, 교육, 헬프데스크 팀과 정보를 공유하고 Frontier 참가자를 선정해 정식 출시 전에 피드백을 제공하는 방식을 권합니다.

평가 시에는 다음 기준을 함께 기록해 두면 좋습니다.

1. 어떤 프롬프트와 원자료로 슬라이드를 만들었는지
2. 생성 결과를 이해하는 데 걸린 시간과 수동 수정량
3. 사실·수치·관계의 정확성
4. 발표 중 상호 작용의 안정성과 호환성
5. 접근성 및 조직 디자인 기준 충족 여부
6. 기존 표준 발표 제작 절차에 넣을 검토 단계

조직이 표준화된 발표 제작 프로세스를 운영한다면 Frontier 결과를 바로 외부 자료에 쓰기보다 내부 초안과 파일 복사본으로 검증하세요. 교육 자료에서도 ‘완성본 자동 제작’이 아니라 복잡한 시각 설명을 시작하는 도구로 위치를 분명히 하는 편이 좋습니다.
