# Copilot Studio 에이전트도 Copilot Chat처럼: 응답 경험이 하나로 맞춰집니다

Microsoft 365 Copilot 안에서 Copilot Chat과 Copilot Studio 에이전트를 번갈아 써 보면 같은 화면인데도 서로 다른 제품처럼 느껴질 때가 있습니다. 답변 서식이 다르고, 응답이 표시되는 방식이 다르며, 인용이나 도구 실행 정보를 확인하는 방법도 다릅니다.

사용자는 어느 쪽이 기본 Copilot이고 어느 쪽이 에이전트인지보다 **지금 하려는 일을 잘 끝낼 수 있는지**에 관심이 있습니다. 경험이 달라질수록 학습 부담과 혼선만 커집니다.

메시지 센터 공지 **RM570435**로 안내된 이번 업데이트는 **Microsoft 365 Copilot에서 사용하는 Copilot Studio 에이전트 경험을 Copilot Chat과 연결**합니다.

---

## 무엇이 달라지나요

Microsoft는 변화를 **보이는 방식(look), 느껴지는 방식(feel), 동작 방식(behave)** 세 가지로 설명합니다.

### 보이는 방식

- Copilot Chat과 **유사한 응답 서식**
- **압축된 사고 과정(compressed chain of thought)** 표시

에이전트 답변도 기본 Copilot Chat 응답처럼 읽히도록 시각적 차이를 줄입니다.

### 느껴지는 방식

- **더 부드러운 스트리밍(smoother streaming)**
- **재개(resume)**
- **재시도(retry)**
- **음성 받아쓰기(voice dictation)**

응답이 생성되는 흐름과 사용자 입력 방식이 Copilot Chat에 가까워집니다. 중단된 작업을 이어 가거나 결과를 다시 시도하고, 음성으로 지시하는 경험이 같은 패턴으로 맞춰집니다.

### 동작 방식

- **클릭 가능한 인용(clickable citations)**
- **도구 실행 추적(tool execution traces)**

답변의 근거를 바로 열어 보고, 에이전트가 어떤 도구를 실행했는지 확인할 수 있습니다. 단순한 UI 통일을 넘어 **신뢰와 검증 가능성**이 강화되는 부분입니다.

---

## 한눈에 보는 변화

| 영역 | 개선 내용 |
|---|---|
| **Look** | 유사한 서식, 압축된 사고 과정 |
| **Feel** | 부드러운 스트리밍, 재개·재시도, 음성 받아쓰기 |
| **Behave** | 클릭 가능한 인용, 도구 실행 추적 |

목표는 Copilot Studio 에이전트의 응답이 **Copilot Chat 자체의 응답과 매우 비슷하게 보이고, 느껴지고, 동작하도록** 만드는 것입니다.

---

## 왜 의미가 있나요

### 사용자 학습 부담 감소

에이전트마다 결과를 읽고 조작하는 방법이 다르면 사용자는 새 인터페이스를 다시 배워야 합니다. 경험이 통일되면 **어떤 에이전트를 쓰더라도 익숙한 방식으로** 작업할 수 있습니다.

### 인용을 통한 근거 확인

클릭 가능한 인용은 사용자가 답변의 출처를 즉시 확인할 수 있게 합니다. 정책, 규정, 분석처럼 근거가 중요한 업무에서 특히 유용합니다.

### 도구 실행의 투명성

도구 실행 추적을 통해 에이전트가 답변만 한 것인지, 외부 시스템을 조회하거나 작업을 실행했는지 확인할 수 있습니다. 에이전트가 더 많은 행동을 수행할수록 이런 가시성이 중요해집니다.

### 중단·실패 복구

재개와 재시도 기능은 긴 작업이나 도구 호출이 포함된 작업에서 유용합니다. 처음부터 다시 시작하지 않고 흐름을 이어 갈 수 있습니다.

---

## 최근 Copilot Studio 업데이트와 함께 보기

최근 공지들과 연결하면 Copilot Studio 에이전트의 운영 경험이 한 방향으로 정리되고 있음을 알 수 있습니다.

| 기능 | 의미 |
|---|---|
| **도구 호출 승인 게이트** (RM570434) | 민감한 도구 실행 전 사람의 승인 강제 |
| **이번 응답 경험 통일** (RM570435) | 인용과 도구 실행 추적을 사용자에게 표시 |
| **에이전트 공유** (RM569475) | 메이커 간 Viewer·Editor 권한 공유 |
| **평가 경험 개선** (RM569607) | 추론 추적, 지식 소스 인용, 실행 비교 |

만들기, 검토하기, 실행하기, 사용자에게 보여 주기의 각 단계에서 **가시성과 통제**가 강화되고 있습니다.

## 도입 담당자를 위한 체크포인트

- **사용자 안내 자료를 통합하세요**: Copilot Chat과 에이전트의 조작 방식이 가까워지므로 별도 안내보다 공통 사용법 중심으로 정리할 수 있습니다.
- **인용 품질을 검증하세요**: 클릭할 수 있다는 것과 근거가 적절하다는 것은 별개입니다. 대표 질문으로 인용 대상과 연결 정확도를 확인하세요.
- **도구 실행 추적을 운영에 활용하세요**: 에이전트가 어떤 작업을 했는지 확인하는 절차를 지원·감사 프로세스에 반영할 수 있습니다.
- **승인 게이트와 함께 설계하세요**: 민감한 도구에는 승인 게이트를 걸고, 실행 후에는 도구 추적으로 확인하는 방식으로 사전·사후 통제를 구성할 수 있습니다.
- **음성 입력의 사용 환경을 고려하세요**: 공개 장소나 현장 환경에서는 민감 정보가 음성으로 노출되지 않도록 사용자 지침이 필요할 수 있습니다.
- **압축된 사고 과정의 성격을 이해하세요**: 사용자에게 표시되는 요약 정보는 전체 내부 추론을 공개하는 것이 아니라 작업 진행을 이해하도록 돕는 압축된 표현으로 봐야 합니다.

---

## 마무리

에이전트가 늘어날수록 사용자는 제품별 차이를 배우기보다 **일관된 경험**을 원합니다. 이번 업데이트는 Copilot Studio 에이전트를 Microsoft 365 Copilot 안에서 별도의 낯선 도구가 아니라 **Copilot Chat의 자연스러운 확장**으로 느끼게 만드는 변화입니다.

특히 클릭 가능한 인용과 도구 실행 추적은 보기 좋은 UI 이상의 의미가 있습니다. 에이전트가 무엇을 근거로 답했고 어떤 행동을 했는지 확인할 수 있어, 실무 도입에 필요한 신뢰를 높입니다.
