# ERP 에이전트의 불필요한 도구 호출을 줄인다: MCP 실행 경로 최적화

도구가 많아지면 에이전트가 같은 결과에 도달하는 경로도 다양해집니다. ERP 업무에서 불필요한 조회나 중간 호출이 늘면 응답 시간이 길어지고 실행 흐름도 복잡해질 수 있습니다.

Microsoft는 Dynamics 365 ERP MCP 서버가 **작업에 적합한 도구 실행 순서를 사용하도록 개선**하는 기능을 로드맵에 등록했습니다.

---

## 무엇을 바꾸나요?

현재 동적 도구 환경에서는 언어 모델의 오케스트레이션이 필요 이상으로 많은 호출을 선택할 수 있다는 문제를 설명합니다. 개선안은 MCP 도구의 단일 진입점과 사용 가능한 ERP 메뉴 항목·엔터티·동작의 의미 인덱스를 활용합니다.

서버가 작업 수행에 적합한 실행 순서를 사용하게 해 응답 성능과 정확도를 높이려는 방향입니다. 다만 “모든 요청이 한 번의 내부 호출로 끝난다”거나 일정 비율로 빨라진다는 보장은 아닙니다.

## 개발자가 확인할 지표

같은 업무 요청의 호출 수, 응답 시간, 결과 정확성을 함께 비교하는 것이 좋습니다. 빨라졌더라도 필요한 검증 단계가 빠지지 않았는지 확인해야 합니다. 이는 도입 시 평가 권고이며 원문이 특정 평가 도구를 제공한다는 뜻은 아닙니다.

원문에는 별도 API 코드나 성능 벤치마크 수치가 없습니다.

## 일정

프리뷰 목표는 **2026년 10월**, GA 목표는 **2026년 12월**입니다. 관리자·메이커·마케터 자동 활성화 항목으로 분류되지만, 수집 시점에 GA가 완료됐다고 표현해서는 안 됩니다.
