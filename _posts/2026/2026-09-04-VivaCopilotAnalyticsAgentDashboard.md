# 에이전트 채택과 Copilot 크레딧을 함께 보는 Viva Agent Dashboard

조직에 배포된 에이전트가 늘어나면 단순한 생성 개수보다 실제 사용자가 돌아오는지, 응답이 얼마나 발생하는지, Copilot 크레딧은 어디에 쓰이는지를 함께 봐야 합니다. Microsoft Viva의 Copilot Analytics에 추가되는 **Agent Dashboard**가 이런 채택과 소비 지표를 통합합니다.

대시보드는 Microsoft 365 Copilot에서 사용되는 다양한 에이전트를 다룹니다. Copilot Studio, SharePoint 또는 Microsoft 365 Agents Toolkit으로 만들었는지, 제작 주체가 직원·조직·Microsoft·파트너인지와 관계없이 지원 범위에 포함될 수 있습니다.

---

## 여섯 달 추세를 보여 주는 핵심 지표

Viva Insights의 Copilot Analytics에서 새 Agent Dashboard를 열면 최대 6개월의 과거 추세와 함께 다음 지표를 볼 수 있습니다.

- 활성 에이전트 수
- 활성 에이전트 사용자 수
- 에이전트 응답 수
- 사용된 Copilot 크레딧
- Copilot 크레딧을 사용한 사용자 수
- Copilot 사용자 중 에이전트를 사용하는 비율

![Agent Dashboard의 핵심 채택 및 Copilot 크레딧 지표](/mwkorea/assets/images/2026-09-04-VivaCopilotAnalyticsAgentDashboard/image1.png)

사용량과 비용 신호를 같은 화면에서 볼 수 있어 단순 접속자 수만으로 채택을 판단하는 한계를 줄일 수 있습니다. 다만 지표는 성과 자체를 자동으로 증명하지 않으므로 업무 결과나 사용자 피드백과 함께 해석해야 합니다.

## 유지율과 에이전트별 상세 분석

월간·주간 사용자 유지 추세를 확인하고 그룹끼리 비교할 수 있습니다. 반복 사용자가 늘어나는지 살펴보면 일회성 시험과 지속적인 업무 채택을 구분하는 데 도움이 됩니다.

또한 활성 사용자 수, 에이전트 응답, 소비한 Copilot 크레딧을 기준으로 상위 에이전트를 확인할 수 있습니다. 특정 에이전트를 선택하면 시간에 따른 핵심 채택 지표를 더 자세히 볼 수 있습니다.

![상위 에이전트와 활성 사용 지표](/mwkorea/assets/images/2026-09-04-VivaCopilotAnalyticsAgentDashboard/image3.png)

개인정보 보호를 위해 에이전트 활동 인사이트에는 최소 그룹 크기 기준이 적용됩니다. 작은 집단을 분석할 때 값이 보이지 않는다면 데이터 부재로 단정하기 전에 조직의 최소 그룹 크기 설정을 확인해야 합니다.

## 기존 Copilot Dashboard와 연결

Copilot Dashboard의 **Adoption** 탭도 개선됩니다. Copilot 사용자가 에이전트와 크레딧을 어떻게 활용하는지에 대한 맥락형 인사이트를 제공하고, 더 깊은 분석을 위해 Agent Dashboard로 바로 이동할 수 있는 진입점을 보여 줍니다.

![Copilot Dashboard Adoption 탭의 Agent Dashboard 진입점](/mwkorea/assets/images/2026-09-04-VivaCopilotAnalyticsAgentDashboard/image5.png)

이 연결을 통해 전체 Copilot 채택을 살펴보다가 에이전트 사용과 비용 신호를 별도 대시보드에서 분석하는 흐름을 만들 수 있습니다.

## 대상과 접근 관리

대상은 Microsoft Viva Insights를 사용하는 리더, 위임자, 채택 전문가와 관리자입니다. 테넌트에는 **Microsoft 365 Copilot 라이선스가 50개 이상 할당**돼 있어야 합니다.

관리자는 Viva Insights 웹 앱의 VFAM 제어 아래에서 사용자, 그룹과 테넌트 수준으로 Agent Dashboard 접근을 관리할 수 있습니다. 조직의 노사 협의 절차가 적용되는 경우 works council과 검토하고, 분석 지표의 의미와 최소 그룹 크기 기준을 교육 자료에 반영하는 것이 권장됩니다.
