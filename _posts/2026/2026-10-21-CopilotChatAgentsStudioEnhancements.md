# Copilot Chat 에이전트를 더 체계적으로: Studio에 토픽·평가·환경별 배포 지원

인사 규정이나 브랜드 가이드처럼 답변의 일관성이 중요한 업무에서는 에이전트가 자연스럽게 말하는 것만으로 충분하지 않습니다. 정해진 절차를 따르고, 품질을 평가하고, 개발 버전과 운영 버전을 구분할 수 있어야 합니다.

Microsoft의 MC1518233 공지는 Copilot Studio에서 **Copilot Chat 에이전트, 즉 declarative agents**를 만드는 경험을 강화한다고 안내합니다. 공지 시점 기준 일반 제공 예정일은 **2026년 10월 26일**입니다.

---

## 제작부터 운영까지 연결되는 여섯 가지 기능

| 기능 | 원문이 설명하는 역할 |
|---|---|
| Topics | 결정적인 대화 흐름 구성 |
| Connected agents | 다른 에이전트에 작업 위임 |
| Evaluations | 에이전트 품질 개선 |
| Monitoring | 에이전트 사용 현황 추적 |
| Copilot Chat 기본 미리 보기와 Activity Map | 실제 사용자 경험을 테스트하고 동작 이해 |
| Agent lifecycle management | 개발·테스트·운영 환경에 서로 다른 버전 배포 |

예를 들어 인사 에이전트는 규정에 근거한 표준 답변을 제공하고, 콘텐츠 에이전트는 브랜드와 법무 요구사항에 맞는 결과를 만들도록 설계할 수 있습니다. 다만 **기능 추가가 답변의 정확성이나 규정 준수를 자동 보장하는 것은 아닙니다.**

## 메이커와 운영 담당자가 준비할 일

기존 에이전트에서 자유로운 생성보다 정해진 흐름이 필요한 구간을 먼저 찾아보세요. 이어서 평가 질문을 준비하고, Activity Map으로 사용자에게 보이는 흐름을 확인하며, 개발·테스트·운영 버전을 구분하는 배포 절차를 정리하는 접근을 권합니다.

이 순서는 도입을 위한 제안이며 제품의 필수 설정 순서를 뜻하지 않습니다. 원문은 별도 즉시 조치가 필요하지 않은 안내성 공지로, 내부 개발 문서와 교육 자료를 갱신하고 메이커·개발팀에 변경 사항을 공유할 것을 권장합니다.

## 마무리

이번 변화의 핵심은 Copilot Chat 에이전트를 단순한 시제품이 아니라 **검증하고 배포하며 관찰하는 업무 서비스**로 다룰 수 있도록 지원하는 데 있습니다. 실제 테넌트에서 제공되는 범위는 배포 이후 확인해야 합니다.
