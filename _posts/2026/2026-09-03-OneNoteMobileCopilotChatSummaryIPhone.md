# OneNote iPhone, Copilot 채팅과 긴 페이지 요약 기능 제공

휴대폰에서 긴 OneNote 페이지를 읽을 때 필요한 내용을 찾기 위해 계속 스크롤해야 했던 사용자는 이제 Copilot과 대화할 수 있습니다. Microsoft는 iPhone용 OneNote 모바일 앱에 페이지 요약과 노트 기반 질의응답을 제공하는 새 Copilot 채팅 창을 추가합니다.

이번 기능은 이동 중에도 긴 회의 노트나 업무 기록의 핵심을 빠르게 확인하도록 설계됐습니다. 사용자가 이미 접근할 수 있는 OneNote 콘텐츠를 Copilot이 분석해 요약하거나 질문에 답하며, 기존 Microsoft 365 Copilot의 권한과 정책이 그대로 적용됩니다.

---

## 모바일 앱 안의 새 Copilot 채팅

적격 사용자는 iPhone용 OneNote에서 **Copilot chat pane**을 볼 수 있습니다. 별도 앱으로 이동하지 않고 현재 노트와 관련된 요청을 OneNote 안에서 처리하는 화면입니다.

![iPhone용 OneNote의 Copilot 채팅 창](/mwkorea/assets/images/2026-09-03-OneNoteMobileCopilotChatSummaryIPhone/image1.png)

채팅 창에서 제공되는 핵심 기능은 두 가지입니다.

- 긴 OneNote 페이지를 간결하게 정리하는 **Summary**
- 사용자가 접근 권한을 가진 노트 내용을 바탕으로 한 질문과 답변

![Copilot 채팅의 페이지 요약과 질의응답](/mwkorea/assets/images/2026-09-03-OneNoteMobileCopilotChatSummaryIPhone/image2.png)

단순히 짧은 미리 보기를 표시하는 것이 아니라 생성형 AI가 페이지 내용을 처리해 요약을 만들고 질문에 응답합니다. 따라서 결과를 중요한 의사결정에 사용할 때는 원문 노트와 대조해야 합니다.

## 대상 사용자와 라이선스

이번 공지의 플랫폼은 **OneNote Mobile on iPhone**입니다. Android용 기능은 별도의 메시지와 Roadmap ID로 관리되므로, iOS와 Android 배포 상태를 구분해야 합니다.

기능을 사용하려면 공지에 명시된 **Microsoft 365 Copilot (Premium) 라이선스**가 필요합니다. 모든 Microsoft 365 테넌트가 배포 범위에 포함되지만, Premium 라이선스가 없는 사용자는 영향을 받지 않습니다. 공지에는 최소 iOS 버전, OneNote 앱 버전 또는 iPad 지원 여부가 적혀 있지 않으므로 이를 임의로 확대 해석해서는 안 됩니다.

## 수정된 전 세계 배포 일정

2026년 9월 2일 업데이트에서 일정이 다음과 같이 변경됐습니다.

- **전 세계 일반 공급 시작:** 2026년 9월 말
- **배포 완료 예상:** 2026년 10월 중순
- 이전 일정: 8월 말 시작, 9월 중순 완료

배포는 순차적으로 진행되므로 같은 테넌트의 iPhone 사용자 사이에서도 기능이 나타나는 시점이 다를 수 있습니다.

## 권한과 데이터 처리

Copilot 채팅은 사용자가 이미 접근 권한을 가진 OneNote 콘텐츠만 처리합니다. 기존 Microsoft 365 Copilot의 데이터 처리, 권한, 보안과 정책이 계속 적용되며, 새 기능이 사용자의 원래 OneNote 접근 권한을 넓히지는 않습니다.

다만 생성형 AI가 노트 내용을 분석하는 새로운 모바일 상호작용이 추가됩니다. 조직은 모바일 기기에서 Copilot을 사용하는 상황도 기존 거버넌스, 규정 준수와 사용 정책의 범위에 포함되는지 확인해야 합니다.

## 관리자와 지원팀의 준비

배포 전에 필요한 관리자 조치는 없습니다. 새 기능을 위한 별도 설정이나 정책 변경도 이번 공지에는 제시되지 않았습니다. 관리자는 다음 사항을 확인하면 됩니다.

1. 기능이 필요한 iPhone 사용자에게 Premium 라이선스가 할당되어 있는지 점검합니다.
2. 헬프 데스크에 iPhone 전용 기능과 변경된 배포 일정을 공유합니다.
3. 사용자 교육에 채팅 창, Summary, 노트 기반 질의응답 흐름을 추가합니다.
4. 기존 Microsoft 365 Copilot 거버넌스와 규정 준수 정책이 모바일 사용 시나리오에도 맞는지 검토합니다.
5. Copilot 결과는 원문 확인이 필요한 생성형 AI 출력임을 안내합니다.

이 업데이트는 데스크톱에 있던 작업을 그대로 축소한 기능이 아니라, 이동 중 노트를 검토하는 흐름에 맞춘 새 진입점입니다. 라이선스와 플랫폼 범위를 정확히 안내하고, 요약이 원본 노트를 대체하지 않는다는 원칙을 함께 교육하는 것이 중요합니다.
