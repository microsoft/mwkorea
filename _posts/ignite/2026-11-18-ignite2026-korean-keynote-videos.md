Microsoft Ignite 2026 오프닝 키노트에서 가장 많이 드러난 변화는 AI가 질문에 답하는 도구를 넘어, 사람과 함께 업무를 이어가고 조직의 지능을 연결하는 기반으로 이동하고 있다는 점입니다.

다만 약 **2시간 25분에 이르는 키노트 전체를 외국어로 끝까지 보기 쉽지는 않습니다.** 그래서 원본 발표를 한국어 더빙과 자막으로 편집해, 시청 목적에 따라 두 가지 영상으로 준비했습니다.

이 영상은 오프닝부터 마무리까지 전체 키노트를 순서대로 담았습니다. 각 발표 사이의 연결과 실제 데모의 맥락을 이해하거나, 관심 있는 내용을 찾아 다시 시청하기에 적합합니다.

특히 다음과 같은 주제가 하나의 흐름으로 이어집니다.

- **사람, 인텔리전스, 신뢰:** 이번 키노트를 관통하는 세 가지 원칙
- **Copilot:** Chat, Cowork, Code, Autopilot을 연결하는 새로운 업무 시작점
- **Fusion과 협업:** 사람과 에이전트가 공동의 맥락과 목표를 중심으로 일하는 방식
- **Microsoft IQ:** Fabric, Foundry, Microsoft 365와 외부 시스템의 지식을 조직 전체로 연결하는 구조
- **MAI Code 2:** 실제 소프트웨어 개발과 디버깅을 위한 코딩 모델
- **기업 사례:** Chevron, Unilever, Alaska Airlines, Publicis, AT&T의 적용 장면
- **Agent 365:** 에이전트 ID, 거버넌스, 관리, 비용과 성과 분석
- **Perception:** Red, Blue, Green 보안 에이전트가 협력하는 에이전틱 보안 체계
- **AI 투명성:** 에이전트의 행동을 독립적으로 확인하고 통제하는 표준과 원칙

풀버전에는 챕터도 표시해 두었습니다. 전체를 보고 싶은 분은 처음부터, 특정 제품이나 기업 사례가 궁금한 분은 해당 시점부터 바로 확인하면 됩니다.

## 한국어 더빙은 어떻게 만들었나?

두 영상 모두 다음 방식으로 제작했습니다.

- **음성 인식:** Azure MAI-Transcribe-2
- **화자 구분:** 발화자 분리
- **번역:** AI 번역과 문맥 기반 고유명사 보정
- **더빙:** Azure MAI-Voice-2의 AI 합성 음성
- **자막:** 한국어 자막 추가
- **원음 처리:** 원본 목소리는 낮은 배경음으로 유지

화자 성별에 맞춰 남성·여성 음성을 나누고, 원본 발표의 말투와 장면 전환을 최대한 살리도록 편집했습니다. 핵심은 단순히 영상을 번역하는 데 그치지 않고, **한국어 사용자가 발표의 기술 흐름과 실제 데모를 자연스럽게 이해하도록 돕는 것**입니다.

> 이 영상은 Microsoft 공식 영상이 아니라 개인 제작한 **비공식 AI 한국어 더빙 콘텐츠**입니다. 번역이나 발음에 오류가 있을 수 있으므로 정확한 표현은 [Microsoft 공식 원본 영상](https://www.youtube.com/watch?v=ZR4v1c4CClc)을 함께 확인해 주세요.

## 마무리

Ignite 2026 오프닝 키노트의 흐름은 새로운 제품을 하나씩 소개하는 데 그치지 않습니다. Copilot이 업무의 시작점이 되고, Microsoft IQ가 조직의 맥락과 지식을 연결하며, Agent 365가 에이전트를 운영하고 보안과 비용까지 관리하는 하나의 구조를 보여줍니다.

글로벌 발표를 빠르게 이해해야 한다면 하이라이트부터 시작하세요. 깊은 맥락과 실제 사례까지 확인하고 싶다면 풀버전에서 해당 장면을 이어서 보시기 바랍니다.

두 영상 모두 **한국어 더빙과 자막**으로 제공하므로, 19분의 빠른 정리와 2시간 25분의 상세한 내용을 원하는 방식으로 선택할 수 있습니다.
